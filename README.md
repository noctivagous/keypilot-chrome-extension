# KeyPilot Chrome Extension

**Keyboard-first navigation for the web with instant visual feedback**

KeyPilot transforms browsing so key presses do the work of mouse clicks. Hover a link and press **F** to activate it. **G** opens the link in a new background tab. KeyPilot calls this a key-click; other actions are arranged on the keyboard the same way.

## Installation

### Manual (development)

1. Run `npm run build` from this repository.
2. Open `chrome://extensions/` (or Opera GX’s extensions page).
3. Enable Developer mode and **Load unpacked**. Select the `extension/` subdirectory.

The toolbar popup shows a short usage overview. In-product docs and Settings live in the extension UI.

#### Navigation

| Keys | Action |
| --- | --- |
| `I` | Copy hovered image |
| `M` | Open saved Media Library |
| `R` | Browser history forward |
| `U` | Copy hovered link URL |
| `;` | Toolbar, visits, and bookmarks |
| `B` | Open link in a new foreground tab |
| `D` | Browser history back |
| `E` | Preview link in a popup |
| `F` | Click the hovered element |
| `G` | Open link in a new background tab |
| `J` | Browse this tab’s history |
| `L` | Address bar overlay |
| `P` | Open link in a popup window |
| `S` | Navigate to the site origin |
| `N` | Origin-based continuous scroll |
| `'` | Open KeyPilot Settings |

#### Tabs

| Keys | Action |
| --- | --- |
| `Q` | Switch to the previous tab |
| `T` | Open a blank new tab |
| `W` | Switch to the next tab |
| `A` | Close the current tab |

#### Page navigation

| Keys | Action |
| --- | --- |
| `O` | Browse media found on this page |
| `C` | Jump one page up instantly |
| `V` | Jump one page down instantly |
| `X` | Jump to bottom of scroll target |
| `Z` | Jump to top of scroll target |

## Compatibility

- Chrome and other Chromium browsers: full support
- Edge: full support
- Opera / Opera GX: Chromium-based; see `refs/OPERA_GX_PUBLICATION_CHECKLIST.md`
- Firefox: limited
- Safari: not supported
