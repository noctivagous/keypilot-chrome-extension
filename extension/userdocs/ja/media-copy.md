# カーソル下をコピー

ホバー中の画像または URL を、1 つのキーでクリップボード、メディアライブラリ、またはその両方へ取得します。

## 使い方

1. 画像またはリンク / URL の対象にホバーし、KeyPilot がハイライトするまで待ちます。
2. <kbd>I</kbd> でホバー中の **画像** をコピーします。
3. <kbd>U</kbd> でホバー中の **URL** をコピーします。
4. クリップボードの代わりに（または加えて）メディアライブラリへ送りたい場合は、レイアウトエディターでアクションインスタンスの設定を確認してください。

**Copy Video** はアクションライブラリにありますが、デフォルトの組み込みキーはありません。必要な場合はレイアウトエディターでバインドしてください。

## リファレンス

### デフォルトキー（ブラウジング、右手）

| キー | アクション |
| --- | --- |
| <kbd>I</kbd> | ホバー中の画像をコピー |
| <kbd>U</kbd> | ホバー中の URL をコピー |

左手ブラウジングでは、画像コピーはデフォルトで <kbd>E</kbd> に配置されます。

### 送信先

多くのコピー関数は次をサポートします:

- クリップボード
- メディアライブラリ
- 両方

アクションインスタンスを設定してから、そのインスタンスをキーに配置します。

### 関連

- **ページメディア**（<kbd>O</kbd>）— ページ上で見つかったものをすべて閲覧
- **メディアライブラリ**（<kbd>M</kbd>）— 保存した内容を確認
