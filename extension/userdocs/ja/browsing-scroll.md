# スクロール

固定ステップ、ジャンプ、または連続のスクロールライン制御で、ページやカーソル下の入れ子スクロール領域をスクロールします。

## 使い方

1. ページ（またはスクロール可能な領域の内側）を指します。
2. **Page Up** と **Page Down** で、設定した距離だけスクロールします。
3. **Scroll To Top** でスクロール対象の先頭へジャンプし、**Scroll To Bottom** で末尾へジャンプします。
4. 連続制御には **Scroll Line** を使います：
   - カーソル下に原点マークが表示されます。
   - 原点からマウスを離します — 遠いほど速くスクロールします。
   - もう一度 **Scroll Line** を使うか、クリックするか、<kbd>Esc</kbd> を押すと終了します。
5. 必要に応じて、設定 → スクロール で**ページの空き領域での中クリック**を有効にし、Scroll Line キーなしでスクロールラインを開始できます。
6. **ズームアウト**（<kbd>[</kbd>）と**ズームイン**（<kbd>]</kbd>）で、カーソル下の点を固定したままタブのズームを1段階変えます。ピンチ操作と同じです。

ステップサイズとアニメーションは**設定 → スクロール**で調整します。

## リファレンス

### 関数

| 関数 | 動作 |
| --- | --- |
| **Page Up** | 設定した瞬間距離だけ上にスクロール |
| **Page Down** | 設定した瞬間距離だけ下にスクロール |
| **Scroll To Top** | スクロール対象の先頭へジャンプ |
| **Scroll To Bottom** | スクロール対象の末尾へジャンプ |
| **Scroll Line** | 原点ベースの連続スクロールを切り替え |
| **ズームアウト** | カーソル位置を基準にタブを1段階縮小 |
| **ズームイン** | カーソル位置を基準にタブを1段階拡大 |

これらの関数のデフォルトキーは、アクティブなキーボードレイアウトによって異なります。

### 重要な設定

- Page Up / Page Down の**スクロール距離**
- ジャンプの**スムーズ／瞬間**アニメーション
- スクロールラインでの**幅広のカルーセル風スクロール領域をスキップ**
- ページの空き領域でスクロールラインを開始する**中クリック**

### スクロール対象

KeyPilot はページ、またはカーソル下の入れ子スクロール領域をスクロールします。スクロールラインが誤った領域にロックした場合は終了してポインターを置き直し、もう一度 **Scroll Line** を使ってください。
