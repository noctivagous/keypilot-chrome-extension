# キーボードレイアウトエディター

レイアウトエディターは、キーへの関数の配置、レイアウトの作成、アクションインスタンスの管理を行うためのものです。

## 使い方

1. <kbd>Alt</kbd>+<kbd>C</kbd> を押すか、キーボードリファレンスのドロップダウンから **Edit Keyboard Layout…** を選びます。
2. キーボードリファレンスが配置面になり、コンフィグパネルにアクションライブラリとレイアウトツールが入ります。
3. **レイアウトを作成または選択** — 組み込みを編集するとユーザコピーが作られます（組み込み自体は読み取り専用のままです）。
4. アクションを探し（ライブラリを検索）、選択してから、キーボードリファレンス上の **キーキャップをクリック** して配置します。
5. 必要に応じて、既存のカスタムスロットを置き換えたりクリアしたりします。
6. そのレイアウトでブラウジングしたいときは、現在のレイアウトに設定します。
7. 終了したら、もう一度 <kbd>Alt</kbd>+<kbd>C</kbd> を押すか、パネルを閉じます。

ドロップダウンからは **New Blank Keyboard Layout** と **New Duplicate Keyboard Layout** も利用できます。

## リファレンス

### レイアウト管理

- ユーザレイアウトの名前変更、削除、複製
- カスタムレイアウトを JSON としてインポート / エクスポート
- 編集中のレイアウトと現在のレイアウトの切り替え

### 配置ルール

- カスタムレイアウトは **排他的** です。割り当てたキーと、常時有効なシステムレイヤーだけが動作します。
- パラメータ付きの関数は、設定を保存した **アクションインスタンス** になります（ラベル、送信先、スクリプト本体など）。
- 一部の関数（たとえば Type Characters）は、入力中でも実行できるよう、素の文字キーではなく **修飾キーのコード** にのみバインドできる場合があります。

### ヒント

- 配置中はキーボードリファレンスを表示したままにし、キーキャップにホバーして確認します。
- 少しだけ変えたいときは、Browsing の Duplicate から始めます。
- 配置できる内容については *関数とアクション* と *Execute JS* を参照してください。
