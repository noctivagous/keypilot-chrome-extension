# クリックとリンク

マウスで要素を指し、キーを押してその下にあるものを操作します。KeyPilot はカーソル下のクリック可能なターゲットまたはテキストフィールドにフォーカス矩形を描画します。

## 使い方

1. リンク、ボタン、またはテキストフィールドの上にポインターを動かし、フォーカス矩形が表示されるまで待ちます。
2. <kbd>F</kbd> を押してクリックします — またはテキストフィールドをフォーカスしてテキストモードに入ります。
3. リンクを**新しい前面タブ**で開くには、<kbd>B</kbd> を押します。
4. **背面タブ**で開く（中クリックと同様）には、<kbd>G</kbd> を押します。
5. ポップアップウィンドウで素早く確認するには、<kbd>E</kbd>（リンクプレビュー）または <kbd>P</kbd>（大きめのポップオーバー）を押します。*リンクプレビューとポップオーバー* を参照してください。

間違った要素がハイライトされる場合は、マウスを少し動かしてください — KeyPilot はカーソル下の末端要素を優先します。

## リファレンス

### デフォルトキー（ブラウジング、右手）

| キー | アクション |
| --- | --- |
| <kbd>F</kbd> | カーソル下をクリック／操作；テキストフィールドをフォーカス |
| <kbd>B</kbd> | リンクを新しいタブで開く（前面） |
| <kbd>G</kbd> | リンクを新しいタブで開く（背面） |
| <kbd>E</kbd> | リンクプレビューポップアップ |
| <kbd>P</kbd> | リンクをポップオーバーポップアップで開く |

### 視覚フィードバック

- フォーカス矩形はクリック可能なターゲットとテキストフィールドを示します。
- 色とグローは**設定 → クリックモード**で調整できます。
- オプションのアクティベーション効果（Flash、Dash、Marquee、Scale）がクリック時に再生されます。

### テキストフィールド

テキストフィールド上で <kbd>F</kbd> を押すとフォーカスし、ほとんどのブラウジングキーを一時停止して入力できるようになります。<kbd>Esc</kbd> を押すとテキストモードを終了します。*モード* を参照してください。
