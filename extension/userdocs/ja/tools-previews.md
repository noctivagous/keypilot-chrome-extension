# リンクプレビューとポップオーバー

現在のタブを置き換えずに、サイズ指定の OS ポップアップウィンドウでリンクを覗けます。

## 使い方

### リンクプレビュー（<kbd>E</kbd>）

1. リンクにホバーしてハイライトされるまで待ちます。
2. <kbd>E</kbd> を押すと、カーソル付近にサイズ指定のポップアップウィンドウが開きます。
3. KeyPilot のタイトルバーから **このタブで開く** または **新しいタブで開く** を使います。
4. <kbd>Esc</kbd>、タイトルバーの閉じる操作、または同じアクションキーでもう一度閉じてください。

### ポップオーバー（<kbd>P</kbd>）

1. リンクにホバーします。
2. <kbd>P</kbd> を押すと、より大きなサイズ指定のポップアップウィンドウが開きます。
3. もう一度 <kbd>P</kbd>、または <kbd>Esc</kbd> で閉じます。

ランチャーのカードプレビューとカテゴリ検索結果も、同じポップアップウィンドウを使います。

## リファレンス

### デフォルトキー（ブラウジング、右手）

| キー | アクション |
| --- | --- |
| <kbd>E</kbd> | リンクプレビューのポップアップ |
| <kbd>P</kbd> | より大きな Open Popover ポップアップ |

### 動作メモ

- プレビューは常に Chrome/Brave のポップアップウィンドウとして開きます（ページ内 iframe ではありません）。
- 設定 / ガイド / ドキュメントは、引き続きページ内ポップオーバーのクローム（タイトルバー、<kbd>Esc</kbd> で閉じる）を使います。
- これらの関数はレイアウトエディターでカスタマイズまたは再バインドできます。
