# マクロ

マクロは、1 つのキーにバインドされた、関数とロジックのステップの順序付きシーケンスです。

## 使い方

1. **キーボードレイアウトエディター**（<kbd>Alt</kbd>+<kbd>C</kbd>）を開き、**User Macros** に進みます（編集は *マクロビルダー* を参照）。
2. 試すストックマクロを選ぶか、自分で作成します。
3. ほかのアクションと同様に、キーボードリファレンスのキーキャップにマクロを配置します。
4. ページでそのキーを押すと、ステップが順に実行され、Gate が続行するかどうかを決めます。

ストックの例には **AI Assist**、**Quick Nav**、**Clip & Search** などのフローがあります。ストックマクロを編集するとユーザコピーにフォークされ、自由にカスタマイズできます。

## リファレンス

### 概念

- **Steps** — 関数（Execute JS を含む）とロジックチップ
- **Gate** — 直前の結果を検査し、続くステップをスキップできる
- **Delay** — ステップ間の任意の待機
- **Run Macro** — 別のマクロを入れ子で実行（循環は防止されます）

### ストックマクロ

読み取り専用のテンプレートです。保存 / 編集すると、自由にカスタマイズして配置できるユーザマクロがフォークされます。

### 単一の関数との比較

| 関数を使う場合… | マクロを使う場合… |
| --- | --- |
| 1 つの操作で足りる | パイプラインが必要 |
| パラメータが単純なまま | Gate / 待機 / 入れ子の実行が必要 |

### 次のステップ

作成 / 編集 / 配置の詳細は *マクロビルダー* を、マクロ内のスクリプトステップは *Execute JS* を開いてください。
