# オムニボックス

オムニボックスは、履歴とブックマークの候補付きのページ上アドレス/検索ボックスです。

## 使い方

1. <kbd>L</kbd>（既定のブラウジング）または <kbd>Alt</kbd>+<kbd>L</kbd> を押します。
2. URL または検索クエリを入力します。
3. <kbd>↑</kbd>/<kbd>↓</kbd> またはポインターで候補を選びます。
4. <kbd>Enter</kbd> で現在のタブをナビゲートします。
5. <kbd>Esc</kbd> でナビゲートせずに閉じます。

URL 以外のクエリは **設定 → 検索** の検索エンジンを使います。

## リファレンス

### 動作

- 候補はブラウザー履歴とブックマークを組み合わせます。
- <kbd>Enter</kbd> は **現在** のタブをナビゲートします（新しいタブを開くランチャーではありません）。
- <kbd>Alt</kbd>+<kbd>L</kbd> は chrome ホットキーとして、レイアウトのオムニボックスキーを再割り当てまたは解除しても動作します。

### 関連

- **ランチャー**（<kbd>Alt</kbd>+<kbd>;</kbd> / <kbd>Alt</kbd>+<kbd>A</kbd>）— カテゴリ分けされたサイトと Launch Deck
- **トップサイト**（<kbd>;</kbd>）— ツールバー / よく訪れるサイト / 最近のブックマーク
- 新しいタブページにも同じエンジン設定の検索が埋め込まれています
