# 関数とアクション

関数は、キーにバインドする構成要素です。**アクションインスタンス**は、関数に保存済みのパラメータ値を加えたものです。

## 使い方

1. **キーボードレイアウトエディター**（<kbd>Alt</kbd>+<kbd>C</kbd>）を開きます。
2. **アクションライブラリ**を閲覧または検索します（カードまたはテーブル表示）。
3. 関数を選択します。パラメータがある場合は、**アクションインスタンス**を作成または編集します（わかりやすい名前を付けます）。
4. キーボードリファレンスのキーキャップをクリックして、そのインスタンスを配置します。
5. 通常のページでそのキーを押して実行します。

あとから動作を変えるときは、コンフィグでインスタンスのパラメータを編集します。そのインスタンスを使うすべてのキーに変更が反映されます。

## リファレンス

### 概念

| 用語 | 意味 |
| --- | --- |
| **関数** | 再利用可能な操作の定義 |
| **アクションインスタンス** | 関数 + 保存済みパラメータ |
| **キーアクション** | スロットを占めるもの — 関数 / インスタンスまたはマクロ |
| **結果の送信先** | クリップボード、ポップオーバー、ページ変更、メディアライブラリなど |

### ライブラリのカテゴリ（概要）

Navigation · Tab Control · Begin URL · Get Page Data · Maps · Scroll · Select · Clipboard · Type · Keystrokes · Data · Lookup · Translate · Script · Media Library · AI · KeyPilot · Tools · System

### 主な関数

<h3 id="type-characters">Type Characters</h3>

保存したテキストをフォーカス中のフィールドに挿入します。入力中でも実行できるよう、修飾キーのコードでバインドします。スニペットごとに 1 つのアクションインスタンスを作成します。

<h3 id="open-urls">URLを開く</h3>

保存したウェブサイトの一覧をバックグラウンドタブで開きます。サイト集ごとにアクションインスタンスを作り、キーボードレイアウトエディタのインスペクタで URL を編集します。[タブと履歴](kp://docs/browsing-tabs#open-urls) を参照してください。

<h3 id="font-info">Font Info</h3>

カーソル下のスタイル付きテキストについて、ファミリー、サイズ、ファイル形式、ダウンロード URL をポップオーバーで表示し、そのテキストランのアウトラインも示します。

<h3 id="lookup-word">単語を調べる</h3>

英語辞書機能です。カーソル下の英単語について Free Dictionary API の定義を表示します。日本語辞書には対応していません。パスが利用可能な場合、アクションインスタンスで Ask AI ソースをオプションとして選べます。

<h3 id="translate">翻訳</h3>

ハイライト、またはカーソル下の単語 / 文 / 段落を翻訳します。送信先はページテキストの置換、またはポップオーバーの表示にできます。

<h3 id="send-text-to-ai">Send selection to AI</h3>

設定可能な指示とともに選択テキストを送ります。結果をクリップボード、ポップオーバー、またはその両方へルーティングできます。

<h3 id="get-text-at-cursor">Get text / media under cursor</h3>

**Get Text At Cursor** は単語、文、段落、またはハイパーリンクのテキストをコピーします。**Get Media At Cursor** はカーソル下の画像、動画、または音声をコピーします。**Get Text Range** は、現在のハイライトを次のステップに渡すマクロステップです。

<h3 id="show-popover">Show Popover</h3>

前のステップの結果（またはフォールバックテキスト）を結果ポップオーバーに表示するマクロステップです。

<h3 id="poi">Map place (POI)</h3>

カーソル下に地図ピンがあるとき: **Place Website** はリンクプレビューでその場所のページを開き、**Place Address** は住所をコピーします（txt または vCard）。

<h3 id="media-library-functions">Add / Fetch URL for Media Library</h3>

**Add URL** はホバー中の href をダウンロードせずに保存します。**Fetch URL** はリンク先のファイル（PDF、音声、動画、画像）をメディアライブラリへダウンロードします。

<h3 id="execute-js">Execute JS</h3>

カスタムスクリプト関数です。バインディング、コールバック、AI プロンプトの詳細: [Execute JS](kp://docs/execute-js)。

<h3 id="keystrokes">Macro Keys (keystrokes)</h3>

ホットキー、バースト、ラウンドロビン、連続キー、合成マウス、リマップ — アクションライブラリでインスタンス化できるキーストローク関数です。[キーボードレイアウトエディター](kp://docs/layout-config) を参照してください。

### ストックとユーザ

組み込みレイアウトは読み取り専用のソースです。編集すると、所有するユーザコピーがフォークされます。
