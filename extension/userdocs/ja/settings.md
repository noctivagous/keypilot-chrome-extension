# 設定

設定では外観、スクロール、検索エンジン、コントロールストリップ、使用するキーボードファミリーなどを制御します。変更は同じ Chrome プロファイル内のタブ間で同期されます。

## 使い方

1. <kbd>'</kbd>（クォート）を押すか、コントロールストリップ、ポップアップ、新しいタブページ、キーボードリファレンスのドロップダウンから設定を開きます。
2. 左ナビでカテゴリを選びます。
3. コントロールを調整します — ほとんどはすぐに適用されます。
4. 終わったら <kbd>Esc</kbd> またはタイトルバーの閉じるコントロールを押します。

まずは [**キーボード**](kp://settings/keyboard)（レイアウト + 利き手）と [**スクロール**](kp://settings/scrolling)（Page Up / Page Down の距離）から始めてください。基本が馴染んだら [**クリックモード**](kp://settings/click-mode) と [**テキストモード**](kp://settings/text-mode) を微調整します。

## リファレンス

### カテゴリ

| セクション | 設定内容 |
| --- | --- |
| [**概要**](kp://settings/overview) | 各カテゴリへのハブ |
| [**外観**](kp://settings/appearance) | テーマと視覚的 chrome |
| [**キーボード**](kp://settings/keyboard) | レイアウトファミリー、左手、数字行、押下キーフィードバック |
| [**クリックモード**](kp://settings/click-mode) | カーソルスタイル、クロスヘア形状、フォーカス矩形の見た目、リンクホバーヒント、起動効果 |
| [**テキストモード**](kp://settings/text-mode) | カーソル、フォーカススタイル（パルス端 / ティント）、端の幅、ラベル、アウトライン |
| [**スクロール**](kp://settings/scrolling) | Page Up / Page Down の距離、スムーズと瞬時のジャンプ、カルーセルスキップ、中クリックのスクロールライン |
| [**カーソル**](kp://settings/cursor) | カスタムカーソルなし vs KeyPilot カーソル；有効時のクリックモードクロスヘア形状 |
| [**コントロールストリップ**](kp://settings/control-strip) | 表示と開始時折りたたみ；<kbd>Alt</kbd>+<kbd>J</kbd> で復元 |
| [**検索**](kp://settings/search) | オムニボックス / 新しいタブ検索用の Brave、Google、または DuckDuckGo |
| [**について**](kp://settings/about) | この Chrome プロファイルの保存と同期に関するメモ |

### 関連する画面

- 深いキーの再割り当ては設定ではなく **キーボードレイアウトエディター**（<kbd>Alt</kbd>+<kbd>C</kbd>）にあります。[キーボードレイアウトエディター](kp://docs/layout-config) を参照してください。
- ドキュメントは <kbd>Alt</kbd>+<kbd>H</kbd>；短いガイドページはいくつかの chrome 入口から引き続き利用できます。
