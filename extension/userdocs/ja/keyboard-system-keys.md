# システムキーと Alt chrome

一部のキーは常に KeyPilot の chrome に属します。組み込みレイアウトでもカスタムレイアウトでも利用できます。

## 使い方

### 常時オンのシステムレイヤー

これらの文字キーは、カスタムレイアウトで空にしてあっても動作します：

1. <kbd>Esc</kbd> を押すと、現在のモード（テキストモード、選択、スクロールライン、多くのポップオーバー）をキャンセルします。
2. <kbd>K</kbd>（右手）または <kbd>D</kbd>（左手）で **キーボードリファレンス** の表示/非表示を切り替えます。
3. <kbd>'</kbd>（クォート）で **設定** を開きます。

### Alt chrome ホットキー

<kbd>Alt</kbd> を押しながら次を押します：

| 組み合わせ | アクション |
| --- | --- |
| <kbd>Alt</kbd>+<kbd>K</kbd> | KeyPilot のオン/オフ（無効時でも動作） |
| <kbd>Alt</kbd>+<kbd>J</kbd> | コントロールストリップの表示/非表示（無効時でも動作） |
| <kbd>Alt</kbd>+<kbd>L</kbd> | オムニボックスを開く |
| <kbd>Alt</kbd>+<kbd>;</kbd> または <kbd>Alt</kbd>+<kbd>A</kbd> | 検索にフォーカスした状態でランチャーを開く |
| <kbd>Alt</kbd>+<kbd>[</kbd> / <kbd>Alt</kbd>+<kbd>]</kbd> | 前 / 次のレイアウトファミリー |
| <kbd>Alt</kbd>+<kbd>C</kbd> | キーボードレイアウトエディターの表示切替 |
| <kbd>Alt</kbd>+<kbd>H</kbd> | このドキュメントを開く |
| <kbd>Alt</kbd>+<kbd>I</kbd> | 導入ウォークスルーの表示/非表示 |

まず <kbd>Alt</kbd>+<kbd>K</kbd>、<kbd>Esc</kbd>、<kbd>K</kbd>、<kbd>'</kbd>、<kbd>Alt</kbd>+<kbd>H</kbd> を覚えてください — ほかの機能への入口になります。

## リファレンス

### システムレイヤーとレイアウトキー

- **システムレイヤー** — <kbd>Esc</kbd>、キーボードリファレンス、設定。レイアウトファミリーとは別に定義されます。
- **レイアウトキー** — <kbd>F</kbd>、<kbd>D</kbd>、スクロール、ツールなど。有効な組み込みまたはカスタムレイアウトから来ます。
- **Alt chrome** — 通常のキー振り分けより先に処理されます。通常の文字割り当てとしては表示されません。

### 利き手に関する注意

左手レイアウトでは、ミラーされた Activate クラスターと衝突しないよう、キーボードリファレンスは <kbd>D</kbd> に移ります。設定は <kbd>'</kbd> のままです。

### 日常用途ではありません

<kbd>Alt</kbd>+<kbd>D</kbd> は開発者向けの shadow-root デバッグ HUD を切り替えます。描画の診断以外では使わないでください。
