# はじめに

KeyPilot は通常のウェブページにキーボードショートカットを追加します。マウスでリンクやボタンを指し、キーを押して操作します — マウスの手が狙い、キーボードの手が実行します。

## 基本的な使い方

### 要素をクリックする
1. ポインターをリンクの上に移動します。ターゲットにフォーカス矩形が表示されます。
2. <kbd>F</kbd>（デフォルトの右手のブラウジングレイアウト）を押してクリックします。

### 必須キー
1. <kbd>Alt</kbd>+<kbd>K</kbd> を押して KeyPilot のオン／オフを切り替えます。
2. <kbd>K</kbd> を押してキーボードリファレンスを開きます — 割り当て済みのすべてのキーのライブマップです。
3. <kbd>Alt</kbd>+<kbd>H</kbd> を押すと、このドキュメントに戻ります。

特に記載がない限り、これらのドキュメントでのキー名は**デフォルトの右手のブラウジング**レイアウトを指します。左手レイアウトでは主なクラスターがミラーされます。カスタムレイアウトでは割り当てた任意のキーを使えます。

## KeyPilot が提供するもの

- **クリック、スクロール、ナビゲート** — 毎回キーボードとマウスの間で手を動かさずに操作できます。<kbd>F</kbd> でクリック、<kbd>C</kbd>/<kbd>V</kbd> でスクロール、<kbd>D</kbd>/<kbd>R</kbd> で戻る／進む。
- **追加のブラウジングツール** — オムニボックス、ランチャー、トップサイト、タブ履歴、メディア収集。
- **完全なカスタマイズ** — キーの再割り当て、アクションインスタンスの作成、Execute JS スクリプトの実行。

## 制限事項

KeyPilot は通常のウェブページ上でコンテンツスクリプトとして動作します。Chrome は新しいタブページ、`chrome://` ページ、Chrome Web Store での拡張機能の実行を許可しません。
