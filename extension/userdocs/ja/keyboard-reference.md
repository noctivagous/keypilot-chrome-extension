# キーボードリファレンス

フローティングのキーボードリファレンスは、現在のレイアウトのライブマップです — 学習とレイアウト切替にいちばん速い手段です。

## 使い方

1. <kbd>K</kbd>（右手）または <kbd>D</kbd>（左手）を押すか、コントロールストリップ / ポップアップ / 新しいタブのトグルを使います。
2. キーキャップにホバーすると、割り当てられたアクションが表示されます。
3. **タイトルバーのレイアウトドロップダウン**で次ができます：
   - 組み込みファミリーまたはカスタムレイアウトの切替
   - レイアウトエディターを開く（編集 / 新規 / 複製）
   - **導入チュートリアル** を起動
   - **KeyPilot ドキュメント/ヘルプ**（このポップオーバー）を開く
   - **KeyPilot 設定** を開く
4. ウィンドウをドラッグできます。画面が必要なら折りたたみ、× または同じトグルキーで閉じます。
5. KeyPilot がテキストモードのとき、<kbd>Esc</kbd> の代わりにリファレンス chrome 上の <kbd>Exit</kbd> も使えます。

## リファレンス

### 表示内容

- 有効なファミリー、利き手、カスタム割り当て
- 常時オンのシステムキー
- 任意の数字行（設定 → キーボード）
- フィードバック有効時の押下キーのハイライト
- リンクホバー時のアクションキーの任意のグロー（設定 → クリックモード）

### 編集モード

<kbd>Alt</kbd>+<kbd>C</kbd> のレイアウトエディターが開いているとき、キーボードリファレンスは配置面になります：ライブラリでアクションを選び、キーキャップをクリックして割り当てます。

### ヒント

- 学習中はセカンドモニターや画面の隅に開いたままにしておくと便利です。
- キーが何もしないときは、KeyPilot の不具合と決めつける前にこのウィンドウを確認してください — ナビゲーションファミリーや疎なカスタムレイアウトの可能性があります。
