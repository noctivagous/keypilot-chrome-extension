# 選択

カーソル下のテキストまたは HTML 要素を選択し、結果をコピーしたり操作したりします。

## 使い方

### テキスト選択

1. 選択を開始したい位置にカーソルを移動します。
2. <kbd>H</kbd> を押して文字単位のテキスト選択を開始します。
3. 範囲の終わりまで移動し、もう一度 <kbd>H</kbd> を押して完了しコピーします。
4. コピーせずにキャンセルするには <kbd>Esc</kbd> を押します。

テキスト選択はキャレットからキャレットまで（クリックドラッグと同様）で、破線矩形の切り抜きではありません。矩形はドラッグガイドです。コピーされる範囲は、開始と終了のキャレットの間にあるドキュメント順のすべての内容です。

コピー形式（リッチテキストまたはプレーンテキスト）は、テキスト選択関数のアクションインスタンスで設定できます。

### 要素選択

1. <kbd>Y</kbd> を押して、交差する HTML 要素の矩形選択を開始します。
2. 選択したい要素の上で矩形をドラッグ／調整します。
3. 画面上の案内に従って選択を完了します（設定されていれば累積ピックモードも使えます）。
4. <kbd>Esc</kbd> を押すとキャンセルします。

デフォルトの粒度は記事の機能単位です。段落または見出し、テーブル全体（個々のセルではない）、図または画像全体（内側の画像ではない）、リスト全体。段落内のリンクをヒットすると、その段落がすぐに選択されます。重なり判定は各要素の行ボックスを使い、単一の境界ボックスではありません。

## リファレンス

### デフォルトキー（ブラウジング、右手）

| キー | アクション |
| --- | --- |
| <kbd>H</kbd> | テキスト選択（開始／完了 + コピー） |
| <kbd>Y</kbd> | 要素の矩形選択（または累積ピックモード） |
| <kbd>Esc</kbd> | 選択モードをキャンセル |

### <kbd>Y</kbd> のモード

- **矩形** — 描いた矩形と行ボックスが交差する記事の機能単位（段落、テーブル、図、リスト）を選択します。段落内のリンクはその段落を選択します。
- **累積ピック** — 要素をひとつずつ追加し、<kbd>Enter</kbd> で完了します（関数側で設定）。

### 関連ツール

- <kbd>I</kbd> / <kbd>U</kbd> はホバー中の画像／URL をコピーします（*カーソル下をコピー* を参照）。
- <kbd>O</kbd> はページ上で見つかったすべての Page Media を開きます。
- クリップボードとメディアライブラリの送信先は、レイアウトエディター内の多くの Get / Copy 関数に表示されます。

## 単位選択（クリップボード）

Actions Library の Clipboard セクションから **Select Word**、**Select Sentence**、**Select Paragraph**、または **Select Image** を配置します。これらはコピーせずに KeyPilot カーソル下を選択します。

1. 単語、文、段落、または画像の上にホバーします。
2. 割り当てたキーを押して選択します。同じ単位の上でもう一度押すと選択解除します。
3. **Copy**（または Cut）で KeyPilot の選択をクリップボードに送ります。
4. <kbd>Esc</kbd> を押すと選択をクリアします。

各関数はキーボードリファレンスのキー情報ポップオーバーに Exclusive / Cumulative を表示します（その関数で共有され、キーごとのアクションインスタンスではありません）。

- **Exclusive**（デフォルト） — 押すと現在の選択を置き換えます。
- **Cumulative** — 単位を追加または削除します。離れた範囲もハイライトされたままです。

KeyPilot は独自のハイライトを描画するため、隙間のある選択も見えるままです。これは <kbd>H</kbd> / <kbd>Y</kbd> のドラッグ選択とは別です。
