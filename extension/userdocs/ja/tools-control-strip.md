# コントロールストリップ

コントロールストリップは、マウスに触れずに KeyPilot の切り替え、キーボードリファレンスの表示、設定へのアクセスができる、常時表示の小さなバーです。

## 使い方

1. ページ上でストリップを探します（ドラッグ可能）。消えている場合は <kbd>Alt</kbd>+<kbd>J</kbd> で復元します。
2. 次の操作に使います:
   - KeyPilot の **オン/オフ**
   - **キーボードリファレンス** を開く
   - **設定** を開く
   - ストリップの折りたたみ / 展開、または閉じる
3. 移動ハンドルでドラッグして、邪魔にならない位置に置きます。
4. **設定 → コントロールストリップ** で、起動時に表示するか折りたたむかを選べます。

KeyPilot が無効でも、<kbd>Alt</kbd>+<kbd>J</kbd> でストリップを復元できます。

## リファレンス

### コントロール

| コントロール | 役割 |
| --- | --- |
| オン/オフ | <kbd>Alt</kbd>+<kbd>K</kbd> と同等 |
| キーボードリファレンス | <kbd>K</kbd> / <kbd>D</kbd> と同等 |
| 設定 | <kbd>'</kbd> と同等 |
| 折りたたみ / 閉じる | ストリップを隠します。<kbd>Alt</kbd>+<kbd>J</kbd> で復元 |

### 外観

- テキストモードではストリップがオレンジ色になり、ブラウジングキーが一時停止している理由がわかります。
- 表示の設定はプロファイルと同期します。
