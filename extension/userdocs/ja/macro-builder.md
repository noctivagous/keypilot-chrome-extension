# マクロビルダー

マクロビルダーは、キーボードレイアウトエディターから使うユーザマクロ用のステップエディターです。

## 使い方

1. <kbd>Alt</kbd>+<kbd>C</kbd> を押してレイアウトエディターを開きます。
2. **User Macros** を開きます。
3. マクロを **作成** してわかりやすい名前を付けるか、既存のものを複製します。
4. ステップを追加します:
   - アクションライブラリで関数を選び、マクロに追加します
   - **Logic** チップを追加します: Wait、Gate、Stop、Run Macro
   - 次のステップ用に現在の選択を取り込む **Get Text Range** を追加します
   - 前のステップの結果（またはフォールバックテキスト）を表示する **Show Popover** を追加します
   - 貼り付けたスクリプトを実行する **Execute JS** を追加します
5. ステップの並べ替えや削除を行い、ステップを開いてパラメータと任意の遅延を設定します。
6. **Save** したあと、ライブラリ / マクロ一覧からキーにマクロを配置します。
7. 通常のページで試し、早めに打ち切りたい場合は Gate を調整します。

## リファレンス

### ロジックチップ

| チップ | 役割 |
| --- | --- |
| **Wait** | 次のステップの前に一時停止 |
| **Gate** | 直前の結果を検査し、失敗時は設定した後続ステップをスキップ |
| **Stop** | マクロを終了 |
| **Run Macro** | 別のマクロを呼び出す（入れ子。循環は防止） |
| **Execute JS** | 貼り付けたスクリプトを実行。戻り値は次の Gate に渡る |
| **Get Text Range** | 次のステップ用に現在のハイライト / 選択を取り込む。キーアクションではありません（Copy を使います）。 |
| **Show Popover** | 前の関数の結果（または設定したフォールバックテキスト）をポップオーバーに表示。キーアクションではありません。 |

### Gate のテスト

直前の関数の結果に対する典型的な比較:

- Has value / empty
- Equals / not equal
- Greater than / less than

失敗した Gate は設定どおり先へ進むので、本格的なスクリプトなしで分岐できます。

### ステップとしての Macro Keys

設定済みのキーストロークプリミティブ（ホットキー、バースト、ラウンドロビン、連続、合成マウス、通常のリマップ）は、単体のキーアクションとしても、マクロの関数ステップとしても実行できます。

### ヒント

- マクロは短く保ち、ステップには意図がわかる名前を付けます。
- ステップが何も返さない可能性があるときは、無条件の長い連鎖より Gate を優先します。
- Execute JS の戻り値は、次の Gate に `kpPriorResult` として渡ります（*Execute JS* を参照）。
