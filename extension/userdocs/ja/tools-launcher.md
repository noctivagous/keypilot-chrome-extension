# ランチャー

ランチャーは、検索、ブックマーク、履歴、編集可能な Launch Deck 付きのカテゴリ分けサイトブラウザーです。

## 使い方

1. <kbd>Alt</kbd>+<kbd>;</kbd> または <kbd>Alt</kbd>+<kbd>A</kbd> で、検索にフォーカスした状態でランチャーを開きます。
2. 入力して絞り込むか、カテゴリを閲覧します（Launch Deck、ブックマーク、最近、ソーシャル、ニュース、生産性、動画、エンターテイメント、ショッピング、AI、Internet Archive、検索など）。
3. グリッドまたは一覧からサイトを開きます。
4. <kbd>/</kbd> で再び検索にフォーカス；<kbd>←</kbd>/<kbd>→</kbd>/<kbd>↑</kbd>/<kbd>↓</kbd> で移動；<kbd>Esc</kbd> で閉じます（または先に編集モードを終了）。

自分用のショートカットをピン留めするには **Launch Deck** を開き、編集モードで並べ替え、削除、追加を行います。

## リファレンス

### 開き方

| 方法 | メモ |
| --- | --- |
| <kbd>Alt</kbd>+<kbd>;</kbd> / <kbd>Alt</kbd>+<kbd>A</kbd> | chrome ホットキー — 検索にフォーカス |
| レイアウトの Function | ランチャーはレイアウトエディターで任意のキーに割り当て可能（右手ブラウジングには裸の既定キーなし） |

### サブビュー

- Launch Deck / サイトカテゴリ
- お気に入り / ブックマーク
- 履歴
- 検索

### ヒント

- 繰り返し訪れる宛先にはランチャー、その場の URL やクエリにはオムニボックスが向いています。
- Launch Deck の編集はプロファイルに保存されます。
