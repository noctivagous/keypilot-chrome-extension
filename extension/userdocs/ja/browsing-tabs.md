# タブと履歴

ブラウザのボタンに手を伸ばさずに、タブとブラウザ履歴を移動します。

## 使い方

1. <kbd>Q</kbd> / <kbd>W</kbd> を押して前／次のタブへ移動します。
2. <kbd>T</kbd> で新しいタブ、<kbd>A</kbd> で現在のタブを閉じます。
3. <kbd>D</kbd> で戻る、<kbd>R</kbd> で進みます。
4. <kbd>S</kbd>（または <kbd>1</kbd>）で現在のサイトのルート（スキーム + ホスト）へジャンプします。
5. <kbd>J</kbd> で**タブ履歴**を開きます — このタブ向けの分岐対応の履歴ストリップです（*タブ履歴* を参照）。
6. <kbd>.</kbd> で**タブ一覧**を開きます。各ウィンドウがカードになり、その中のタブがリスト表示されます。タブをキークリックすると移動し、見出しをキークリックするとそのウィンドウだけに移動します。左手ブラウジングでは <kbd>X</kbd> です。

## リファレンス

### デフォルトキー（ブラウジング、右手）

| キー | アクション |
| --- | --- |
| <kbd>Q</kbd> | 前のタブ |
| <kbd>W</kbd> | 次のタブ |
| <kbd>T</kbd> | 新しいタブ |
| <kbd>A</kbd> | タブを閉じる |
| <kbd>D</kbd> | 戻る |
| <kbd>R</kbd> | 進む |
| <kbd>S</kbd> / <kbd>1</kbd> | サイトのルート |
| <kbd>J</kbd> | タブ履歴ポップオーバー |
| <kbd>.</kbd> | タブ一覧（左手: <kbd>X</kbd>） |

<h3 id="open-bookmarks">ブックマークを開く</h3>

**ブックマークを開く**はタブ操作のアクションインスタンスです。ブックマークマネージャからフォルダを選びます。キーを押すと、そのフォルダ内のウェブサイトを先頭から30件、サブフォルダを含めて、現在のタブの後にバックグラウンドタブで開きます。

### ヒント

- 戻る／進むは、そのタブの通常のブラウザ履歴に従います。
- タブ履歴は分岐から離れてナビゲートしたときの代替ブランチを保持します — 同じページから複数の経路を探索したあとに便利です。
- 左手のブラウジングでは、これらのクラスターがキーボードの右側にミラーされます。
- **URLを開く** はインスペクタに保存したサイト一覧を、1 つのキーでバックグラウンドタブとして開きます。
