# レイアウトと利き手

**レイアウト**はキー → アクションの対応です。KeyPilot には組み込みのファミリーが用意されており、利き手の切替やカスタムレイアウトの作成もできます。

## 使い方

1. **設定**（<kbd>'</kbd>）→ **キーボード** を開くか、**キーボードリファレンス**のタイトルバーにあるレイアウトのドロップダウンを使います。
2. **ファミリー**を選びます：
   - **ブラウジング** — クリック、スクロール、タブ、ツール一式（既定）。
   - **ナビゲーション** — クリック / 戻る / 進むに絞ったコンパクトなセット。
3. マウスを左手で持つ場合は **左手** を有効にします — 主なショートカットがキーボードの右側へ移ります。
4. 利き手はそのままに、<kbd>Alt</kbd>+<kbd>[</kbd>（前）と <kbd>Alt</kbd>+<kbd>]</kbd>（次）でいつでもファミリーを切り替えられます。
5. キーを詳しくカスタマイズするには、<kbd>Alt</kbd>+<kbd>C</kbd> でキーボードレイアウトエディターを開きます（そのトピックを参照）。

切替後に <kbd>K</kbd>（キーボードリファレンス）を開いてください — 描画されるキーボードは常に有効なレイアウトと一致します。

## リファレンス

### 組み込みファミリー

| ファミリー | 用途 |
| --- | --- |
| ブラウジング | 日常のキーボード優先ブラウジング |
| ナビゲーション | 最小限のナビゲーションサブセット |

利き手はファミリーとは独立しています。旧「Basic Navigation」の ID は古い設定から解決される場合がありますが、通常のピッカーには表示されません。

### カスタムレイアウト

- レイアウトエディターで組み込みを編集すると、ユーザーコピーが作成されます（例：「Browsing Copy 1」）。
- カスタムレイアウトは **排他的** です：割り当てたスロットと常時オンのシステムレイヤーだけが動作します。
- レイアウトエディターから JSON をインポート/エクスポートして、バックアップや共有ができます。

### 関連する設定

- キーボードリファレンス / エディターに数字行を表示
- ショートカット入力時の押下キーフィードバック
- 現在のレイアウト ID とファミリーは Chrome プロファイルに保存されます
