# モード

KeyPilot は連続入力が必要な操作にモーダル状態を使います。モードが有効な間、ほとんどのブラウジングキーは一時停止されます。<kbd>Esc</kbd> はほぼ常にキャンセルします。

## 使い方

1. **通常のブラウジング** — ショートカットが有効で、フォーカス矩形がクリック可能なターゲットを示します。
2. **テキストモード** — テキストフィールド上で <kbd>F</kbd> を押します。通常どおり入力します。終わったら <kbd>Esc</kbd>（またはキーボードリファレンスの終了コントロール）を押します。
3. **スクロールライン** — <kbd>B</kbd> を押し、原点から離れてスクロールします。<kbd>B</kbd>、クリック、または <kbd>Esc</kbd> で終了します。
4. **選択** — <kbd>H</kbd> または <kbd>Y</kbd>。<kbd>Esc</kbd> でキャンセルします。
5. **削除モード** — <kbd>Backspace</kbd> を押し、要素を狙って確認するとページから削除します。<kbd>Esc</kbd> でキャンセルします。
6. **ポップオーバー／オムニボックス／レイアウトエディター** — それぞれ独自の開いた状態です。<kbd>Esc</kbd> またはツールの閉じるキーで閉じます。

キーが「効かない」ように感じる場合は、テキストモードや別のモーダルに入っている可能性があります。<kbd>Esc</kbd> を一度押してからもう一度試してください。

## リファレンス

### テキストモードの詳細

- ほとんどのレイアウトのブラウジングキーは一時停止されるため、安全に入力できます。
- 短いホバー＋<kbd>F</kbd> のウィンドウでは、テキストフォーカスを完全に離れずに別のクリック可能なターゲットを操作できます（カウントダウン対応の Activate）。
- 見た目（T字／クロスヘア、オレンジの縁、ラベル）は**設定 → テキストモード**にあります。

### 削除モード

- デフォルトレイアウトでは <kbd>Backspace</kbd> で入ります。
- 要素を視覚的に選び、確認するとその DOM ノードがライブページから削除されます（ページローカル — ブラウザ履歴の取り消しではありません）。

### その他のモーダルサーフェス

| サーフェス | 典型的な開き方 | 終了 |
| --- | --- | --- |
| リンクプレビュー | <kbd>E</kbd> | <kbd>Esc</kbd>、タイトルバーの閉じる、または同じアクションをもう一度 |
| ポップオーバー | <kbd>P</kbd> | <kbd>Esc</kbd> / <kbd>P</kbd> で切り替え |
| オムニボックス | <kbd>L</kbd> / <kbd>Alt</kbd>+<kbd>L</kbd> | <kbd>Esc</kbd> |
| キーボードレイアウトエディター | <kbd>Alt</kbd>+<kbd>C</kbd> | <kbd>Alt</kbd>+<kbd>C</kbd> / 閉じる |
| 設定 / ドキュメント / ガイド | <kbd>'</kbd> / <kbd>Alt</kbd>+<kbd>H</kbd> / ガイド入口 | <kbd>Esc</kbd> |

### 常に利用可能

テキストモードでブラウジングキーが一時停止されているときや、拡張機能がオフのときでも、<kbd>Alt</kbd>+<kbd>K</kbd> は KeyPilot を切り替えます。
