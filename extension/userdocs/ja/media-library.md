# メディアライブラリ

メディアライブラリは、ブラウジング中に集めた画像、動画、ドキュメント、URL の個人用ギャラリーです。

## 使い方

1. <kbd>M</kbd> を押します（デフォルトの右手ブラウジング）。
2. **Images**、**Videos**、**Documents**、**URLs**、およびドメイン別に閲覧します。
3. 項目を開くかフルビュー表示し、範囲選択で一括操作します。
4. カテゴリまたは選択内容を ZIP でダウンロードし、不要なものは削除します。
5. <kbd>Esc</kbd> またはオーバーレイの閉じる操作で閉じます。

項目はページメディア、カーソル下をコピーする関数、または送信先としてメディアライブラリを列挙するほかのアクションから追加できます。

## リファレンス

### デフォルトキー

| レイアウト | キー |
| --- | --- |
| ブラウジング右手 | <kbd>M</kbd> |

### カテゴリ

- Images、Videos、Documents、URLs（およびドメインのグループ）
- ホバー中のファイルリンクで **Fetch URL for Media Library** を使うか、ページメディアから送信します

### ヒント

- 長く残す保存にはメディアライブラリを優先し、一度きりの貼り付けにはクリップボードの送信先を使います。
