# ページメディア

ページメディアは、現在のページ上の画像、動画、テキスト、ドキュメント、フォント、URL をスキャンし、手動で調べなくても閲覧や保存ができるようにします。

## 使い方

1. デフォルトの右手ブラウジングレイアウトで <kbd>O</kbd> を押します。
2. タブを切り替えます: **Image**、**Video**、**Text**、**Docs**、**Fonts**、**URLs**。
3. 項目をプレビューします。必要に応じて画像の拡大率やアスペクトを調整します。
4. コピー、ダウンロード、フルビューを開く、または項目を **メディアライブラリ** に送ります。
5. <kbd>Esc</kbd> またはオーバーレイの閉じる操作で閉じます。

ページ上のすべてを見たいときはページメディアを使い、すでにホバーしているアセットがわかっているときは <kbd>I</kbd> / <kbd>U</kbd> を使います。

## リファレンス

### デフォルトキー

| レイアウト | キー |
| --- | --- |
| ブラウジング右手 | <kbd>O</kbd> |

必要ならレイアウトエディターで再バインドできます。

### 機能

- 画像の拡大率とアスペクトの制御。**Article first**（デフォルトでオン）は、サイトのクロームより記事 / メイン内の画像を優先して並べます
- Fonts タブ（カスタムの `.woff2` / `.otf` / `.ttf` を先に、次にシステムフォント）
- URL のテーブルビュー、またはカードグリッドとして折り返すリストビュー（記事 / メインを先に、サイトのヘッダー / フッターを後に）
- コピー、メディアライブラリへの送信、ダウンロード
- 画像 / 動画のフルビュー

### 関連

- **メディアライブラリ**（<kbd>M</kbd>）— 保存したコレクション
- **カーソル下をコピー** — ホバー中の単一の画像 / URL
