# スタートガイド

任意のページで最初の数キーを押してみてください。レイアウトが身につくまでキーボードリファレンスを開いたままにしておくとよいです。

## 使い方

1. <kbd>Alt</kbd>+<kbd>K</kbd> で KeyPilot の**オン**／**オフ**を切り替えます。
2. <kbd>Alt</kbd>+<kbd>J</kbd> でコントロールストリップを切り替えます。
3. <kbd>K</kbd> で**キーボードリファレンス**を切り替えます。
4. キーボードリファレンスのレイアウトドロップダウン（KeyPilot → Onboarding Tutorial）から**オンボーディングチュートリアル**を開くか、<kbd>Alt</kbd>+<kbd>I</kbd> を押してウォークスルーを表示します。

### 最初に練習するキーコマンド

| 目的 | デフォルトキー |
| --- | --- |
| カーソル下をクリック／フォーカス | <kbd>F</kbd> |
| 戻る | <kbd>D</kbd> |
| サイトのルート | <kbd>S</kbd> |
| 進む | <kbd>R</kbd> |
| 上／下にスクロール | <kbd>C</kbd> / <kbd>V</kbd> |
| モード終了／キャンセル | <kbd>Esc</kbd> |
| キーボードリファレンス | <kbd>K</kbd> |
| 設定 | <kbd>'</kbd> — [設定](kp://settings/overview) を開くか [キーボード](kp://settings/keyboard) へジャンプ |
| KeyPilot の切り替え | <kbd>Alt</kbd>+<kbd>K</kbd> |
| このドキュメント | <kbd>Alt</kbd>+<kbd>H</kbd> |

### ウォークスルーと練習

- **ウォークスルー**は実際のブラウジング操作のチェックリストです。進捗は Chrome プロファイルに保存され、チュートリアルの入口からリセットできます。
- **練習パネル**はテキストボックスのスライドと一緒に表示され、<kbd>F</kbd> でフォーカスし、通常どおり入力し、<kbd>Esc</kbd> で抜けられます。

</section>
<section class="article-column">

### その他の入口

- 拡張機能の**ポップアップ** → Tutorial
- **ガイド**ポップオーバー → Launch Walkthrough
- キーボードリファレンスのドロップダウン → Onboarding Tutorial
- <kbd>Alt</kbd>+<kbd>I</kbd> は進捗をリセットせずにウォークスルーの表示／非表示を切り替えます

</section>

### 何も起きない場合

- KeyPilot が有効か確認してください（<kbd>Alt</kbd>+<kbd>K</kbd>）。
- `chrome://` や Web Store 上にいないことを確認してください。
- キーボードリファレンスを開き、押したキーがレイアウトにまだ割り当てられているか確認してください。
