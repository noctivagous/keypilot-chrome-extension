# トップサイト

トップサイトは、ツールバーのブックマーク、よく訪れるサイト、最近のブックマーク、KeyPilot ツール向けのコンパクトなパネルです。

## 使い方

1. <kbd>;</kbd> を押します（既定の右手ブラウジング；左手では多くの場合 <kbd>A</kbd> / <kbd>&#96;</kbd>）。
2. パネル内のタブを切り替えます：**ツールバー**、**よく訪れるサイト**、**最近のブックマーク**、および右端の **KeyPilot**。数字キー <kbd>1</kbd>–<kbd>4</kbd> でタブへジャンプ；<kbd>Tab</kbd> で循環します。
3. サイトカードをクリックまたは起動してナビゲートします。パネルはカード 3 行分の高さがあり、切れません。
4. **KeyPilot** タブを開くと、拡張機能ポップアップと同じツールカードが表示されます：キーボードリファレンス、ヘルプ / ドキュメント、導入チュートリアル、設定、コントロールストリップ。
5. **トップサイト** のタイトルバーをドラッグしてパネルを移動し、端や角をドラッグしてリサイズします。サイズと位置は記憶されます。
6. <kbd>Esc</kbd> またはタイトルバーの閉じるボタンで閉じます。

## ページをまたいで開いたままにする

既定ではトップサイトは一時的なモーダルです（<kbd>Esc</kbd>、外側クリック、またはページ離脱で閉じます）。

キーボードリファレンスのようにブラウジング中も残すには：

1. タイトルバーの歯車メニューを開きます（閉じるの左）。
2. **ページをまたいで開いたままにする** をオンにします。

パネルは開いたまま各ページで再マウントされ、位置はタブ間で同期されます。閉じる（または再度 <kbd>;</kbd>）と、次に開くまで非表示になります。歯車オプションをオフにすると一時的なモーダルに戻ります。

## リファレンス

### 既定の開きキー

| レイアウト | 典型的なキー |
| --- | --- |
| ブラウジング右手 | <kbd>;</kbd>（および <kbd>&#96;</kbd>） |
| ブラウジング左手 | <kbd>A</kbd> / <kbd>&#96;</kbd> |

### ランチャーとの比較

- **トップサイト** — Chrome のツールバー / よく訪れるサイト / 最近のブックマークへの素早いアクセスに加え、KeyPilot ツールタブ。
- **ランチャー** — より広いカテゴリに加え、編集可能な Launch Deck とフォーカス済み検索（<kbd>Alt</kbd>+<kbd>;</kbd>）。
