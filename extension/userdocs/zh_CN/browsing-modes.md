# 模式

KeyPilot 对需要持续输入的操作使用模态状态。模式激活时会暂停大多数浏览按键；<kbd>Esc</kbd> 几乎总能取消。

## 使用

1. **普通浏览**——快捷键可用；焦点矩形显示可点击目标。
2. **文本模式**——在文本字段上按 <kbd>F</kbd>。正常输入；完成后按 <kbd>Esc</kbd>（或键盘参考上的退出控件）。
3. **滚动线**——按 <kbd>B</kbd>；移离原点即可滚动；<kbd>B</kbd>、点击或 <kbd>Esc</kbd> 可退出。
4. **选择**——<kbd>H</kbd> 或 <kbd>Y</kbd>；<kbd>Esc</kbd> 取消。
5. **删除模式**——按 <kbd>Backspace</kbd>，指向元素并确认即可从页面移除；<kbd>Esc</kbd> 取消。
6. **弹出窗口 / 万能框 / 布局编辑器**——各自有打开状态；<kbd>Esc</kbd> 或工具关闭键可关闭。

若按键似乎“失效”，您可能处于文本模式或其他模态——按一次 <kbd>Esc</kbd> 后重试。

## 参考

### 文本模式详情

- 大多数布局浏览按键会暂停，确保输入安全。
- 短暂的悬停加 <kbd>F</kbd> 窗口仍可激活其他可点击目标，无需完全离开文本焦点（倒计时感知的激活）。
- 外观（T 形与十字准星、橙色边缘、标签）在**设置 → 文本模式**中配置。

### 删除模式

- 默认布局中使用 <kbd>Backspace</kbd> 进入。
- 您可直观地选择元素；确认后会从实时页面删除该 DOM 节点（仅限页面本地，不能通过浏览器历史记录撤销）。

### 其他模态界面

| 界面 | 常见打开方式 | 退出 |
| --- | --- | --- |
| 链接预览 | <kbd>E</kbd> | <kbd>Esc</kbd>、标题栏关闭或再次执行操作 |
| Reader Mode | <kbd>P</kbd> | <kbd>Esc</kbd> / 切换 <kbd>P</kbd> |
| 万能框 | <kbd>L</kbd> / <kbd>Alt</kbd>+<kbd>L</kbd> | <kbd>Esc</kbd> |
| 键盘布局编辑器 | <kbd>Alt</kbd>+<kbd>C</kbd> | <kbd>Alt</kbd>+<kbd>C</kbd> / 关闭 |
| 设置 / 文档 / 指南 | <kbd>'</kbd> / <kbd>Alt</kbd>+<kbd>H</kbd> / 指南入口 | <kbd>Esc</kbd> |

### 始终可用

即使文本模式暂停浏览按键，或扩展已关闭，<kbd>Alt</kbd>+<kbd>K</kbd> 仍可切换 KeyPilot。
