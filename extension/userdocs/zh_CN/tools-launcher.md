# 启动器

启动器是一个带有搜索、书签、历史记录和可编辑启动面板的分类网站浏览器。

## 使用

1. 按 <kbd>Alt</kbd>+<kbd>;</kbd> 或 <kbd>Alt</kbd>+<kbd>A</kbd>，打开启动器并聚焦搜索。
2. 输入以筛选，或浏览分类（启动面板、书签、最近、社交、新闻、效率、视频、娱乐、购物、AI、互联网档案、搜索等）。
3. 从网格或列表打开网站。
4. 按 <kbd>/</kbd> 再次聚焦搜索；使用 <kbd>←</kbd>/<kbd>→</kbd>/<kbd>↑</kbd>/<kbd>↓</kbd> 移动；<kbd>Esc</kbd> 关闭（或先退出编辑模式）。

要固定自己的快捷方式，请打开**启动面板**并使用编辑模式重新排序、移除或添加条目。

## 参考

### 打开方式

| 方法 | 说明 |
| --- | --- |
| <kbd>Alt</kbd>+<kbd>;</kbd> / <kbd>Alt</kbd>+<kbd>A</kbd> | Chrome 热键——搜索已聚焦 |
| 布局函数 | 可在布局编辑器中将启动器绑定到任意按键（右手浏览没有单独默认键） |

### 子视图

- 收藏夹 / 书签
- 历史记录

### 提示

- 对重复访问的目的地使用启动器；临时 URL 和查询使用万能框。
- 启动面板编辑会保存在您的个人资料中。
