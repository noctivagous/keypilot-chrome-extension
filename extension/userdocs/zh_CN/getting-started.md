# 快速入门

在任意页面按下最初几个按键；在熟悉布局前，请保持键盘参考处于打开状态。

## 使用

1. 使用 <kbd>Alt</kbd>+<kbd>K</kbd> **开启**或**关闭** KeyPilot。
2. 使用 <kbd>Alt</kbd>+<kbd>J</kbd> 切换控制栏。
3. 使用 <kbd>K</kbd> 切换**键盘参考**。
4. 从键盘参考的布局下拉菜单（KeyPilot → Onboarding Tutorial）打开**新手教程**，或按 <kbd>Alt</kbd>+<kbd>I</kbd> 显示演练。

### 首先练习的按键命令

| 目标 | 默认按键 |
| --- | --- |
| 点击 / 聚焦光标下方对象 | <kbd>F</kbd> |
| 后退 | <kbd>D</kbd> |
| 网站根目录 | <kbd>S</kbd> |
| 前进 | <kbd>R</kbd> |
| 向上 / 向下滚动 | <kbd>C</kbd> / <kbd>V</kbd> |
| 退出模式 / 取消 | <kbd>Esc</kbd> |
| 键盘参考 | <kbd>K</kbd> |
| 设置 | <kbd>'</kbd> — 打开[设置](kp://settings/overview)或跳转到[键盘](kp://settings/keyboard) |
| 切换 KeyPilot | <kbd>Alt</kbd>+<kbd>K</kbd> |
| 本文档 | <kbd>Alt</kbd>+<kbd>H</kbd> |

### 演练与练习

- **演练**是实际浏览操作的清单。进度存储在 Chrome 个人资料中，可从教程入口重置。
- **练习面板**会随文本框幻灯片出现，您可用 <kbd>F</kbd> 进入焦点、正常输入，并用 <kbd>Esc</kbd> 离开。

</section>
<section class="article-column">

### 其他入口

- 扩展**弹出窗口** → Tutorial
- **指南**弹出窗口 → Launch Walkthrough
- 键盘参考下拉菜单 → Onboarding Tutorial
- <kbd>Alt</kbd>+<kbd>I</kbd> 显示或隐藏演练，但不重置进度

</section>
</div>

### 如果没有任何反应

- 确认 KeyPilot 已启用（<kbd>Alt</kbd>+<kbd>K</kbd>）。
- 确认您不在 `chrome://` 页面或网上应用店中。
- 打开键盘参考，确认当前布局仍为您按下的键分配了操作。
