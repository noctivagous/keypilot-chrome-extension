# 键盘参考

浮动的键盘参考是当前布局的实时地图，也是学习和切换布局最快的方式。

## 使用

1. 按 <kbd>K</kbd>（右手）或 <kbd>D</kbd>（左手），也可通过控制栏、弹出窗口或新标签页切换。
2. 悬停在键帽上即可查看绑定的操作。
3. 使用**标题栏布局下拉菜单**切换内置系列或自定义布局、打开布局编辑器（编辑 / 新建 / 复制）、启动**新手教程**、打开**KeyPilot 文档/帮助**或**KeyPilot 设置**。
4. 拖动窗口；需要屏幕空间时可折叠；使用 × 或同一切换键关闭。
5. 当 KeyPilot 处于文本模式时，如果不想按 <kbd>Esc</kbd>，可使用参考窗口控件上的 <kbd>Exit</kbd>。

## 参考

### 显示内容

- 活动系列、惯用手设置和自定义分配
- 始终开启的系统按键
- 可选数字行（设置 → 键盘）
- 启用反馈时的已按按键高亮
- 悬停在链接上时操作按键的可选光晕（设置 → 点击模式）

### 编辑模式

当 <kbd>Alt</kbd>+<kbd>C</kbd> 键盘布局编辑器打开时，键盘参考会成为放置区域：在库中选择操作，然后点击键帽进行分配。

### 提示

- 学习时请在第二台显示器或屏幕角落保持打开。
- 如果按键没有反应，先检查此窗口；您可能处于导航系列或稀疏的自定义布局，而非 KeyPilot 出现故障。
