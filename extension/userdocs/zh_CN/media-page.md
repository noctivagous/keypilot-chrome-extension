# 页面媒体

页面媒体会扫描当前页面中的图片、视频、文本、文档、字体和 URL，让您无需手动检查页面即可浏览或保存它们。

## 使用

1. 在默认右手浏览布局中按 <kbd>O</kbd>。
2. 切换**图片**、**视频**、**文本**、**文档**、**字体**、**URL**标签。
3. 预览项目；在相关时调整图片缩放/纵横比。
4. 复制、下载、打开完整视图，或将项目发送至**媒体库**。
5. 使用 <kbd>Esc</kbd> 或叠加层关闭控件关闭。

需要页面中的全部内容时使用页面媒体；已经知道要获取哪个悬停资源时使用 <kbd>I</kbd> / <kbd>U</kbd>。

## 参考

### 默认按键

| 布局 | 按键 |
| --- | --- |
| 浏览右手 | <kbd>O</kbd> |

如有需要可通过布局编辑器重新绑定。

### 功能

- 图片缩放和纵横比控件；**文章优先**（默认开启）会将文章/主内容中的图片排在网站界面之前
- 字体标签（先显示自定义 `.woff2` / `.otf` / `.ttf`，然后是系统字体）
- URL 表格视图，或换行卡片网格列表视图（文章/主内容优先；网站页眉/页脚最后）
- 复制、发送至媒体库、下载
- 图片/视频完整视图

### 相关功能

- **媒体库**（<kbd>M</kbd>）——您保存的收藏
- **复制光标下内容**——单个悬停图片/URL
