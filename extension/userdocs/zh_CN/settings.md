# 设置

设置控制外观、滚动、搜索引擎、控制栏和使用的键盘系列。更改会在同一 Chrome 个人资料的标签页间同步。

## 使用

1. 按 <kbd>'</kbd>（引号），或从控制栏、弹出窗口、新标签页或键盘参考下拉菜单打开设置。
2. 在左侧导航中选择类别。
3. 调整控件——大多数会立即生效。
4. 完成后按 <kbd>Esc</kbd> 或标题栏关闭控件。

先从[**键盘**](kp://settings/keyboard)（布局 + 惯用手）和[**滚动**](kp://settings/scrolling)（向上翻页 / 向下翻页距离）开始。基础功能适用后，再微调[**点击模式**](kp://settings/click-mode)和[**文本模式**](kp://settings/text-mode)。

## 参考

### 类别

| 部分 | 可配置内容 |
| --- | --- |
| [**概览**](kp://settings/overview) | 链接至各类别的中心 |
| [**外观**](kp://settings/appearance) | 主题和视觉界面 |
| [**键盘**](kp://settings/keyboard) | 布局系列、左手模式、数字行、已按键反馈 |
| [**点击模式**](kp://settings/click-mode) | 光标样式、十字准星几何、焦点矩形、链接悬停提示、激活效果 |
| [**文本模式**](kp://settings/text-mode) | 光标、焦点样式（脉冲边缘 / 色调）、边缘宽度、标签、轮廓 |
| [**滚动**](kp://settings/scrolling) | 向上翻页 / 向下翻页距离、平滑或即时跳转、跳过轮播、中键滚动线 |
| [**光标**](kp://settings/cursor) | 不使用自定义光标或使用 KeyPilot 光标；启用时的点击模式十字准星几何 |
| [**控制栏**](kp://settings/control-strip) | 可见性和初始折叠；用 <kbd>Alt</kbd>+<kbd>J</kbd> 恢复 |
| [**搜索**](kp://settings/search) | 用于万能框 / 新标签页搜索的 Brave、Google 或 DuckDuckGo |
| [**关于**](kp://settings/about) | 此 Chrome 个人资料的存储和同步说明 |

### 相关界面

- 深度按键重映射位于**键盘布局编辑器**（<kbd>Alt</kbd>+<kbd>C</kbd>），不在设置中。参阅[键盘布局编辑器](kp://docs/layout-config)。
- 文档快捷键为 <kbd>Alt</kbd>+<kbd>H</kbd>；短版指南页面仍可从多个界面入口打开。
