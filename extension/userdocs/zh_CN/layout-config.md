# 键盘布局编辑器

布局编辑器用于创建自定义键位图：将函数放到按键上、创建布局并管理操作实例。

## 使用

1. 按 <kbd>Alt</kbd>+<kbd>C</kbd>，或从键盘参考下拉菜单选择**编辑键盘布局…**。
2. 键盘参考会成为放置区域；配置面板包含操作库和布局工具。
3. **创建或选择布局**——编辑内置布局会生成用户副本（内置布局保持只读）。
4. 查找操作（搜索库）、选中它，然后在键盘参考中**点击键帽**放置操作。
5. 按需替换或清除现有自定义槽位，并在要使用该布局浏览时将其设为当前布局。
6. 完成后再次按 <kbd>Alt</kbd>+<kbd>C</kbd> 或关闭面板。

下拉菜单还提供：**新建空白键盘布局**和**新建重复键盘布局**。

- 将自定义布局导入 / 导出为 JSON
- 切换正在编辑的布局与当前使用的布局

### 放置规则

- 自定义布局是**排他的**：仅已分配按键和始终开启的系统层会运行。
- 参数化函数会成为带保存设置的**操作实例**（标签、目标、脚本正文等）。
- 某些函数（例如输入字符）只能绑定到**修饰键组合**，而不能绑定到单独字母键，以便在输入时运行。

### 提示

- 放置时保持键盘参考可见；悬停键帽进行确认。
- 如果只想更改少数按键，请从浏览布局的副本开始。
- 参阅*函数与操作*和*执行 JS*以了解可放置内容。
