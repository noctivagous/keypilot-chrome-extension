# 万能框

万能框是带有历史记录和书签建议的页内地址/搜索框。

## 使用

1. 按 <kbd>L</kbd>（默认浏览布局）或 <kbd>Alt</kbd>+<kbd>L</kbd>。
2. 输入 URL 或搜索查询。
3. 使用 <kbd>↑</kbd>/<kbd>↓</kbd> 或指针选择建议。
4. 按 <kbd>Enter</kbd> 在当前标签页中导航；按 <kbd>Esc</kbd> 不导航并关闭。

非 URL 查询使用**设置 → 搜索**中的搜索引擎。

## 参考

### 行为

- 建议结合浏览器历史记录和书签。
- <kbd>Enter</kbd> 导航至**当前**标签页（它不是新标签页启动器）。
- 即使重新绑定或清除布局中的万能框按键，<kbd>Alt</kbd>+<kbd>L</kbd> 仍是界面热键。

### 相关功能

- **启动器**（<kbd>Alt</kbd>+<kbd>;</kbd> / <kbd>Alt</kbd>+<kbd>A</kbd>）用于分类网站和启动面板
- **常用网站**（<kbd>;</kbd>）用于工具栏 / 最常访问 / 最近书签
- 新标签页也使用相同的搜索引擎偏好嵌入搜索
