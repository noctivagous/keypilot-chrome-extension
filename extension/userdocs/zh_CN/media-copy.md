# 复制光标下内容

按一个键即可获取悬停的图片或 URL——复制到剪贴板、媒体库或两者。

## 使用

1. 悬停在图片或链接/URL 目标上，直到 KeyPilot 高亮它。
2. 按 <kbd>I</kbd> 复制悬停的**图片**。
3. 按 <kbd>U</kbd> 复制悬停的**URL**。
4. 若要使用媒体库而不是（或同时使用）剪贴板，请检查布局编辑器中的操作实例设置。

**复制视频**存在于操作库中，但没有默认内置按键；如需要，请在布局编辑器中绑定。

## 参考

### 默认按键（浏览，右手）

| 按键 | 操作 |
| --- | --- |
| <kbd>I</kbd> | 复制悬停图片 |
| <kbd>U</kbd> | 复制悬停 URL |

左手浏览默认将复制图片放在 <kbd>E</kbd>。

### 目标

许多复制函数支持：

- 剪贴板
- 媒体库
- 两者

配置操作实例，然后将该实例放置到按键上。

### 相关功能

- **页面媒体**（<kbd>O</kbd>）——浏览页面中找到的所有内容
- **媒体库**（<kbd>M</kbd>）——查看已保存内容
