# 函数与操作

函数是绑定到按键的构建块。**操作实例**是函数加上保存的参数值。

## 使用

1. 打开**键盘布局编辑器**（<kbd>Alt</kbd>+<kbd>C</kbd>）。
2. 浏览或搜索**操作库**（卡片或表格视图）。
3. 选择函数。若它有参数，请创建或编辑**操作实例**（请清楚命名）。
4. 点击键盘参考键帽以放置该实例。
5. 在普通页面按该键运行。

若以后要改变行为，请在配置中编辑实例参数——使用该实例的每个按键都会获得更改。

## 参考

### 概念

| 术语 | 含义 |
| --- | --- |
| **函数** | 可重用操作定义 |
| **操作实例** | 函数 + 保存的参数 |
| **按键操作** | 占用一个槽位的内容——函数/实例或宏 |
| **结果目标** | 剪贴板、弹出窗口、页面更改、媒体库等 |

### 重要函数

<h3 id="type-characters">输入字符</h3>

将保存的文本插入焦点字段。使用修饰键组合绑定，以便在输入时运行。每个片段创建一个操作实例。

<h3 id="open-urls">打开网址</h3>

在后台标签页中打开已保存的一组网站。每组网站创建一个动作实例，并在键盘布局编辑器的检查器中编辑网址列表。参见[标签页与历史记录](kp://docs/browsing-tabs#open-urls)。

<h3 id="open-bookmarks">打开书签</h3>

打开书签文件夹中前 30 个网站书签（包含子文件夹）。在动作实例上选择文件夹。参见[标签页与历史记录](kp://docs/browsing-tabs#open-bookmarks)。

<h3 id="font-info">字体信息</h3>

显示光标下样式文本的字体系列、大小、文件类型和下载 URL 的弹出窗口，并显示该文本运行的轮廓。

<h3 id="lookup-word">查词</h3>

使用 Free Dictionary API 获取光标下单词的定义。当路径可用时，可在操作实例中选择 Ask AI 来源。

<h3 id="translate">翻译</h3>

翻译高亮内容，或光标下的单词/句子/段落。目标可替换页面文本或打开弹出窗口。

<h3 id="send-text-to-ai">将选择内容发送至 AI</h3>

使用可配置指令发送选定文本。将结果路由到剪贴板、弹出窗口或两者。

<h3 id="get-text-at-cursor">获取光标下的文本 / 媒体</h3>

**获取光标下的文本**复制单词、句子、段落或超链接文本。**获取光标下的媒体**复制光标下的图片、视频或音频。**获取文本范围**是将当前高亮传给下一步的宏步骤。

<h3 id="show-popover">显示弹出窗口</h3>

在结果弹出窗口中显示前一步结果（或备用文本）的宏步骤。

<h3 id="poi">地图地点 (POI)</h3>

当光标下有地图图钉时：**地点网站**会在链接预览中打开地点页面；**地点地址**会复制街道地址（txt 或 vCard）。

<h3 id="media-library-functions">为媒体库添加 / 获取 URL</h3>

**添加 URL**保存悬停 href 而不下载。**获取 URL**将链接文件（PDF、音频、视频、图片）下载到媒体库。

<h3 id="execute-js">执行 JS</h3>

自定义脚本函数。完整绑定、回调和 AI 提示：[执行 JS](kp://docs/execute-js)。

<h3 id="keystrokes">宏按键（按键操作）</h3>

热键、连发、轮询、连续按键、合成鼠标和重映射——操作库中可实例化的按键函数。参阅[键盘布局编辑器](kp://docs/layout-config)。

### 库存与用户
