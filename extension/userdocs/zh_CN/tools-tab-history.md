# 标签页历史记录

标签页历史记录显示此标签页去过的位置，包括从分叉处离开时保留的备用分支。

## 使用

1. 按 <kbd>J</kbd>（默认右手浏览；左手为 <kbd>F</kbd>）。
2. 浏览水平栏：保留分支的历史记录和普通浏览器历史记录。
3. 分支徽章标记分叉处的备用后代。
4. 点击卡片导航至该处；按 <kbd>Esc</kbd> 关闭。

从同一文章或文档站点探索多条路径后，当仅靠后退不足以返回时使用它。

## 参考

### 栏

- 当前标签页的**保留分支**历史记录
- 用于传统后退栈上下文的**浏览器历史记录**栏

### 提示

- 卡片在当前标签页中导航。
- 使用 <kbd>Esc</kbd> 关闭不会改变页面。
- 如需将按键用于其他用途，请在布局编辑器中重新绑定或移除标签页历史记录。
