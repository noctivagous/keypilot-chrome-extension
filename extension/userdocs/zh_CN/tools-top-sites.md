# 常用网站

常用网站是用于工具栏书签、最常访问网站、最近书签和 KeyPilot 工具的紧凑面板。

## 使用

1. 按 <kbd>;</kbd>（默认右手浏览；左手通常使用 <kbd>A</kbd> / <kbd>&#96;</kbd>）。
2. 在面板中切换**工具栏**、**最常访问**、**最近书签**和**KeyPilot**（右侧边缘）标签。数字键 <kbd>1</kbd>–<kbd>4</kbd> 可跳转；<kbd>Tab</kbd> 循环切换。
3. 点击或激活网站卡片进行导航。面板足够高，可显示三行卡片而不裁剪。
4. 在**KeyPilot**标签中打开键盘参考、帮助 / 文档、新手教程、设置和控制栏。
5. 拖动标题栏移动面板；拖动边缘或角落调整大小。大小和位置会被记住。
6. 按 <kbd>Esc</kbd> 或标题栏关闭按钮关闭。

## 跨页面保持打开

默认情况下，常用网站是临时模态窗口（按 <kbd>Esc</kbd>、点击外部或离开页面时关闭）。

要像键盘参考一样在浏览时保持打开：

1. 打开标题栏的齿轮菜单（关闭按钮左侧）。
2. 开启**跨页面保持打开**。

面板会在每个页面重新挂载，并在标签页间同步位置。关闭它（或再次按 <kbd>;</kbd>）会隐藏它，直到重新打开；关闭齿轮选项即可恢复临时模态窗口。

## 参考

### 默认打开按键

| 布局 | 常用按键 |
| --- | --- |
| 浏览右手 | <kbd>;</kbd>（也可 <kbd>&#96;</kbd>） |
| 浏览左手 | <kbd>A</kbd> / <kbd>&#96;</kbd> |

### 与启动器比较

- **常用网站**——快速访问 Chrome 工具栏 / 最常访问 / 最近书签，另有 KeyPilot 工具标签。
- **启动器**——更多分类、可编辑启动面板和聚焦搜索（<kbd>Alt</kbd>+<kbd>;</kbd>）。
