# 选择

选择光标下的文本或 HTML 元素，然后复制或处理结果。

## 使用

### 文本选择

1. 将光标移到选择起点。
2. 按 <kbd>H</kbd> 开始逐字符选择文本。
3. 移到范围终点，再按 <kbd>H</kbd> 完成并复制。
4. 按 <kbd>Esc</kbd> 取消且不复制。

文本选择是从插入点到插入点（类似点击拖动），不是虚线矩形的裁剪。矩形是拖动引导：复制范围是文档顺序中起止插入点之间的所有内容。富文本或纯文本复制格式可在文本选择函数的操作实例中配置。

### 元素选择

1. 按 <kbd>Y</kbd> 开始选择相交 HTML 元素的矩形。
2. 在所需元素上拖动/调整矩形。
3. 按屏幕提示完成选择（或在已配置时使用累计选择模式）。
4. 按 <kbd>Esc</kbd> 取消。

默认粒度是文章功能单元：段落或标题、整个表格、整个图或图片、整个列表。段落内的链接会立即选中该段落。重叠使用每个元素的行框，而非单一边界框。

## 参考

### 默认按键（浏览，右手）

| 按键 | 操作 |
| --- | --- |
| <kbd>H</kbd> | 文本选择（开始 / 完成 + 复制） |
| <kbd>Y</kbd> | 矩形选择元素（或累计选择模式） |
| <kbd>Esc</kbd> | 取消选择模式 |

### <kbd>Y</kbd> 的模式

- **矩形**——选择行框与所绘矩形相交的文章功能单元（段落、表格、图、列表）。
- **累计选择**——逐个添加元素，并用 <kbd>Enter</kbd> 完成（在函数中配置）。

### 相关工具

- <kbd>I</kbd> / <kbd>U</kbd> 复制悬停的图片 / URL（参阅*复制光标下内容*）。
- <kbd>O</kbd> 打开页面媒体，查看页面中找到的所有内容。
- 剪贴板和媒体库目标可用于布局编辑器中的许多获取 / 复制函数。

## 单元选择（剪贴板）

从操作库的剪贴板部分放置**选择单词**、**选择句子**、**选择段落**或**选择图片**。它们选择 KeyPilot 光标下的对象而不复制。

1. 悬停在单词、句子、段落或图片上。
2. 按绑定键进行选择；再次在同一单元上按键可取消选择。
3. 使用**复制**（或剪切）将 KeyPilot 选择内容发送到剪贴板。
4. 按 <kbd>Esc</kbd> 清除选择。

每个函数都会在键盘参考的按键说明弹出窗口中显示“排他 / 累计”（按函数共享，而不是按键操作实例）。

- **排他**（默认）——按键替换当前选择。
- **累计**——添加或移除单元；不连续范围会保持高亮。

KeyPilot 绘制自己的高亮，因此间隔选择仍可见。这与 <kbd>H</kbd> / <kbd>Y</kbd> 拖动选择不同。
