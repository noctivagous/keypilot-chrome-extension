# 标签页与历史记录

无需操作浏览器界面按钮，即可在标签页和浏览器历史记录间移动。

## 使用

1. 按 <kbd>Q</kbd> / <kbd>W</kbd> 转到上一个 / 下一个标签页。
2. 按 <kbd>T</kbd> 新建标签页；按 <kbd>A</kbd> 关闭当前标签页。
3. 按 <kbd>D</kbd> 后退；按 <kbd>R</kbd> 前进。
4. 按 <kbd>S</kbd>（或 <kbd>1</kbd>）跳转到当前网站的根目录（协议 + 主机）。
5. 按 <kbd>J</kbd> 打开**标签页历史记录**——此标签页的保留分支历史记录栏（参阅*标签页历史记录*）。
6. 按 <kbd>.</kbd> 打开**标签页总览**。每个窗口是一张卡片，其中的标签页以列表显示。对标签页按键点击即可切换；对窗口标题栏按键点击只聚焦该窗口。左手浏览使用 <kbd>X</kbd>。

## 参考

### 默认按键（浏览，右手）

| 按键 | 操作 |
| --- | --- |
| <kbd>Q</kbd> | 上一个标签页 |
| <kbd>W</kbd> | 下一个标签页 |
| <kbd>T</kbd> | 新建标签页 |
| <kbd>A</kbd> | 关闭标签页 |
| <kbd>D</kbd> | 后退 |
| <kbd>R</kbd> | 前进 |
| <kbd>S</kbd> / <kbd>1</kbd> | 网站根目录 |
| <kbd>J</kbd> | 标签页历史记录弹出窗口 |
| <kbd>.</kbd> | 标签页总览（左手：<kbd>X</kbd>） |

### 提示

- 后退/前进遵循该标签页的普通浏览器历史记录。
- 当您从分叉处离开时，标签页历史记录会保留备用分支——在同一页面探索多条路径后很有用。
- 左手浏览布局会将这些按键簇镜像到键盘右侧。
- **打开网址** 在检查器中保存一组网站，按一次键即可在后台标签页中打开它们。
