# 滚动

使用固定步长、跳转或连续滚动线控制，滚动页面或光标下的嵌套滚动区域。

## 使用

1. 指向页面（或可滚动区域内部）。
2. 使用**向上翻页**和**向下翻页**按配置距离滚动。
3. 使用**滚动到顶部**跳至滚动目标顶部；使用**滚动到底部**跳至底部。
4. 如需连续控制，请使用**滚动线**：光标下会出现原点标记；将鼠标移离原点，距离越远滚动越快；再次使用**滚动线**、点击或按 <kbd>Esc</kbd> 退出。
5. 可在设置 → 滚动中启用**在空白页面区域中键点击**，无需滚动线按键即可启动滚动线。

在**设置 → 滚动**中调整步长和动画。

## 参考

### 函数

| 函数 | 作用 |
| --- | --- |
| **向上翻页** | 按配置的即时距离向上滚动 |
| **向下翻页** | 按配置的即时距离向下滚动 |
| **滚动到顶部** | 跳至滚动目标顶部 |
| **滚动到底部** | 跳至滚动目标底部 |
| **滚动线** | 切换基于原点的连续滚动 |

这些函数的默认按键取决于活动键盘布局。

### 重要设置

- 用于向上翻页 / 向下翻页的**滚动距离**
- 跳转的**平滑**或**即时**动画
- 在滚动线中**跳过宽幅轮播式滚动区域**
- 在空白页面区域**中键点击**以启动滚动线

### 滚动目标

KeyPilot 会滚动页面或光标下的嵌套滚动区域。若滚动线锁定了错误区域，请退出，重新放置指针后再次使用**滚动线**。
