# 布局与惯用手

**布局**是按键 → 操作的映射。KeyPilot 提供内置系列；您可切换惯用手或创建自定义布局。

## 使用

1. 打开**设置**（<kbd>'</kbd>）→ **键盘**，或使用**键盘参考**标题栏上的布局下拉菜单。
2. 选择一个**系列**：**浏览**——完整的点击、滚动、标签页和工具（默认）；**导航**——专注于点击 / 后退 / 前进的精简集合。
3. 若左手持鼠标，请启用**左手模式**——主要快捷键将移到键盘右侧。
4. 随时用 <kbd>Alt</kbd>+<kbd>[</kbd>（上一个）和 <kbd>Alt</kbd>+<kbd>]</kbd>（下一个）循环切换系列，惯用手设置不会变化。
5. 要深度自定义按键，请按 <kbd>Alt</kbd>+<kbd>C</kbd> 打开键盘布局编辑器。

切换后打开 <kbd>K</kbd>（键盘参考）——绘制的键盘始终与活动布局一致。

## 参考

### 内置系列

| 系列 | 用途 |
| --- | --- |
| 浏览 | 日常键盘优先浏览 |
| 导航 | 最小导航子集 |

惯用手与系列相互独立。旧版“Basic Navigation”ID 仍可从旧设置解析，但会在普通选择器中隐藏。

### 自定义布局

- 在布局编辑器中编辑内置布局会创建用户副本（例如“Browsing Copy 1”）。
- 自定义布局是**排他的**：只有已分配槽位和始终开启的系统层会响应。
- 可从布局编辑器导入/导出 JSON，以备份或分享布局。

### 相关设置

- 在键盘参考 / 编辑器中显示数字行
- 输入快捷键时的已按键反馈
- 当前布局 ID 和系列会保存在 Chrome 个人资料中
