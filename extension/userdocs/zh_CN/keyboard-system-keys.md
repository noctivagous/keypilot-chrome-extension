# 系统按键与 Alt 快捷键

某些按键始终属于 KeyPilot 界面。它们在内置和自定义布局中都可使用。

## 使用

### 始终开启的系统层

即使自定义布局没有分配它们，这些字符键仍有效：

1. 按 <kbd>Esc</kbd> 取消当前模式（文本模式、选择、滚动线和许多弹出窗口）。
2. 按 <kbd>K</kbd>（右手）或 <kbd>D</kbd>（左手）显示或隐藏**键盘参考**。
3. 按 <kbd>'</kbd>（引号）打开**设置**。

### Alt 界面热键

按住 <kbd>Alt</kbd> 并按：

| 组合键 | 操作 |
| --- | --- |
| <kbd>Alt</kbd>+<kbd>K</kbd> | 开启/关闭 KeyPilot（即使禁用时也有效） |
| <kbd>Alt</kbd>+<kbd>J</kbd> | 显示/隐藏控制栏（即使禁用时也有效） |
| <kbd>Alt</kbd>+<kbd>L</kbd> | 打开万能框 |
| <kbd>Alt</kbd>+<kbd>;</kbd> 或 <kbd>Alt</kbd>+<kbd>A</kbd> | 打开启动器并聚焦搜索 |
| <kbd>Alt</kbd>+<kbd>[</kbd> / <kbd>Alt</kbd>+<kbd>]</kbd> | 上一个 / 下一个布局系列 |
| <kbd>Alt</kbd>+<kbd>C</kbd> | 切换键盘布局编辑器 |
| <kbd>Alt</kbd>+<kbd>H</kbd> | 打开本文档 |
| <kbd>Alt</kbd>+<kbd>I</kbd> | 显示/隐藏新手演练 |

请先记住 <kbd>Alt</kbd>+<kbd>K</kbd>、<kbd>Esc</kbd>、<kbd>K</kbd>、<kbd>'</kbd> 和 <kbd>Alt</kbd>+<kbd>H</kbd>——它们能解锁其余功能。

## 参考

### 系统层与布局按键

- **系统层**——<kbd>Esc</kbd>、键盘参考、设置；与布局系列分开定义。
- **布局按键**——<kbd>F</kbd>、<kbd>D</kbd>、滚动、工具等；来自活动的内置或自定义布局。
- **Alt 界面**——在普通按键路由前处理；不显示为常规字母分配。

### 惯用手说明

在左手布局中，键盘参考移至 <kbd>D</kbd>，以免与镜像的激活按键簇冲突。设置仍为 <kbd>'</kbd>。

### 不用于日常操作

<kbd>Alt</kbd>+<kbd>D</kbd> 会切换开发者 Shadow DOM 调试 HUD。除非正在诊断渲染问题，否则请跳过它。
