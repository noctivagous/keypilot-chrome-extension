# 宏构建器

宏构建器是用户宏的步骤编辑器，可从键盘布局编辑器进入。

## 使用

1. 按 <kbd>Alt</kbd>+<kbd>C</kbd> 打开布局编辑器。
2. 打开**用户宏**。
3. **创建**一个宏并给它清晰的名称，或复制现有宏。
4. 添加步骤：从操作库选择函数；添加**逻辑**芯片（等待、门控、停止、运行宏）；添加**获取文本范围**以捕获当前选择供下一步使用；添加**显示弹出窗口**以显示前一步结果（或备用文本）；添加**执行 JS**以运行粘贴的脚本。
5. 重新排序或移除步骤；打开步骤以设置参数和可选延迟。
6. **保存**，然后从库 / 宏列表将宏放置到按键上。
7. 在普通页面测试；若流程应提前退出，请优化门控。

## 参考

### 逻辑芯片

| 芯片 | 作用 |
| --- | --- |
| **等待** | 在下一步前暂停 |
| **门控** | 测试前一结果；失败时跳过配置的后续步骤 |
| **停止** | 结束宏 |
| **运行宏** | 调用另一个宏（嵌套；受循环保护） |
| **执行 JS** | 运行粘贴的脚本；返回值会馈送给下一个门控 |
| **获取文本范围** | 捕获当前高亮/选择供下一步使用。不是按键操作（请使用复制）。 |
| **显示弹出窗口** | 在弹出窗口中显示前一个函数结果（或配置的备用文本）。不是按键操作。 |

### 门控测试

针对前一函数结果的常见比较：

- 有值 / 空
- 等于 / 不等于
- 大于 / 小于

失败的门控会按配置跳过步骤，因此无需完整脚本即可分支。

### 宏按键作为步骤

已配置的按键原语（热键、连发、轮询、连续、合成鼠标、普通重映射）既可作为宏函数步骤运行，也可作为独立按键操作。

### 提示

- 宏应保持简短，并按意图命名步骤。
- 当步骤可能没有结果时，请优先使用门控，而非冗长的无条件链。
- 执行 JS 返回值会通过 `kpPriorResult` 馈送给下一个门控（参阅*执行 JS*）。
