# 链接预览与弹出窗口

在不替换当前标签页的情况下，通过有尺寸的操作系统弹出窗口预览链接。

## 使用

### 链接预览（<kbd>E</kbd>）

1. 悬停在链接上，直至它高亮。
2. 按 <kbd>E</kbd> 在光标附近打开有尺寸的弹出窗口。
3. 从 KeyPilot 标题栏使用**在此标签页打开**或**在新标签页打开**。
4. 使用 <kbd>Esc</kbd>、标题栏关闭控件或再次按操作键关闭。

### 弹出窗口（<kbd>P</kbd>）

1. 悬停在链接上。
2. 按 <kbd>P</kbd> 打开更大的有尺寸弹出窗口。
3. 再按 <kbd>P</kbd> 或 <kbd>Esc</kbd> 关闭。

启动器卡片预览和类别搜索结果使用相同的弹出窗口。

## 参考

### 默认按键（浏览，右手）

| 按键 | 操作 |
| --- | --- |
| <kbd>E</kbd> | 链接预览弹出窗口 |
| <kbd>P</kbd> | 更大的打开弹出窗口 |

### 行为说明

- 预览始终以 Chrome/Brave 弹出窗口打开（不是页内 iframe）。
- 设置 / 指南 / 文档仍使用页内弹出窗口界面（标题栏，<kbd>Esc</kbd> 关闭）。
- 可在布局编辑器中自定义或重新绑定这些函数。
