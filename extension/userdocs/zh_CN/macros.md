# 宏

宏是绑定到单个按键的一组有序函数和逻辑步骤。

## 使用

1. 打开**键盘布局编辑器**（<kbd>Alt</kbd>+<kbd>C</kbd>）并进入**用户宏**（编辑请参阅*宏构建器*）。
2. 选择库存宏进行尝试，或创建自己的宏。
3. 像任何其他操作一样，将宏放置到键盘参考键帽上。
4. 在页面按该键——步骤会按顺序运行，门控决定是否继续。

库存示例包括 **AI Assist**、**Quick Nav** 和 **Clip & Search** 等流程。编辑库存宏会创建可自由自定义的用户副本。

## 参考

### 概念

- **步骤**——函数（包括执行 JS）和逻辑芯片
- **门控**——检查前一步结果；可跳过后续步骤
- **延迟**——步骤之间的可选等待
- **运行宏**——嵌套另一个宏（会防止循环）

### 库存宏

只读模板。保存/编辑会创建可自定义和自由放置的用户宏。

### 与单个函数比较

| 在以下情况使用函数 | 在以下情况使用宏 |
| --- | --- |
| 一个操作即可 | 需要流水线 |
| 参数保持简单 | 需要门控 / 等待 / 嵌套运行 |
