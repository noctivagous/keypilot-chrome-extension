# 控制栏

控制栏是一条始终可见的小栏，用于切换 KeyPilot、打开键盘参考和进入设置，无需触碰鼠标。

## 使用

1. 在页面上找到可拖动的控制栏。若它消失，按 <kbd>Alt</kbd>+<kbd>J</kbd> 恢复。
2. 可通过它开启/关闭 KeyPilot、打开键盘参考和设置，以及折叠 / 展开或关闭控制栏。
3. 通过移动手柄拖动，将其停靠到不碍事的位置。
4. 在**设置 → 控制栏**中选择初始可见或折叠。

即使 KeyPilot 已禁用，<kbd>Alt</kbd>+<kbd>J</kbd> 仍可恢复控制栏。

## 参考

### 控件

| 控件 | 作用 |
| --- | --- |
| 开/关 | 等同于 <kbd>Alt</kbd>+<kbd>K</kbd> |
| 键盘参考 | 等同于 <kbd>K</kbd> / <kbd>D</kbd> |
| 设置 | 等同于 <kbd>'</kbd> |
| 折叠 / 关闭 | 隐藏控制栏；用 <kbd>Alt</kbd>+<kbd>J</kbd> 恢复 |

### 外观

- 文本模式会将控制栏染成橙色，提示浏览按键已暂停。
- 可见性偏好会与您的个人资料同步。
