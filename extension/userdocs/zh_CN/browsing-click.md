# 点击与链接

用鼠标指向元素；按键即可激活其下方的对象。KeyPilot 会在光标下的可点击目标或文本字段上绘制焦点矩形。

## 使用

1. 将指针移到链接、按钮或文本字段上，直到出现焦点矩形。
2. 按 <kbd>F</kbd> 点击；或者聚焦文本字段并进入文本模式。
3. 按 <kbd>N</kbd> 在**新的前台标签页**中打开链接。
4. 按 <kbd>G</kbd> 在**后台标签页**中打开链接（类似中键点击）。
5. 按 <kbd>E</kbd> 快速查看弹出窗口。参阅*链接预览与弹出窗口*。要阅读本页正文，请按 <kbd>P</kbd>（Reader Mode）。

若高亮的元素不正确，请轻微移动鼠标——KeyPilot 优先选择光标下最内层的元素。

## 参考

### 默认按键（浏览，右手）

| 按键 | 操作 |
| --- | --- |
| <kbd>F</kbd> | 点击 / 激活光标下对象；聚焦文本字段 |
| <kbd>N</kbd> | 在新标签页中打开链接（前台） |
| <kbd>G</kbd> | 在新标签页中打开链接（后台） |
| <kbd>E</kbd> | 链接预览弹出窗口 |
| <kbd>P</kbd> | Reader Mode |

### 视觉反馈

- 焦点矩形标记可点击目标和文本字段。
- 可在**设置 → 点击模式**调整颜色和光晕。
- 点击时可播放可选的激活效果（闪烁、虚线、跑马灯、缩放）。

### 文本字段

在文本字段上按 <kbd>F</kbd> 会聚焦它并暂停大多数浏览按键，方便您输入。按 <kbd>Esc</kbd> 离开文本模式。参阅*模式*。
