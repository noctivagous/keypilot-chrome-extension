# 媒体库

媒体库是您在浏览时收集的已保存图片、视频、文档和 URL 的个人图库。

## 使用

1. 按 <kbd>M</kbd>（默认右手浏览）。
2. 按**图片**、**视频**、**文档**、**URL**和域浏览。
3. 打开项目或查看完整视图；选择范围以进行批量操作。
4. 将类别或选择内容下载为 ZIP；删除不再需要的内容。
5. 使用 <kbd>Esc</kbd> 或叠加层关闭控件关闭。

可从页面媒体、复制光标下函数或其他将媒体库列为目标的操作添加项目。

## 参考

### 默认按键

| 布局 | 按键 |
| --- | --- |
| 浏览右手 | <kbd>M</kbd> |

### 类别

- 图片、视频、文档、URL（以及域分组）
- 对悬停的文件链接使用**为媒体库获取 URL**，或从页面媒体发送

### 提示

- 需要长期保存时使用媒体库；一次性粘贴请使用剪贴板目标。
