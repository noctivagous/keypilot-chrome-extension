# Caja omnidireccional

Omnibox es un cuadro de búsqueda/dirección en la página con historial y sugerencias de marcadores.

## Úselo

![Omnibox](images/omnibox.png)

1. Presione <kbd>L</kbd> (navegación predeterminada) o <kbd>Alt</kbd>+<kbd>L</kbd>.
2. Escriba una URL o una consulta de búsqueda.
3. Utilice <kbd> ↑</kbd>/<kbd>↓</kbd> o el puntero para elegir una sugerencia.
4. Presione <kbd>Ingrese</kbd> para navegar por la pestaña actual.
5. Presione <kbd>Esc</kbd> para cerrar sin navegar.

Las consultas que no son URL utilizan el motor de búsqueda desde **Configuración → Buscar**.

## Referencia

### Comportamiento

- Las sugerencias combinan el historial del navegador y los marcadores.
- <kbd>Enter</kbd> navega por la pestaña **actual** (no es un iniciador de pestañas nuevas).
- <kbd>Alt</kbd>+<kbd>L</kbd> funciona como una tecla de acceso rápido de Chrome incluso cuando vuelves a vincular o borras la tecla Omnibox del diseño.

### Relacionado

- **Lanzador** (<kbd>Alt</kbd>+<kbd>;</kbd> / <kbd>Alt</kbd>+<kbd>A</kbd>) para sitios categorizados y plataforma de lanzamiento
- **Sitios principales** (<kbd>;</kbd>) para la barra de herramientas/marcadores más visitados/recientes
- La página Nueva pestaña también incorpora búsqueda con la misma preferencia de motor
