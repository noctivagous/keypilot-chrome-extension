# Teclas del sistema y Alt Chrome

Algunas claves siempre pertenecen a KeyPilot Chrome. Permanecen disponibles en diseños integrados y personalizados.

## Úselo

### Capa del sistema siempre activa

Estas teclas de caracteres funcionan incluso cuando su diseño personalizado las deja vacías:

1. Presione <kbd>Esc</kbd> para cancelar el modo actual (modo de texto, selección, línea de desplazamiento, muchas ventanas emergentes).
2. Presione <kbd>K</kbd> (diestro) o <kbd>D</kbd> (zurdo) para mostrar u ocultar la **Referencia de teclado**.
3. Presione <kbd>'</kbd> (cita) para abrir **Configuración**.

### Teclas de acceso rápido alternativas de Chrome

Mantenga presionado <kbd>Alt</kbd> y presione:

| Acorde | Acción |
| --- | --- |
| <kbd>Alt</kbd>+<kbd>K</kbd> | Activar/desactivar KeyPilot (funciona incluso cuando está desactivado) |
| <kbd>Alt</kbd>+<kbd>J</kbd> | Mostrar/ocultar tira de control (funciona incluso cuando está desactivada) |
| <kbd>Alt</kbd>+<kbd>L</kbd> | Abrir cuadro multifunción |
| <kbd>Alt</kbd>+<kbd>;</kbd> o <kbd>Alt</kbd>+<kbd>A</kbd> | Lanzador abierto con búsqueda centrada |
| <kbd>Alt</kbd>+<kbd>[</kbd> / <kbd>Alt</kbd>+<kbd>]</kbd> | Familia de diseño anterior/siguiente |
| <kbd>Alt</kbd>+<kbd>C</kbd> | Alternar editor de distribución de teclado |
| <kbd>Alt</kbd>+<kbd>H</kbd> | Abrir esta documentación |
| <kbd>Alt</kbd>+<kbd>I</kbd> | Mostrar/ocultar el tutorial de incorporación |

Memorizar <kbd>Alt</kbd>+<kbd>K</kbd>, <kbd>Esc</kbd>, <kbd>K</kbd>, <kbd>'</kbd> y <kbd>Alt</kbd>+<kbd>H</kbd> primero: desbloquean todo lo demás.

## Referencia

### Capa del sistema versus claves de diseño

- **Capa del sistema** — <kbd>Esc</kbd>, Referencia del teclado, Configuración. Definido por separado de las familias de diseño.
- **Teclas de diseño**: <kbd>F</kbd>, <kbd>D</kbd>, desplazamiento, herramientas, etc. Provienen del diseño activo integrado o personalizado.
- **Alt chrome**: manejado antes del enrutamiento normal de claves; no se muestran como asignaciones de letras ordinarias.

### nota de lateralidad

En diseños para zurdos, la Referencia del teclado se mueve a <kbd>D</kbd> para que no choque con el clúster Activar reflejado. La configuración sigue siendo <kbd>'</kbd>.

### No para uso diario

<kbd>Alt</kbd>+<kbd>D</kbd> toggles a developer shadow-root debug HUD. Skip it unless you are diagnosing rendering.
