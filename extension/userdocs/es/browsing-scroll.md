# Desplazamiento

Desplácese por la página o controles de desplazamiento anidados debajo del cursor con pasos fijos, saltos o control continuo de la línea de desplazamiento.

## Úselo

1. Apunte a la página (o dentro de una región desplazable).
2. Use **Página arriba** y **Página abajo** para desplazarse según la distancia configurada.
3. Use **Desplazarse hacia arriba** para saltar a la parte superior del objetivo de desplazamiento; **Desplazarse hacia abajo** para la parte inferior.
4. Para control continuo, use **Línea de desplazamiento**:
   - Aparece una marca de origen debajo del cursor.
   - Aleje el mouse del origen; más lejos significa un desplazamiento más rápido.
   - Use **Línea de desplazamiento** nuevamente, haga clic o presione <kbd>Esc</kbd> para salir.
5. Opcionalmente, habilite **clic central en el área de la página vacía** en Configuración → Desplazamiento para iniciar la línea de desplazamiento sin la tecla de Línea de desplazamiento.

Ajuste el tamaño del paso y la animación en **Configuración → Desplazamiento**.

## Referencia

### Funciones

| Función | Qué hace |
| --- | --- |
| **Página arriba** | Desplazarse hacia arriba la distancia instantánea configurada |
| **Página abajo** | Desplazarse hacia abajo la distancia instantánea configurada |
| **Desplazarse hacia arriba** | Saltar a la parte superior del objetivo de desplazamiento |
| **Desplazarse hacia abajo** | Saltar al final del objetivo de desplazamiento |
| **Línea de desplazamiento** | Alternar el desplazamiento continuo basado en origen |

Las teclas predeterminadas de estas Funciones dependen de la distribución de teclado activa.

### Configuraciones que importan

- **Distancia de desplazamiento** para Página arriba / Página abajo
- **Animación suave versus instantánea** para saltos
- **Omitir desplazamientos anchos tipo carrusel** en la línea de desplazamiento
- **Haga clic con el botón central** para iniciar la línea de desplazamiento en un área de página vacía

### Objetivo de desplazamiento

KeyPilot desplaza la página o el cursor anidado debajo del cursor. Si la línea de desplazamiento se bloquea en la región incorrecta, salga y reposicione el puntero, luego use **Línea de desplazamiento** nuevamente.
