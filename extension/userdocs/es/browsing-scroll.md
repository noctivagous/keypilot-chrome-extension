# Desplazamiento

Desplácese por la página o controles de desplazamiento anidados debajo del cursor con pasos fijos, saltos o control continuo de la línea de desplazamiento.

## Úselo

1. Apunte a la página (o dentro de una región desplazable).
2. Presione <kbd>C</kbd> para desplazarse hacia arriba y <kbd>V</kbd> para desplazarse hacia abajo según la distancia configurada.
3. Presione <kbd>Z</kbd> para saltar a la parte superior del objetivo de desplazamiento; <kbd>X</kbd> para la parte inferior.
4. Para control continuo, presione <kbd>N</kbd> para iniciar **Línea de desplazamiento**:
   - Aparece una marca de origen debajo del cursor.
   - Aleje el mouse del origen; más lejos significa un desplazamiento más rápido.
   - Presione <kbd>N</kbd> nuevamente, haga clic o presione <kbd>Esc</kbd> para salir.
5. Opcionalmente, habilite **clic central en el área de la página vacía** en Configuración → Desplazamiento para iniciar la línea de desplazamiento sin <kbd>N</kbd>.

Ajuste el tamaño del paso y la animación en **Configuración → Desplazamiento**.

## Referencia

### Teclas predeterminadas (navegación, diestros)

| Clave | Acción |
| --- | --- |
| <kbd>C</kbd> | Desplazarse hacia arriba (distancia instantánea) |
| <kbd>V</kbd> | Desplazarse hacia abajo (distancia instantánea) |
| <kbd>Z</kbd> | Saltar a la parte superior del objetivo de desplazamiento |
| <kbd>X</kbd> | Saltar al final del objetivo de desplazamiento |
| <kbd>N</kbd> | Alternar modo de línea de desplazamiento |

### Configuraciones que importan

- **Distancia de desplazamiento** para <kbd>C</kbd> / <kbd>V</kbd>
- **Animación suave versus instantánea** para saltos
- **Omitir desplazamientos anchos tipo carrusel** en la línea de desplazamiento
- **Haga clic con el botón central** para iniciar la línea de desplazamiento en un área de página vacía

### Objetivo de desplazamiento

KeyPilot desplaza la página o el cursor anidado debajo del cursor. Si la línea de desplazamiento se bloquea en la región incorrecta, salga y reposicione el puntero, luego presione <kbd>N</kbd> nuevamente.
