# Tira de control

La Control Strip es una pequeña barra siempre visible para alternar KeyPilot, abrir la Referencia del teclado y acceder a Configuración, sin tocar el mouse.

## Úselo

1. Encuentra la tira en la página (arrastrable). Si desapareció, presione <kbd>Alt</kbd>+<kbd>J</kbd> para restaurarlo.
2. Úselo para:
   - Encienda KeyPilot **Encendido/Apagado**
   - Abrir **Referencia de teclado**
   - Abrir **Configuración**
   - Contraer/expandir o cerrar la tira
3. Arrastre mediante el controlador de movimiento para estacionarlo fuera del camino.
4. En **Configuración → Tira de control**, elige si comienza visible o contraído.

<kbd>Alt</kbd>+<kbd>J</kbd> restores the strip even when KeyPilot is disabled.

## Referencia

### Controles

| Controlar | Rol |
| --- | --- |
| Encendido/Apagado | Equivalente a <kbd>Alt</kbd>+<kbd>K</kbd> |
| Referencia del teclado | Equivalente a <kbd>K</kbd> / <kbd>D</kbd> |
| Configuración | Equivalente a <kbd>'</kbd> |
| Contraer / Cerrar | Esconde la tira; restaurar con <kbd>Alt</kbd>+<kbd>J</kbd> |

### Apariencia

- El modo de texto tiñe la franja de color naranja para que puedas ver por qué las teclas de navegación están suspendidas.
- Las preferencias de visibilidad se sincronizan con su perfil.
