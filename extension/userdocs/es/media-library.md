# Biblioteca multimedia

La biblioteca multimedia es su galería personal de imágenes, vídeos, documentos y URL guardados recopilados mientras navega.

## Úselo

1. Presione <kbd>M</kbd> (navegación predeterminada para diestros).
2. Busque por **Imágenes**, **Vídeos**, **Documentos**, **URL** y dominios.
3. Abrir o ver completamente un elemento; seleccione rangos para acciones masivas.
4. Descargue una categoría o selección como ZIP; elimina lo que ya no necesitas.
5. Cierre con <kbd>Esc</kbd> o el control de cierre superpuesto.

Agregue elementos de medios de página, funciones de copiar debajo del cursor u otras acciones que incluyan la biblioteca multimedia como destino.

## Referencia

### Clave predeterminada

| Diseño | Clave |
| --- | --- |
| Navegando diestros | <kbd>M</kbd> |

### Categorías

- Imágenes, vídeos, documentos, URL (y agrupaciones de dominios)
- Utilice **Obtener URL para la biblioteca multimedia** en un enlace de archivo suspendido o Enviar desde Page Media

### Consejos

- Prefiere la biblioteca multimedia para guardar cosas duraderas; utilice destinos del portapapeles para pegados únicos.
