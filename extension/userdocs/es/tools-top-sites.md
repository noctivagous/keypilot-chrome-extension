# Sitios principales

Top Sites es un panel compacto para los marcadores de la barra de herramientas, los sitios más visitados, los marcadores recientes y las herramientas KeyPilot.

## Úselo

1. Presione <kbd>;</kbd> (navegación predeterminada para diestros; los zurdos a menudo usan <kbd>A</kbd> / <kbd>`</kbd>).
2. Cambie de pestaña dentro del panel: **Barra de herramientas**, **Más visitados**, **Marcadores recientes** y **KeyPilot** (borde derecho). Teclas numéricas <kbd>1</kbd>–<kbd>4</kbd> saltan a una pestaña; <kbd>Tab</kbd> los cicla.
3. Haga clic o active una tarjeta del sitio para navegar. El panel es lo suficientemente alto para tres filas de tarjetas sin recortes.
4. Abra la pestaña **KeyPilot** para ver las mismas tarjetas de herramientas que la ventana emergente de extensión: Referencia del teclado, Ayuda/Documentos, Tutorial de incorporación, Configuración y Tira de control.
5. Arrastre la barra de título **Sitios principales** para mover el panel; arrastre un borde o una esquina para cambiar su tamaño. Se recuerdan el tamaño y la posición.
6. Presione <kbd>Esc</kbd> o el botón de cierre de la barra de título para cerrar.

## Manténgalo abierto en todas las páginas

De forma predeterminada, Top Sites es un modal transitorio (se cierra cuando presiona <kbd>Esc</kbd>, hace clic fuera o sale de la página).

Para mantenerlo disponible mientras navega, como Referencia del teclado:

1. Abra el menú de ajustes en la barra de título (a la izquierda de cerrar).
2. Activa **Mantener abierto en todas las páginas**.

Luego, el panel se vuelve a montar en cada página mientras lo deja abierto, y su posición permanece sincronizada en todas las pestañas. Ciérrelo (o presione <kbd>;</kbd> nuevamente) para ocultarlo hasta que lo vuelva a abrir. Desactive la opción de marcha para volver a un modo transitorio.

## Referencia

### Teclas abiertas predeterminadas

| Diseño | Clave típica |
| --- | --- |
| Navegando diestros | <kbd>;</kbd> (también <kbd>`</kbd>) |
| Navegando para zurdos | <kbd>A</kbd> / <kbd>`</kbd> |

### Comparado con el lanzador

- **Sitios principales**: acceso rápido a la barra de herramientas de Chrome/los marcadores más visitados/recientes, además de una pestaña de herramientas de KeyPilot.
- **Lanzador**: categorías más amplias, plataforma de lanzamiento editable y búsqueda enfocada (<kbd>Alt</kbd>+<kbd>;</kbd>).
