# Lanzador

Launcher es un navegador de sitios categorizado con búsqueda, marcadores, historial y una plataforma de lanzamiento editable.

## Úselo

![Launcher](images/launcher.png)

1. Presione <kbd>Alt</kbd>+<kbd>;</kbd> o <kbd>Alt</kbd>+<kbd>A</kbd> para abrir el Lanzador con enfoque de búsqueda.
2. Escriba para filtrar o explorar categorías (Plataforma de lanzamiento, Marcadores, Recientes, Social, Noticias, Productividad, Videos, Entretenimiento, Compras, IA, Archivo de Internet, Búsquedas y más).
3. Abra un sitio de la cuadrícula o lista.
4. Presione <kbd>/</kbd> para enfocar la búsqueda nuevamente; use <kbd>←</kbd>/<kbd>→</kbd>/<kbd> ↑</kbd>/<kbd>↓</kbd> para moverse; <kbd>Esc</kbd> se cierra (o sale primero del modo de edición).

Para fijar sus propios accesos directos, abra **Launch Deck** y use el modo de edición para reordenar, eliminar o agregar entradas.

## Referencia

### Apertura

| Método | Notas |
| --- | --- |
| <kbd>Alt</kbd>+<kbd>;</kbd> / <kbd>Alt</kbd>+<kbd>A</kbd> | Tecla de acceso rápido de Chrome: búsqueda centrada |
| Función de diseño | El iniciador se puede vincular a cualquier tecla en el Editor de diseño (no es un valor predeterminado en la navegación diestro) |

### Subvistas

- Plataforma de lanzamiento/categorías del sitio
- Favoritos/marcadores
- Historia
- Buscar

### Consejos

- Prefiere Launcher para los destinos que vuelvas a visitar; prefiera Omnibox para consultas y URL ad hoc.
- Las ediciones de Launch Deck persisten en su perfil.
