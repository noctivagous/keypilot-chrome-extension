# Empezando

Presione las primeras teclas en cualquier página; mantenga abierta la Referencia del teclado hasta que el diseño sea natural.

## Úselo

1. Active y desactive KeyPilot con <kbd>Alt</kbd>+<kbd>K</kbd>.
2. Cambie la tira de control con <kbd>Alt</kbd>+<kbd>J</kbd>.
3. Alternar **Referencia de teclado** con <kbd>K</kbd>.
4. Abra el **Tutorial de incorporación** desde el menú desplegable de diseño de Referencia del teclado (KeyPilot → Tutorial de incorporación), o presione <kbd>Alt</kbd>+<kbd>I</kbd> para mostrar el tutorial.

### Primeros comandos clave para practicar

| Gol | Clave predeterminada |
| --- | --- |
| Haga clic / enfoque debajo del cursor | <kbd>F</kbd> |
| Atrás | <kbd>D</kbd> |
| Raíz del sitio | <kbd>S</kbd> |
| Adelante | <kbd>R</kbd> |
| Desplazarse hacia arriba/abajo | <kbd>C</kbd> / <kbd>V</kbd> |
| Salir del modo/cancelar | <kbd>Esc</kbd> |
| Referencia del teclado | <kbd>K</kbd> |
| Configuración | <kbd>'</kbd> — abre [Configuración](kp://settings/overview) o salta a [Teclado](kp://settings/keyboard) |
| Alternar piloto clave | <kbd>Alt</kbd>+<kbd>K</kbd> |
| Esta documentación | <kbd>Alt</kbd>+<kbd>H</kbd> |

### Tutorial versus práctica

- El **tutorial** es una lista de verificación de acciones de navegación reales. El progreso se almacena en su perfil de Chrome y se puede restablecer desde los puntos de entrada del tutorial.
- El **panel de práctica** aparece con el cuadro de texto deslizante para que pueda ingresar el foco con <kbd>F</kbd>, escribir normalmente y salir con <kbd>Esc</kbd>.

</section>
<section class="article-column">

### Otros puntos de entrada

- Extensión **ventana emergente** → Tutorial
- **Guía** ventana emergente → Tutorial de inicio
- Menú desplegable de referencia de teclado → Tutorial de incorporación
- <kbd>Alt</kbd>+<kbd>I</kbd> muestra u oculta el recorrido sin restablecer el progreso

</section>

### si no pasa nada

- Confirme que KeyPilot esté habilitado (<kbd>Alt</kbd>+<kbd>K</kbd>).
- Confirme que no está en `chrome://` ni en la Tienda web.
- Abra Referencia del teclado y verifique que su diseño aún asigne la tecla que presionó.
