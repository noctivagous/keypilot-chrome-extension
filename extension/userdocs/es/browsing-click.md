# Hacer clic y enlaces

Apunte a los elementos con el mouse; Pulsa una tecla para activar lo que hay debajo. KeyPilot dibuja un rectángulo de enfoque en el objetivo en el que se puede hacer clic o en el campo de texto debajo del cursor.

## Úselo

1. Mueva el puntero sobre un enlace, botón o campo de texto hasta que aparezca el rectángulo de enfoque.
2. Presione <kbd>F</kbd> para hacer clic o para enfocar un campo de texto e ingresar al modo de texto.
3. Para abrir el enlace en una **nueva pestaña de primer plano**, presione <kbd>N</kbd>.
4. Para abrirlo en una **pestaña de fondo** (como un clic central), presione <kbd>G</kbd>.
5. Para echar un vistazo rápido a una ventana emergente, presione <kbd>E</kbd> (Vista previa del enlace) o <kbd>P</kbd> (Vista emergente más grande). Consulte *Vista previa del enlace y ventana emergente*.

Si se resalta el elemento incorrecto, mueva ligeramente el mouse; KeyPilot prefiere la hoja debajo del cursor.

## Referencia

### Teclas predeterminadas (navegación, diestros)

| Clave | Acción |
| --- | --- |
| <kbd>F</kbd> | Haga clic / active debajo del cursor; campos de texto de enfoque |
| <kbd>N</kbd> | Abrir enlace en una pestaña nueva (primer plano) |
| <kbd>G</kbd> | Abrir enlace en una pestaña nueva (fondo) |
| <kbd>E</kbd> | Ventana emergente de vista previa del enlace |
| <kbd>P</kbd> | Abrir enlace en ventana emergente Popover |

### Comentarios visuales

- Los rectángulos de enfoque marcan objetivos y campos de texto en los que se puede hacer clic.
- Los colores y el brillo se pueden ajustar en **Configuración → Modo de clic**.
- Los efectos de activación opcionales (Flash, Dash, Marquee, Scale) se reproducen al hacer clic.

### Campos de texto

Al presionar <kbd>F</kbd> en un campo de texto, se enfoca y suspende la mayoría de las teclas de navegación para que pueda escribir. Presione <kbd>Esc</kbd> para salir del modo de texto. Ver *Modos*.
