# Historial de pestañas

El Historial de pestañas muestra dónde ha estado esta pestaña, incluidas las ramas alternativas cuando te alejaste de una bifurcación.

## Úselo

1. Presione <kbd>J</kbd> (navegación predeterminada para diestros; <kbd>F</kbd> para zurdos).
2. Explore los rieles horizontales: historial de retención de ramas e historial normal del navegador.
3. Las insignias de rama marcan descendientes alternativos de una bifurcación.
4. Haga clic en una tarjeta para navegar hasta allí.
5. Presione <kbd>Esc</kbd> para cerrar.

Úselo después de explorar varias rutas desde el mismo artículo o sitio de documentos cuando Atrás por sí solo no sea suficiente.

## Referencia

### Rieles

- **Historial de retención de sucursales** para la pestaña actual
- **Historial del navegador** carril para el contexto back-stack convencional

### Consejos

- Las tarjetas navegan por la pestaña actual.
- Cerrar con <kbd>Esc</kbd> no cambia la página.
- Vuelva a vincular o elimine el Historial de pestañas en el Editor de diseño si necesita la clave para otra cosa.
