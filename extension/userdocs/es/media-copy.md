# Copiar debajo del cursor

Tome la imagen o URL sobre la que se encuentra con una sola tecla: al portapapeles, a la biblioteca multimedia o a ambos.

## Úselo

1. Pase el cursor sobre una imagen o un enlace/URL de destino hasta que KeyPilot lo resalte.
2. Presione <kbd>I</kbd> para copiar la **imagen** suspendida.
3. Presione <kbd>U</kbd> para copiar la **URL** suspendida.
4. Verifique la configuración de Instancia de acción en el Editor de diseño si desea una Biblioteca multimedia en lugar de (o además de) el portapapeles.

**Copiar vídeo** existe en la Biblioteca de acciones, pero no tiene una clave incorporada predeterminada; vincúlala en el Editor de diseño si la necesitas.

## Referencia

### Teclas predeterminadas (navegación, diestros)

| Clave | Acción |
| --- | --- |
| <kbd>I</kbd> | Copiar imagen flotante |
| <kbd>U</kbd> | Copiar URL flotante |

La navegación para zurdos coloca la copia de la imagen en <kbd>E</kbd> de forma predeterminada.

### Destinos

Muchas funciones de copia admiten:

- portapapeles
- Biblioteca multimedia
- ambos

Configure la instancia de acción y luego coloque esa instancia en una clave.

### Relacionado

- **Page Media** (<kbd>O</kbd>): explora todo lo que se encuentra en la página
- **Biblioteca multimedia** (<kbd>M</kbd>): revisa lo que guardaste
