# Diseños y destreza

Un **diseño** es el mapa de claves → acciones. KeyPilot envía familias integradas; puede cambiar la lateralidad o crear diseños personalizados.

## Úselo

1. Abra **Configuración** (<kbd>'</kbd>) → **Teclado**, o use el menú desplegable de diseño en la barra de título **Referencia de teclado**.
2. Elige una **familia**:
   - **Navegación**: clic completo, desplazamiento, pestañas, herramientas (predeterminado).
   - **Navegación**: conjunto reducido centrado en hacer clic/atrás/adelante.
3. Habilite **zurdos** si mantiene el mouse en la mano izquierda: los atajos principales se mueven al lado derecho del teclado.
4. Ciclo de familias en cualquier momento con <kbd>Alt</kbd>+<kbd>[</kbd> (anterior) y <kbd>Alt</kbd>+<kbd>]</kbd> (siguiente) sin cambiar de lateralidad.
5. Para personalizar profundamente las teclas, presione <kbd>Alt</kbd>+<kbd>C</kbd> para el Editor de distribución del teclado (consulte ese tema).

Abra <kbd>K</kbd> (Referencia de teclado) después de cambiar: el teclado dibujado siempre coincide con el diseño activo.

## Referencia

### familias integradas

| Familia | Intención |
| --- | --- |
| Navegando | Navegación diaria con el teclado primero |
| Navegación | Subconjunto de navegación mínimo |

La lateralidad es independiente de la familia. Los identificadores heredados de “Navegación básica” aún pueden resolverse desde configuraciones anteriores, pero están ocultos para los selectores normales.

### Diseños personalizados

- La edición de un elemento integrado en el Editor de diseño crea una copia de usuario (por ejemplo, “Copia de navegación 1”).
- Los diseños personalizados son **exclusivos**: solo se activan las ranuras asignadas más la capa del sistema siempre activa.
- Importe/exporte JSON desde el Editor de diseño para realizar copias de seguridad o compartir diseños.

### Configuraciones relacionadas

- Mostrar fila numérica en el editor/referencia del teclado
- Comentarios de teclas presionadas mientras escribe atajos
- La identificación y la familia del diseño actual persisten en su perfil de Chrome
