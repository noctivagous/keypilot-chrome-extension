# Medios de página

Page Media escanea la página actual en busca de imágenes, videos, texto, documentos, fuentes y URL para que pueda explorarlos o guardarlos sin inspeccionar la página manualmente.

## Úselo

1. Presione <kbd>O</kbd> en el diseño predeterminado de navegación para diestros.
2. Cambiar de pestaña: **Imagen**, **Video**, **Texto**, **Documentos**, **Fuentes**, **URL**.
3. Vista previa de elementos; ajuste la escala/aspecto de la imagen cuando sea relevante.
4. Copie, descargue, abra la vista completa o envíe elementos a la **Biblioteca multimedia**.
5. Cierre con <kbd>Esc</kbd> o el control de cierre superpuesto.

Utilice Page Media cuando desee tener todo en la página; use <kbd>I</kbd> / <kbd>U</kbd> cuando ya sepa qué activo flotante tomar.

## Referencia

### Clave predeterminada

| Diseño | Clave |
| --- | --- |
| Navegando diestros | <kbd>O</kbd> |

Vuelva a vincular a través del Editor de diseño si es necesario.

### Capacidades

- Controles de aspecto y escala de imagen; **Artículo primero** (activado de forma predeterminada) clasifica las imágenes en artículos/principal antes que el sitio en Chrome
- Pestaña Fuentes (personalizado `.woff2` / `.otf` / `.ttf` primero, luego fuentes del sistema)
- Vista de tabla de URL o vista de lista como una cuadrícula de tarjeta envolvente (artículo/principal primero; encabezado/pie de página del sitio al final)
- Copiar, enviar biblioteca multimedia, descargar
- Vista completa de imágenes/vídeos

### Relacionado

- **Biblioteca multimedia** (<kbd>M</kbd>): tu colección guardada
- **Copiar debajo del cursor**: imagen/URL única colocada sobre el cursor
