# Introducción

KeyPilot agrega atajos de teclado a páginas web normales. Apunte a un enlace o botón con el mouse, luego presione una tecla para activarlo: la mano del mouse dirige, la mano del teclado actúa.

## Uso básico

![KeyPilot documentation popover](images/docs-intro.png)

### Hacer clic en elementos
1. Mueva el puntero sobre un enlace. Aparece un rectángulo de enfoque en el objetivo.
2. Presione <kbd>F</kbd> (diseño de navegación predeterminado, diestro) para hacer clic.

### Claves esenciales
1. Presione <kbd>Alt</kbd>+<kbd>K</kbd> para activar o desactivar KeyPilot.
2. Presione <kbd>K</kbd> para abrir la Referencia del teclado: un mapa en vivo de cada tecla asignada.
3. Presione <kbd>Alt</kbd>+<kbd>H</kbd> para volver a esta documentación.

Los nombres clave en estos documentos se refieren al diseño **predeterminado de navegación para diestros**, a menos que se indique lo contrario. Los diseños para zurdos reflejan los grupos principales. Los diseños personalizados pueden utilizar cualquier tecla que usted asigne.

## Qué ofrece KeyPilot

- **Haga clic, desplácese y navegue** sin mover las manos entre el teclado y el mouse para cada acción: <kbd>F</kbd> clics, <kbd>C</kbd>/<kbd>V</kbd> desplazamiento, <kbd>D</kbd>/<kbd>R</kbd> retrocede/adelante.
- **Herramientas de navegación adicionales**: Omnibox, Iniciador, Sitios principales, Historial de pestañas y colección de medios.
- **Personalización completa**: reasigna claves, crea instancias de acción y ejecuta scripts de ejecución JS.

</section>

## Limitaciones

KeyPilot se ejecuta como un script de contenido en páginas web normales. Chrome impide que se ejecuten extensiones en la página de nueva pestaña, en las páginas `chrome://` y en Chrome Web Store.
