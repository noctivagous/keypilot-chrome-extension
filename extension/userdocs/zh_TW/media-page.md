# 頁面媒體
頁面媒體會掃描目前頁面的圖片、影片、文字、文件、字型和 URL，讓您不必手動檢查頁面即可瀏覽或儲存。
## 使用方式
1. 在預設右手瀏覽配置按 <kbd>O</kbd>。
2. 切換分頁：**圖片**、**影片**、**文字**、**文件**、**字型**、**URL**。
3. 預覽項目；在適用時調整圖片縮放/比例。
4. 複製、下載、開啟全螢幕檢視，或將項目傳送至**媒體庫**。
5. 使用 <kbd>Esc</kbd> 或覆蓋層關閉控制項關閉。
想取得頁面上的所有內容時使用頁面媒體；已知道要擷取哪個停留資產時，使用 <kbd>I</kbd> / <kbd>U</kbd>。
## 參考
### 預設按鍵
| 配置 | 按鍵 |
| --- | --- |
| 右手瀏覽 | <kbd>O</kbd> |
必要時可透過配置編輯器重新綁定。
### 功能
- 圖片縮放與比例控制；**Article first**（預設開啟）會先排列文章/main 中的圖片，再排列網站控制項。
- 字型分頁（先顯示自訂 `.woff2` / `.otf` / `.ttf`，再顯示系統字型）
- URL 表格檢視，或自動換行的卡片格狀清單檢視（文章/main 優先；網站頁首/頁尾最後）
- 複製、傳送到媒體庫、下載
- 圖片/影片全螢幕檢視
### 相關項目
- **媒體庫**（<kbd>M</kbd>）— 您儲存的收藏
- **複製游標下的內容** — 單一停留圖片/URL
