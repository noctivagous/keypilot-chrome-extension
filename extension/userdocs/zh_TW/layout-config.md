# 鍵盤配置編輯器
配置編輯器用於自訂按鍵對應：在按鍵上放置功能、建立配置及管理動作執行個體。
## 使用方式
1. 按 <kbd>Alt</kbd>+<kbd>C</kbd>，或從鍵盤參考下拉選單選擇**編輯鍵盤配置…**。
2. 鍵盤參考會成為放置表面；設定面板包含動作程式庫和配置工具。
3. **建立或選取配置** — 編輯內建配置會建立使用者副本（內建配置保持唯讀）。
4. 尋找動作（搜尋程式庫）、選取它，然後在鍵盤參考上**點選鍵帽**以放置。
5. 視需要取代或清除既有的自訂插槽。
6. 想以此配置瀏覽時，將其設為目前配置。
7. 完成後再按 <kbd>Alt</kbd>+<kbd>C</kbd> 或關閉面板。
下拉選單還提供：**新增空白鍵盤配置**及**新增複製鍵盤配置**。
## 參考
### 配置管理
- 重新命名、刪除、複製使用者配置
- 以 JSON 匯入 / 匯出自訂配置
- 切換正在編輯的配置與目前使用的配置
### 放置規則
- 自訂配置為**獨占**：只有已指派的按鍵及永遠啟用的系統層可執行。
- 含參數的功能會成為有儲存設定的**動作執行個體**（標籤、目的地、指令碼主體等）。
- 部分功能（例如 Type Characters）只能綁定**修飾鍵組合**，不能綁定單一字母按鍵，讓它們能在輸入時執行。
### 提示
- 放置時保持鍵盤參考可見 — 將游標停在鍵帽上確認。
- 若只要少量變更，請從 Browsing 的複本開始。
- 請參閱*功能與動作*和*執行 JS*，了解可放置的項目。
