# 連結預覽與浮動視窗
在固定大小的作業系統彈出視窗中預覽連結，不取代目前分頁。
## 使用方式
### 連結預覽（<kbd>E</kbd>）
1. 將游標停在連結上直到醒目提示。
2. 按 <kbd>E</kbd> 在游標附近開啟固定大小的彈出視窗。
3. 在 KeyPilot 標題列使用**在此分頁開啟**或**在新分頁開啟**。
4. 使用 <kbd>Esc</kbd>、標題列關閉控制項，或再次按動作按鍵關閉。
### Open Popover
在較大的彈出視窗開啟游標下的連結。Browsing 配置沒有預設按鍵 — 請在配置編輯器綁定 **Open Popover**。
啟動器卡片預覽和分類搜尋結果使用相同彈出視窗。
## 參考
| 按鍵 | 動作 |
| --- | --- |
| <kbd>E</kbd> | 連結預覽彈出視窗 |
### 行為注意事項
- 預覽一律以 Chrome/Brave 彈出視窗開啟（不是頁內 iframe）。
- 設定 / 指南 / 文件仍使用頁內浮動控制項（標題列，按 <kbd>Esc</kbd> 關閉）。
- 可在配置編輯器自訂或重新綁定這些功能。
