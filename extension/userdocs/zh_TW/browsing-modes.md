# 模式
KeyPilot 對需要持續輸入的操作使用模式狀態。模式啟用時，大部分瀏覽按鍵會暫停；<kbd>Esc</kbd> 幾乎總能取消。
## 使用方式
1. **一般瀏覽** — 快速鍵啟用；焦點框顯示可點擊目標。
2. **文字模式** — 在文字欄位按 <kbd>F</kbd>；正常輸入。完成後按 <kbd>Esc</kbd>（或鍵盤參考的結束控制項）。
3. **捲動線** — 按 <kbd>N</kbd>；移離原點即可捲動；以 <kbd>N</kbd>、點擊或 <kbd>Esc</kbd> 離開。
4. **選取** — <kbd>H</kbd> 或 <kbd>Y</kbd>；<kbd>Esc</kbd> 取消。
5. **刪除模式** — 按 <kbd>Backspace</kbd>，指向元素並確認以自頁面移除；<kbd>Esc</kbd> 取消。
6. **浮動視窗 / 全方位搜尋列 / 配置編輯器** — 各有開啟狀態；以 <kbd>Esc</kbd> 或工具的關閉按鍵關閉。
若按鍵似乎「失效」，您大概在文字模式或其他模式中 — 按一次 <kbd>Esc</kbd> 後重試。
## 參考
### 文字模式詳情
- 大部分配置瀏覽按鍵會暫停，讓輸入更安全。
- 短暫停留加 <kbd>F</kbd> 的視窗仍可啟用其他可點擊目標，而不完全離開文字焦點（倒數感知的 Activate）。
- 外觀（T 形與十字游標、橘色邊緣、標籤）位於**設定 → 文字模式**。
### 刪除模式
- 預設配置用 <kbd>Backspace</kbd> 進入。
- 您以視覺方式挑選元素；確認會從即時頁面刪除該 DOM 節點（僅限頁面，不是瀏覽器記錄的復原）。
### 始終可用
即使文字模式暫停瀏覽按鍵或擴充功能已關閉，<kbd>Alt</kbd>+<kbd>K</kbd> 仍可切換 KeyPilot。
