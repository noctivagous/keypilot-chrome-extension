# 分頁與瀏覽記錄
不必使用瀏覽器控制項，即可在分頁和瀏覽記錄間移動。
## 使用方式
1. 按 <kbd>Q</kbd> / <kbd>W</kbd> 切換至上一個 / 下一個分頁。
2. 按 <kbd>T</kbd> 開啟新分頁；按 <kbd>A</kbd> 關閉目前分頁。
3. 按 <kbd>D</kbd> 返回；按 <kbd>R</kbd> 前進。
4. 按 <kbd>S</kbd>（或 <kbd>1</kbd>）跳至目前網站的根目錄（scheme + host）。
5. 按 <kbd>J</kbd> 開啟**分頁記錄** — 此分頁可辨識分支的記錄列（請參閱*分頁記錄*）。
6. 按 <kbd>.</kbd> 開啟**分頁總覽**。每個視窗是一張卡片，其中的分頁以清單顯示。對分頁按鍵點擊即可切換；對視窗標題列按鍵點擊只聚焦該視窗。左手瀏覽使用 <kbd>X</kbd>。
## 參考
### 預設按鍵（右手瀏覽）
| 按鍵 | 動作 |
| --- | --- |
| <kbd>Q</kbd> | 上一個分頁 |
| <kbd>W</kbd> | 下一個分頁 |
| <kbd>T</kbd> | 新分頁 |
| <kbd>A</kbd> | 關閉分頁 |
| <kbd>D</kbd> | 返回 |
| <kbd>R</kbd> | 前進 |
| <kbd>S</kbd> / <kbd>1</kbd> | 網站根目錄 |
| <kbd>J</kbd> | 分頁記錄浮動視窗 |
| <kbd>.</kbd> | 分頁總覽（左手：<kbd>X</kbd>） |
<h3 id="open-bookmarks">開啟書籤</h3>

**開啟書籤**是分頁控制中的動作執行個體。從書籤管理員選擇一個資料夾。按下該鍵會開啟該資料夾中前 30 個網站書籤（包含子資料夾），每個在目前分頁之後的背景分頁中開啟。

### 提示
- 上一頁/下一頁遵循分頁的一般瀏覽器記錄。
- 當您離開分岔點時，分頁記錄會保留替代分支 — 適合從同一頁探索多條路徑後使用。
- 左手瀏覽會將這些按鍵群組鏡像到鍵盤右側。
- **開啟網址** 在檢查器中儲存一組網站，按一下按鍵即可在背景分頁開啟。
