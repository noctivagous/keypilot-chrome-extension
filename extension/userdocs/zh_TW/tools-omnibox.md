# 全方位搜尋列
全方位搜尋列是帶有記錄和書籤建議的頁面內網址/搜尋方塊。
## 使用方式
1. 按 <kbd>L</kbd>（預設瀏覽）或 <kbd>Alt</kbd>+<kbd>L</kbd>。
2. 輸入 URL 或搜尋查詢。
3. 使用 <kbd>↑</kbd>/<kbd>↓</kbd> 或指標挑選建議。
4. 按 <kbd>Enter</kbd> 在目前分頁瀏覽。
5. 按 <kbd>Esc</kbd> 關閉而不瀏覽。
非 URL 查詢會使用**設定 → 搜尋**中的搜尋引擎。
## 參考
### 行為
- 建議會合併瀏覽器記錄和書籤。
- <kbd>Enter</kbd> 會在**目前**分頁瀏覽（不是新分頁啟動器）。
- 即使重新綁定或清除配置的全方位搜尋列按鍵，<kbd>Alt</kbd>+<kbd>L</kbd> 仍是控制項快速鍵。
### 相關項目
- **啟動器**（<kbd>Alt</kbd>+<kbd>;</kbd> / <kbd>Alt</kbd>+<kbd>A</kbd>）可用於分類網站和 Launch Deck
- **熱門網站**（<kbd>;</kbd>）可用於工具列 / 最常造訪 / 最近書籤
- 新分頁也會嵌入使用相同引擎偏好的搜尋
