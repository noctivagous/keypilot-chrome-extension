# 分頁記錄
分頁記錄會顯示此分頁造訪過的位置，包括您從分岔點離開時的替代分支。
## 使用方式
1. 按 <kbd>J</kbd>（預設右手瀏覽；左手為 <kbd>F</kbd>）。
2. 瀏覽水平列：保留分支的記錄和一般瀏覽器記錄。
3. 分支徽章標示分岔點的替代後代。
4. 點擊卡片前往該處。
5. 按 <kbd>Esc</kbd> 關閉。
當您從同一篇文章或文件網站探索數個路徑，而僅靠返回不足時，請使用此工具。
## 參考
### 列
- 目前分頁的**保留分支**記錄
- 一般返回堆疊脈絡的**瀏覽器記錄**列
### 提示
- 卡片會在目前分頁瀏覽。
- 以 <kbd>Esc</kbd> 關閉不會變更頁面。
- 若需要將按鍵用於其他用途，可在配置編輯器重新綁定或移除分頁記錄。
