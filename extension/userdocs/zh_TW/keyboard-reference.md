# 鍵盤參考
浮動的鍵盤參考是目前配置的即時對應表，也是學習與切換配置最快的方式。
## 使用方式
1. 按 <kbd>K</kbd>（右手）或 <kbd>D</kbd>（左手），或使用控制列 / 彈出式視窗 / 新分頁切換鈕。
2. 將游標停在鍵帽上查看已綁定的動作。
3. 使用**標題列配置下拉選單**切換內建系列或自訂配置、開啟配置編輯器（編輯 / 新增 / 複製）、啟動**新手教學課程**、開啟**KeyPilot 文件/說明**（此浮動視窗）或**KeyPilot 設定**。
4. 拖曳視窗；需要螢幕空間時將其收合；按 × 或相同切換按鍵關閉。
5. KeyPilot 處於文字模式時，可使用參考控制項的 <kbd>Exit</kbd>，不必按 <kbd>Esc</kbd>。
## 參考
### 顯示內容
- 使用中的系列、慣用手與自訂指派
- 永遠啟用的系統按鍵
- 選用數字列（設定 → 鍵盤）
- 啟用回饋時的已按鍵醒目提示
- 停留在連結上時，動作按鍵可選用光暈（設定 → 點擊模式）
### 編輯模式
開啟 <kbd>Alt</kbd>+<kbd>C</kbd> 配置編輯器時，鍵盤參考會成為放置表面：在程式庫挑選動作，再點選鍵帽加以指派。
### 提示
- 學習時可在第二台螢幕或角落保持開啟。
- 若按鍵無反應，請先檢查此視窗，不要直接認定 KeyPilot 壞了 — 您可能正使用導覽系列或稀疏的自訂配置。
