# 點擊與連結
以滑鼠指向元素；按下按鍵即可啟用下方的項目。KeyPilot 會在游標下的可點擊目標或文字欄位繪製焦點框。
## 使用方式
1. 將指標移到連結、按鈕或文字欄位，直到出現焦點框。
2. 按下 <kbd>F</kbd> 點擊，或將焦點放在文字欄位並進入文字模式。
3. 按 <kbd>B</kbd> 在**新的前景分頁**開啟連結。
4. 按 <kbd>G</kbd> 在**背景分頁**開啟（如同中鍵點擊）。
5. 按 <kbd>E</kbd>（連結預覽）或 <kbd>P</kbd>（較大的浮動視窗）可快速預覽；請參閱*連結預覽與浮動視窗*。
若醒目提示錯誤元素，稍微移動滑鼠 — KeyPilot 優先選取游標下的最末端元素。
## 參考
### 預設按鍵（右手瀏覽）
| 按鍵 | 動作 |
| --- | --- |
| <kbd>F</kbd> | 點擊 / 啟用游標下方項目；讓文字欄位取得焦點 |
| <kbd>B</kbd> | 在新分頁開啟連結（前景） |
| <kbd>G</kbd> | 在新分頁開啟連結（背景） |
| <kbd>E</kbd> | 連結預覽彈出視窗 |
| <kbd>P</kbd> | 在浮動視窗彈出視窗中開啟連結 |
### 視覺回饋
- 焦點框標示可點擊目標及文字欄位。
- 可在**設定 → 點擊模式**調整顏色和光暈。
- 點擊時可播放選用的啟用效果（Flash、Dash、Marquee、Scale）。
### 文字欄位
在文字欄位按下 <kbd>F</kbd> 會讓它取得焦點並暫停大部分瀏覽按鍵，以便輸入。按 <kbd>Esc</kbd> 離開文字模式；請參閱*模式*。
