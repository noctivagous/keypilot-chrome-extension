# 捲動
以固定距離、跳轉或連續「捲動線」控制來捲動頁面或游標下的巢狀捲動區。
## 使用方式
1. 指向頁面（或可捲動區域內）。
2. 使用**向上翻頁**和**向下翻頁**依設定距離捲動。
3. 使用**捲至頂端**跳至捲動目標頂端；使用**捲至底端**前往底端。
4. 使用**捲動線**進行連續控制：游標下會出現原點標記；將滑鼠移離原點，距離越遠捲動越快；再次使用**捲動線**、點擊或按 <kbd>Esc</kbd> 離開。
5. 您可在設定 → 捲動中啟用**空白頁面區域中鍵點擊**，以不使用捲動線按鍵的方式啟動。
6. 使用**縮小**（<kbd>[</kbd>）和**放大**（<kbd>]</kbd>）將分頁縮放一級，並保持游標下的點不動，效果與雙指捏合同。
請在**設定 → 捲動**調整步距與動畫。
## 參考
### 功能
| 功能 | 說明 |
| --- | --- |
| **向上翻頁** | 依設定的即時距離向上捲動 |
| **向下翻頁** | 依設定的即時距離向下捲動 |
| **捲至頂端** | 跳至捲動目標頂端 |
| **捲至底端** | 跳至捲動目標底端 |
| **捲動線** | 切換以原點為基準的連續捲動 |
| **縮小** | 在游標處將分頁縮小一級 |
| **放大** | 在游標處將分頁放大一級 |
這些功能的預設按鍵取決於使用中的鍵盤配置。
### 重要設定
- Page Up / Page Down 的**捲動距離**
- 跳轉的**平滑或即時**動畫
- 捲動線中**略過寬大的輪播式捲動區**
- 在空白頁面區域以**中鍵點擊**啟動捲動線
### 捲動目標
KeyPilot 會捲動頁面或游標下的巢狀捲動區。若捲動線鎖定錯誤區域，請離開、重新放置指標，再使用**捲動線**。
