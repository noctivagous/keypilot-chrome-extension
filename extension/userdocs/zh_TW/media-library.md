# 媒體庫
媒體庫是您個人的媒體庫，存放瀏覽時收集的圖片、影片、文件和 URL。
## 使用方式
1. 按 <kbd>M</kbd>（預設右手瀏覽）。
2. 依**圖片**、**影片**、**文件**、**URL**和網域瀏覽。
3. 開啟或全螢幕檢視項目；選取範圍以執行大量操作。
4. 將類別或選取內容下載為 ZIP；刪除不再需要的內容。
5. 使用 <kbd>Esc</kbd> 或覆蓋層關閉控制項關閉。
從頁面媒體、複製游標下的內容功能，或其他將媒體庫列為目的地的動作新增項目。
## 參考
### 預設按鍵
| 配置 | 按鍵 |
| --- | --- |
| 右手瀏覽 | <kbd>M</kbd> |
### 類別
- 圖片、影片、文件、URL（以及網域分組）
- 對停留位置的檔案連結使用**Fetch URL for Media Library**，或從頁面媒體傳送
### 提示
- 請將媒體庫用於長期儲存；一次性貼上請使用剪貼簿目的地。
