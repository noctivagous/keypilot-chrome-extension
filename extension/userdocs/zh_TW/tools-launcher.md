# 啟動器
啟動器是分類網站瀏覽器，提供搜尋、書籤、記錄及可編輯的 Launch Deck。
## 使用方式
1. 按 <kbd>Alt</kbd>+<kbd>;</kbd> 或 <kbd>Alt</kbd>+<kbd>A</kbd>，開啟已聚焦搜尋的啟動器。
2. 輸入以篩選，或瀏覽分類（Launch Deck、書籤、最近、社群、新聞、生產力、影片、娛樂、購物、AI、Internet Archive、搜尋等）。
3. 從格狀或清單開啟網站。
4. 按 <kbd>/</kbd> 再次聚焦搜尋；使用 <kbd>←</kbd>/<kbd>→</kbd>/<kbd>↑</kbd>/<kbd>↓</kbd> 移動；<kbd>Esc</kbd> 關閉（或先離開編輯模式）。
若要固定自有捷徑，開啟**Launch Deck**並使用編輯模式重新排序、移除或新增項目。
## 參考
| 方法 | 說明 |
| --- | --- |
| <kbd>Alt</kbd>+<kbd>;</kbd> / <kbd>Alt</kbd>+<kbd>A</kbd> | Chrome 快速鍵 — 聚焦搜尋 |
| 配置功能 | 啟動器可在配置編輯器綁定至任意按鍵（右手瀏覽沒有單鍵預設） |
### 子檢視
- Launch Deck / 網站分類
- 最愛 / 書籤
- 記錄
- 搜尋
### 提示
- 適合重複造訪的目的地；臨時 URL 和查詢請使用全方位搜尋列。
- Launch Deck 編輯會保留在您的個人資料中。
