# Copy under cursor

Grab the hovered image or URL with one key — to the clipboard, Media Library, or both.

## Use it

1. Hover an image or a link/URL target until KeyPilot highlights it.
2. Press <kbd>I</kbd> to copy the hovered **image**.
3. Press <kbd>U</kbd> to copy the hovered **URL**.
4. Check the Action Instance settings in Layout Config if you want Media Library instead of (or in addition to) the clipboard.

**Copy Video** exists in the Actions Library but has no default built-in key — bind it in Layout Config if you need it.

## Reference

### Default keys (Browsing, right-handed)

| Key | Action |
| --- | --- |
| <kbd>I</kbd> | Copy hovered image |
| <kbd>U</kbd> | Copy hovered URL |

Left-handed Browsing places copy-image on <kbd>E</kbd> by default.

### Destinations

Many copy Functions support:

- Clipboard
- Media Library
- Both

Configure the Action Instance, then place that instance on a key.

### Related

- **Page Media** (<kbd>O</kbd>) — browse everything found on the page
- **Media Library** (<kbd>M</kbd>) — review what you saved
