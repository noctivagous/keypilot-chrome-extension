# 配置與慣用手
**配置**是按鍵 → 動作的對應表。KeyPilot 內建多個系列；您可以切換慣用手或建立自訂配置。
## 使用方式
1. 開啟**設定**（<kbd>'</kbd>）→ **鍵盤**，或使用**鍵盤參考**標題列的配置下拉選單。
2. 選擇**系列**：**瀏覽** — 完整的點擊、捲動、分頁與工具（預設）；**導覽** — 精簡的點擊 / 返回 / 前進組合。
3. 若您左手使用滑鼠，啟用**左手** — 主要快速鍵會移到鍵盤右側。
4. 隨時以 <kbd>Alt</kbd>+<kbd>[</kbd>（上一個）及 <kbd>Alt</kbd>+<kbd>]</kbd>（下一個）循環切換系列，而不變更慣用手。
5. 若要深入自訂按鍵，按 <kbd>Alt</kbd>+<kbd>C</kbd> 開啟鍵盤配置編輯器（請參閱該主題）。
切換後開啟 <kbd>K</kbd>（鍵盤參考）— 顯示的鍵盤永遠符合使用中的配置。
## 參考
### 內建系列
| 系列 | 用途 |
| --- | --- |
| 瀏覽 | 日常以鍵盤優先的瀏覽 |
| 導覽 | 最小導覽子集 |
慣用手獨立於系列。舊版「Basic Navigation」id 仍可能從舊設定解析，但正常選擇器中會隱藏。
### 自訂配置
- 在配置編輯器編輯內建配置會建立使用者副本（例如「Browsing Copy 1」）。
- 自訂配置為**獨占**：只有已指派的插槽及永遠啟用的系統層會觸發。
- 從配置編輯器匯入/匯出 JSON，以備份或分享配置。
### 相關設定
- 在鍵盤參考 / 編輯器中顯示數字列
- 輸入快速鍵時的已按鍵回饋
- 目前配置 id 和系列會保留在您的 Chrome 個人資料中
