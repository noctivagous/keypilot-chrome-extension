# 系統按鍵與 Alt 控制項
有些按鍵一律屬於 KeyPilot 控制項。它們在內建和自訂配置中都可使用。
## 使用方式
### 永遠啟用的系統層
即使自訂配置未指派，這些字元按鍵仍可使用：
1. 按 <kbd>Esc</kbd> 取消目前模式（文字模式、選取、捲動線、許多浮動視窗）。
2. 按 <kbd>K</kbd>（右手）或 <kbd>D</kbd>（左手）顯示或隱藏**鍵盤參考**。
3. 按 <kbd>'</kbd>（引號）開啟**設定**。
### Alt 控制項快速鍵
| 組合鍵 | 動作 |
| --- | --- |
| <kbd>Alt</kbd>+<kbd>K</kbd> | 切換 KeyPilot 開啟/關閉（停用時也可使用） |
| <kbd>Alt</kbd>+<kbd>J</kbd> | 顯示/隱藏控制列（停用時也可使用） |
| <kbd>Alt</kbd>+<kbd>L</kbd> | 開啟全方位搜尋列 |
| <kbd>Alt</kbd>+<kbd>;</kbd> 或 <kbd>Alt</kbd>+<kbd>A</kbd> | 開啟啟動器並聚焦搜尋 |
| <kbd>Alt</kbd>+<kbd>[</kbd> / <kbd>Alt</kbd>+<kbd>]</kbd> | 上一個 / 下一個配置系列 |
| <kbd>Alt</kbd>+<kbd>C</kbd> | 切換鍵盤配置編輯器 |
| <kbd>Alt</kbd>+<kbd>H</kbd> | 開啟本文件 |
| <kbd>Alt</kbd>+<kbd>I</kbd> | 顯示/隱藏新手操作導覽 |
請先記住 <kbd>Alt</kbd>+<kbd>K</kbd>、<kbd>Esc</kbd>、<kbd>K</kbd>、<kbd>'</kbd> 和 <kbd>Alt</kbd>+<kbd>H</kbd> — 它們可解鎖其他所有功能。
## 參考
### 系統層與配置按鍵
- **系統層** — <kbd>Esc</kbd>、鍵盤參考、設定；獨立於配置系列定義。
- **配置按鍵** — <kbd>F</kbd>、<kbd>D</kbd>、捲動、工具等，來自使用中的內建或自訂配置。
- **Alt 控制項** — 在一般按鍵路由前處理；不會顯示為一般字母指派。
### 慣用手注意事項
在左手配置中，鍵盤參考移至 <kbd>D</kbd>，以避免與鏡像啟用群組衝突。設定維持 <kbd>'</kbd>。
### 不供日常使用
<kbd>Alt</kbd>+<kbd>D</kbd> 切換開發人員 shadow-root 偵錯 HUD。除非您在診斷繪製問題，否則請略過。
