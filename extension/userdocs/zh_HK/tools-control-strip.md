# 控制列
控制列是始終可見的小列，可切換 KeyPilot、開啟鍵盤參考及前往設定，不必操作滑鼠。
## 使用方式
1. 在頁面尋找可拖曳的控制列。若不見了，按 <kbd>Alt</kbd>+<kbd>J</kbd> 還原。
2. 用來開啟/關閉 KeyPilot、開啟**鍵盤參考**、開啟**設定**，或收合 / 關閉控制列。
3. 經由移動握把拖曳，將它放在不礙事的位置。
4. 在**設定 → 控制列**選擇啟動時是否可見或收合。
即使 KeyPilot 已停用，<kbd>Alt</kbd>+<kbd>J</kbd> 仍可還原控制列。
## 參考
| 控制項 | 角色 |
| --- | --- |
| 開/關 | 等同 <kbd>Alt</kbd>+<kbd>K</kbd> |
| 鍵盤參考 | 等同 <kbd>K</kbd> / <kbd>D</kbd> |
| 設定 | 等同 <kbd>'</kbd> |
| 收合 / 關閉 | 隱藏控制列；以 <kbd>Alt</kbd>+<kbd>J</kbd> 還原 |
文字模式會將控制列染成橘色，讓您知道瀏覽按鍵為何暫停。可見性偏好會與您的個人資料同步。
