# 熱門網站
熱門網站是工具列書籤、最常造訪網站、最近書籤及 KeyPilot 工具的精簡面板。
## 使用方式
1. 按 <kbd>;</kbd>（預設右手瀏覽；左手常用 <kbd>A</kbd> / <kbd>&#96;</kbd>）。
2. 切換面板分頁：**工具列**、**最常造訪**、**最近書籤**與**KeyPilot**（右緣）。數字鍵 <kbd>1</kbd>–<kbd>4</kbd> 跳至分頁；<kbd>Tab</kbd> 循環切換。
3. 點擊或啟用網站卡片以瀏覽。面板足夠高，可顯示三列卡片而不裁切。
4. 開啟**KeyPilot**分頁，取得和擴充功能彈出式視窗相同的工具卡：鍵盤參考、說明 / 文件、新手教學課程、設定和控制列。
5. 拖曳**熱門網站**標題列移動面板；拖曳邊緣或角落調整大小。會記住大小和位置。
6. 按 <kbd>Esc</kbd> 或標題列關閉按鈕關閉。
## 跨頁保持開啟
預設熱門網站是暫時模式（按 <kbd>Esc</kbd>、點擊外側或離開頁面時關閉）。
若要在瀏覽時像鍵盤參考一樣保持顯示：
1. 開啟標題列齒輪選單（關閉鈕左側）。
2. 開啟**跨頁保持開啟**。
面板會在每個頁面重新掛載，位置在分頁間保持同步。關閉它（或再按 <kbd>;</kbd>）可隱藏至再次開啟。關閉齒輪選項可回到暫時模式。

### 與啟動器比較
- **熱門網站** — 快速存取 Chrome 工具列 / 最常造訪 / 最近書籤，加上 KeyPilot 工具分頁。
- **啟動器** — 較廣泛分類，加上可編輯 Launch Deck 和聚焦搜尋（<kbd>Alt</kbd>+<kbd>;</kbd>）。
