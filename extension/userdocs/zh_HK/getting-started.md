# 開始使用

在任何頁面按幾個初始按鍵；在熟悉配置前，請保持鍵盤參考開啟。
## 使用方式
1. 使用 <kbd>Alt</kbd>+<kbd>K</kbd> 開啟或關閉 KeyPilot。
2. 使用 <kbd>Alt</kbd>+<kbd>J</kbd> 切換控制列。
3. 使用 <kbd>K</kbd> 切換**鍵盤參考**。
4. 從鍵盤參考的配置下拉選單開啟**新手教學課程**（KeyPilot → Onboarding Tutorial），或按下 <kbd>Alt</kbd>+<kbd>I</kbd> 顯示操作導覽。
### 建議練習的第一批按鍵命令
| 目標 | 預設按鍵 |
| --- | --- |
| 點擊 / 焦點置於游標下方 | <kbd>F</kbd> |
| 上一頁 | <kbd>D</kbd> |
| 網站根目錄 | <kbd>S</kbd> |
| 下一頁 | <kbd>R</kbd> |
| 向上 / 向下捲動 | <kbd>C</kbd> / <kbd>V</kbd> |
| 離開模式 / 取消 | <kbd>Esc</kbd> |
| 鍵盤參考 | <kbd>K</kbd> |
| 設定 | <kbd>'</kbd> — 開啟 [設定](kp://settings/overview) 或跳至 [鍵盤](kp://settings/keyboard) |
| 切換 KeyPilot | <kbd>Alt</kbd>+<kbd>K</kbd> |
| 本文件 | <kbd>Alt</kbd>+<kbd>H</kbd> |
## 參考
### 操作導覽與練習
- **操作導覽**是真實瀏覽動作的核對清單。進度會儲存在您的 Chrome 個人資料中，且可從教學入口重設。
- **練習面板**會在文字方塊投影片出現，讓您可使用 <kbd>F</kbd> 進入焦點、正常輸入，並以 <kbd>Esc</kbd> 離開。
### 其他入口
- 擴充功能**彈出式視窗** → 教學課程
- **指南**浮動視窗 → 啟動操作導覽
- 鍵盤參考下拉選單 → Onboarding Tutorial
- <kbd>Alt</kbd>+<kbd>I</kbd> 顯示或隱藏操作導覽而不重設進度
### 如果沒有任何反應
- 確認 KeyPilot 已啟用（<kbd>Alt</kbd>+<kbd>K</kbd>）。
- 確認您不在 `chrome://` 或線上應用程式商店。
- 開啟鍵盤參考，確認您的配置仍有指派所按的按鍵。
