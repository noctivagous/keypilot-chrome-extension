# 複製游標下的內容
以單一按鍵擷取停留位置的圖片或 URL — 儲存至剪貼板、媒體庫或兩者。
## 使用方式
1. 將游標停在圖片或連結/URL 目標上，直到 KeyPilot 醒目提示它。
2. 按 <kbd>I</kbd> 複製停留位置的**圖片**。
3. 按 <kbd>U</kbd> 複製停留位置的**URL**。
4. 若您要使用媒體庫取代或額外使用剪貼板，請在配置編輯器檢查動作執行個體設定。
**Copy Video** 位於動作程式庫，但沒有預設內建按鍵 — 如需使用，請在配置編輯器綁定。
## 參考
### 預設按鍵（右手瀏覽）
| 按鍵 | 動作 |
| --- | --- |
| <kbd>I</kbd> | 複製停留位置的圖片 |
| <kbd>U</kbd> | 複製停留位置的 URL |
左手瀏覽預設將複製圖片放在 <kbd>E</kbd>。
### 目的地
許多複製功能支援：剪貼板、媒體庫、兩者。設定動作執行個體後，再將其放到按鍵。
### 相關項目
- **頁面媒體**（<kbd>O</kbd>）— 瀏覽頁面找到的一切
- **媒體庫**（<kbd>M</kbd>）— 檢視已儲存內容
