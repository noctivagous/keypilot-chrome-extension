# 選取
選取游標下的文字或 HTML 元素，再複製或操作結果。
## 使用方式
### 文字選取
1. 將游標移至選取起點。
2. 按 <kbd>H</kbd> 開始逐字文字選取。
3. 移到範圍終點，再按 <kbd>H</kbd> 完成並複製。
4. 按 <kbd>Esc</kbd> 取消且不複製。
文字選取是從插入點到插入點（如同拖曳點擊），而非虛線矩形的剪輯。矩形只是拖曳指引：複製範圍是起訖插入點在文件順序間的所有內容。
複製格式（格式化或純文字）可在文字選取功能的動作執行個體設定。
### 元素選取
1. 按 <kbd>Y</kbd> 開始選取相交 HTML 元素的矩形。
2. 在要選取的元素上拖曳/調整矩形。
3. 依畫面提示完成（或使用已設定的累積挑選模式）。
4. 按 <kbd>Esc</kbd> 取消。
預設粒度為文章功能單位：段落或標題、整個表格、整個圖表或圖片、整個清單。命中段落內的連結會立即選取段落。重疊使用元素的行框，而不是單一邊界框。
## 參考
### 預設按鍵（右手瀏覽）
| 按鍵 | 動作 |
| --- | --- |
| <kbd>H</kbd> | 文字選取（開始 / 完成並複製） |
| <kbd>Y</kbd> | 矩形選取元素（或累積挑選模式） |
| <kbd>Esc</kbd> | 取消選取模式 |
### <kbd>Y</kbd> 的模式
- **矩形** — 選取行框與繪製矩形相交的文章功能單位（段落、表格、圖表、清單）。段落內的連結會選取該段落。
- **累積挑選** — 逐一新增元素，以 <kbd>Enter</kbd> 完成（於功能中設定）。
### 相關工具
- <kbd>I</kbd> / <kbd>U</kbd> 複製停留位置的圖片 / URL（請參閱*複製游標下的內容*）。
- <kbd>O</kbd> 開啟頁面媒體以取得頁面上所有內容。
- 剪貼板和媒體庫目的地會出現在配置編輯器的許多取得 / 複製功能中。
