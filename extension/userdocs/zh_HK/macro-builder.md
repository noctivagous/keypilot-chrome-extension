# 巨集建立器
巨集建立器是使用者巨集的步驟編輯器，可從鍵盤配置編輯器存取。
## 使用方式
1. 按 <kbd>Alt</kbd>+<kbd>C</kbd> 開啟配置編輯器。
2. 開啟**使用者巨集**。
3. **建立**巨集並取清楚名稱，或複製既有巨集。
4. 新增步驟：在動作程式庫選取功能並加入巨集；新增**邏輯**晶片 Wait、Gate、Stop、Run Macro；新增**Get Text Range**擷取目前選取內容供下一步使用；新增**Show Popover**顯示前一步結果（或備援文字）；新增**Execute JS**執行貼上的指令碼。
5. 重新排序或移除步驟；開啟步驟設定參數與選用延遲。
6. **儲存**，然後從程式庫 / 巨集清單將巨集放到按鍵。
7. 在一般頁面測試；若流程應及早中止，請微調 Gate。
## 參考
### 邏輯晶片
| 晶片 | 角色 |
| --- | --- |
| **Wait** | 在下一步之前暫停 |
| **Gate** | 測試前一結果；失敗時略過設定的後續步驟 |
| **Stop** | 結束巨集 |
| **Run Macro** | 呼叫另一個巨集（巢狀；會防止循環） |
| **Execute JS** | 執行貼上的指令碼；回傳值供下一個 Gate 使用 |
| **Get Text Range** | 擷取目前反白/選取內容供下一步使用。不是按鍵動作（請用 Copy）。 |
| **Show Popover** | 在浮動視窗顯示前一功能結果（或設定的備援文字）。不是按鍵動作。 |
### Gate 測試
常見的前一功能結果比較：有值 / 空白、等於 / 不等於、大於 / 小於。失敗的 Gate 會依設定向前略過，讓您不必完整撰寫指令碼即可分支。
### 提示
- 保持巨集精簡，並依意圖命名步驟。
- 當步驟可能無結果時，請優先使用 Gate，而非長的無條件鏈結。
- Execute JS 回傳值會透過 `kpPriorResult` 供下一個 Gate 使用（請參閱*執行 JS*）。
