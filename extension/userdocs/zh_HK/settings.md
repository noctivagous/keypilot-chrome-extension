# 設定
設定可控制外觀、捲動、搜尋引擎、控制列及使用的鍵盤系列。變更會在同一 Chrome 個人資料的分頁間同步。
## 使用方式
1. 按 <kbd>'</kbd>（引號），或從控制列、彈出式視窗、新分頁或鍵盤參考下拉選單開啟設定。
2. 在左側導覽選取類別。
3. 調整控制項 — 多數會立即套用。
4. 完成後按 <kbd>Esc</kbd> 或標題列關閉控制項。
請先使用 [**鍵盤**](kp://settings/keyboard)（配置 + 慣用手）及 [**捲動**](kp://settings/scrolling)（Page Up / Page Down 距離）。熟悉基礎後，再微調 [**點擊模式**](kp://settings/click-mode) 和 [**文字模式**](kp://settings/text-mode)。
## 參考
### 類別
| 區段 | 可設定內容 |
| --- | --- |
| [**總覽**](kp://settings/overview) | 連至各類別的中樞 |
| [**外觀**](kp://settings/appearance) | 外觀與視覺控制項 |
| [**鍵盤**](kp://settings/keyboard) | 配置系列、左手、數字列、已按鍵回饋 |
| [**點擊模式**](kp://settings/click-mode) | 游標樣式、十字游標幾何、焦點框外觀、連結停留提示、啟用效果 |
| [**文字模式**](kp://settings/text-mode) | 游標、焦點樣式（脈衝邊緣 / 色調）、邊緣寬度、標籤、外框 |
| [**捲動**](kp://settings/scrolling) | Page Up / Page Down 距離、平滑與即時跳轉、略過輪播、中鍵捲動線 |
| [**游標**](kp://settings/cursor) | 不使用自訂游標或 KeyPilot 游標；啟用時的點擊模式十字游標幾何 |
| [**控制列**](kp://settings/control-strip) | 可見性與啟動時收合；使用 <kbd>Alt</kbd>+<kbd>J</kbd> 還原 |
| [**搜尋**](kp://settings/search) | 全方位搜尋列 / 新分頁搜尋使用 Brave、Google 或 DuckDuckGo |
| [**關於**](kp://settings/about) | 此 Chrome 個人資料的儲存與同步說明 |
### 相關介面
- 深入的按鍵重新對應位於**鍵盤配置編輯器**（<kbd>Alt</kbd>+<kbd>C</kbd>），不在設定中。請參閱[鍵盤配置編輯器](kp://docs/layout-config)。
- 文件的快速鍵為 <kbd>Alt</kbd>+<kbd>H</kbd>；多個控制項入口仍可使用簡短指南頁面。
