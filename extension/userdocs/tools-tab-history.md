# Tab History

Tab History shows where this tab has been — including alternate branches when you navigated away from a fork.

## Use it

1. Press <kbd>J</kbd> (default right-handed Browsing; <kbd>F</kbd> on left-handed).
2. Browse the horizontal rails: branch-retaining history and ordinary browser history.
3. Branch badges mark alternate descendants from a fork.
4. Click a card to navigate there.
5. Press <kbd>Esc</kbd> to close.

Use it after exploring several paths from the same article or docs site when Back alone is not enough.

## Reference

### Rails

- **Branch-retaining** history for the current tab
- **Browser history** rail for conventional back-stack context

### Tips

- Cards navigate the current tab.
- Closing with <kbd>Esc</kbd> does not change the page.
- Rebind or remove Tab History in Layout Editor if you need the key for something else.
