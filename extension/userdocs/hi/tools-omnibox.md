# ऑम्निबॉक्स

ऑम्निबॉक्स पेज पर एक पता/खोज बॉक्स है, जिसमें इतिहास और बुकमार्क सुझाव होते हैं।

## उपयोग करें

1. <kbd>L</kbd> (डिफ़ॉल्ट ब्राउज़िंग) या <kbd>Alt</kbd>+<kbd>L</kbd> दबाएँ।
2. एक URL या खोज क्वेरी टाइप करें।
3. सुझाव चुनने के लिए <kbd>↑</kbd>/<kbd>↓</kbd> या पॉइंटर का उपयोग करें।
4. वर्तमान टैब पर जाने के लिए <kbd>Enter</kbd> दबाएँ।
5. गए बिना बंद करने के लिए <kbd>Esc</kbd> दबाएँ।

URL न होने वाली क्वेरी **सेटिंग्स → खोज** का खोज इंजन उपयोग करती हैं।

## संदर्भ

### व्यवहार

- सुझाव ब्राउज़र इतिहास और बुकमार्क को मिलाते हैं।
- <kbd>Enter</kbd> **वर्तमान** टैब पर ले जाता है (यह नया-टैब लॉन्चर नहीं है)।
- लेआउट की ऑम्निबॉक्स कुंजी रीबाइंड या साफ़ करने पर भी <kbd>Alt</kbd>+<kbd>L</kbd> क्रोम हॉटकी के रूप में काम करता है।

### संबंधित

- वर्गीकृत साइटों और लॉन्च डेक के लिए **लॉन्चर** (<kbd>Alt</kbd>+<kbd>;</kbd> / <kbd>Alt</kbd>+<kbd>A</kbd>)
- टूलबार / सबसे ज़्यादा देखी / हाल के बुकमार्क के लिए **टॉप साइट्स** (<kbd>;</kbd>)
- नया टैब पेज भी उसी इंजन प्राथमिकता के साथ खोज दिखाता है
