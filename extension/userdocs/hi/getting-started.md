# शुरुआत

किसी भी पेज पर पहली कुछ कुंजियाँ दबाएँ; जब तक लेआउट आदत न बन जाए, कीबोर्ड संदर्भ खुला रखें।

## उपयोग करें

1. <kbd>Alt</kbd>+<kbd>K</kbd> से KeyPilot को **चालू** या **बंद** करें।
2. <kbd>Alt</kbd>+<kbd>J</kbd> से कंट्रोल स्ट्रिप टॉगल करें।
3. <kbd>K</kbd> से **कीबोर्ड संदर्भ** टॉगल करें।
4. कीबोर्ड संदर्भ के लेआउट ड्रॉपडाउन से **आरंभिक ट्यूटोरियल** खोलें (KeyPilot → आरंभिक ट्यूटोरियल), या वॉकथ्रू दिखाने के लिए <kbd>Alt</kbd>+<kbd>I</kbd> दबाएँ।

### अभ्यास के लिए पहली कुंजी आज्ञाएँ

| लक्ष्य | डिफ़ॉल्ट कुंजी |
| --- | --- |
| कर्सर के नीचे क्लिक / फ़ोकस | <kbd>F</kbd> |
| पीछे | <kbd>D</kbd> |
| साइट रूट | <kbd>S</kbd> |
| आगे | <kbd>R</kbd> |
| ऊपर / नीचे स्क्रॉल | <kbd>C</kbd> / <kbd>V</kbd> |
| मोड छोड़ें / रद्द करें | <kbd>Esc</kbd> |
| कीबोर्ड संदर्भ | <kbd>K</kbd> |
| सेटिंग्स | <kbd>'</kbd> — [सेटिंग्स](kp://settings/overview) खोलें या [कीबोर्ड](kp://settings/keyboard) पर जाएँ |
| KeyPilot टॉगल करें | <kbd>Alt</kbd>+<kbd>K</kbd> |
| यह दस्तावेज़ | <kbd>Alt</kbd>+<kbd>H</kbd> |

### वॉकथ्रू बनाम अभ्यास

- **वॉकथ्रू** असली ब्राउज़िंग कामों की चेकलिस्ट है। प्रगति आपकी Chrome प्रोफ़ाइल में सहेजी जाती है और ट्यूटोरियल के प्रवेश बिंदुओं से रीसेट की जा सकती है।
- **अभ्यास पैनल** टेक्स्ट-बॉक्स स्लाइड के साथ दिखता है, ताकि आप <kbd>F</kbd> से फ़ोकस में आएँ, सामान्य रूप से टाइप करें, और <kbd>Esc</kbd> से बाहर निकलें।

</section>
<section class="article-column">

### अन्य प्रवेश बिंदु

- एक्सटेंशन **पॉपअप** → ट्यूटोरियल
- **गाइड** पॉपओवर → वॉकथ्रू शुरू करें
- कीबोर्ड संदर्भ ड्रॉपडाउन → आरंभिक ट्यूटोरियल
- <kbd>Alt</kbd>+<kbd>I</kbd> प्रगति रीसेट किए बिना वॉकथ्रू दिखाता या छिपाता है

</section>

### अगर कुछ न हो

- पुष्टि करें कि KeyPilot चालू है (<kbd>Alt</kbd>+<kbd>K</kbd>)।
- पुष्टि करें कि आप `chrome://` या Web Store पर नहीं हैं।
- कीबोर्ड संदर्भ खोलें और जाँचें कि आपका लेआउट अभी भी उस कुंजी को असाइन करता है जिसे आपने दबाया।
