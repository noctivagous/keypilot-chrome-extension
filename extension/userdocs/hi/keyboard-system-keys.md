# सिस्टम कुंजियाँ और Alt chrome

कुछ कुंजियाँ हमेशा KeyPilot क्रोम की होती हैं। वे अंतर्निहित और कस्टम लेआउट दोनों में उपलब्ध रहती हैं।

## उपयोग करें

### हमेशा-चालू सिस्टम परत

ये वर्ण कुंजियाँ तब भी काम करती हैं जब आपका कस्टम लेआउट उन्हें खाली छोड़ दे:

1. वर्तमान मोड रद्द करने के लिए <kbd>Esc</kbd> दबाएँ (टेक्स्ट मोड, चयन, स्क्रॉल लाइन, कई पॉपओवर)।
2. **कीबोर्ड संदर्भ** दिखाने या छिपाने के लिए <kbd>K</kbd> (दाएँ हाथ) या <kbd>D</kbd> (बाएँ हाथ) दबाएँ।
3. **सेटिंग्स** खोलने के लिए <kbd>'</kbd> (कोट) दबाएँ।

### Alt chrome हॉटकी

<kbd>Alt</kbd> दबाकर रखें और यह दबाएँ:

| कॉर्ड | क्रिया |
| --- | --- |
| <kbd>Alt</kbd>+<kbd>K</kbd> | KeyPilot चालू/बंद टॉगल करें (बंद होने पर भी काम करता है) |
| <kbd>Alt</kbd>+<kbd>J</kbd> | कंट्रोल स्ट्रिप दिखाएँ/छिपाएँ (बंद होने पर भी काम करता है) |
| <kbd>Alt</kbd>+<kbd>L</kbd> | ऑम्निबॉक्स खोलें |
| <kbd>Alt</kbd>+<kbd>;</kbd> या <kbd>Alt</kbd>+<kbd>A</kbd> | खोज फ़ोकस के साथ लॉन्चर खोलें |
| <kbd>Alt</kbd>+<kbd>[</kbd> / <kbd>Alt</kbd>+<kbd>]</kbd> | पिछला / अगला लेआउट परिवार |
| <kbd>Alt</kbd>+<kbd>C</kbd> | कीबोर्ड लेआउट एडिटर टॉगल करें |
| <kbd>Alt</kbd>+<kbd>H</kbd> | यह दस्तावेज़ खोलें |
| <kbd>Alt</kbd>+<kbd>I</kbd> | आरंभिक वॉकथ्रू दिखाएँ/छिपाएँ |

पहले <kbd>Alt</kbd>+<kbd>K</kbd>, <kbd>Esc</kbd>, <kbd>K</kbd>, <kbd>'</kbd>, और <kbd>Alt</kbd>+<kbd>H</kbd> याद रखें — बाकी सब इन्हीं से खुलता है।

## संदर्भ

### सिस्टम परत बनाम लेआउट कुंजियाँ

- **सिस्टम परत** — <kbd>Esc</kbd>, कीबोर्ड संदर्भ, सेटिंग्स। लेआउट परिवारों से अलग परिभाषित।
- **लेआउट कुंजियाँ** — <kbd>F</kbd>, <kbd>D</kbd>, स्क्रॉल, टूल, इत्यादि। सक्रिय अंतर्निहित या कस्टम लेआउट से आती हैं।
- **Alt chrome** — सामान्य कुंजी रूटिंग से पहले संभाला जाता है; सामान्य अक्षर असाइनमेंट के रूप में नहीं दिखता।

### हाथ पर नोट

बाएँ हाथ के लेआउट पर कीबोर्ड संदर्भ <kbd>D</kbd> पर चला जाता है, ताकि वह प्रतिबिंबित Activate समूह से न टकराए। सेटिंग्स <kbd>'</kbd> पर रहती हैं।

### रोज़मर्रा के उपयोग के लिए नहीं

<kbd>Alt</kbd>+<kbd>D</kbd> एक डेवलपर शैडो-रूट डीबग HUD टॉगल करता है। रेंडरिंग जाँचते समय ही इसका उपयोग करें।
