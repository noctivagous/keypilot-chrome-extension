# कंट्रोल स्ट्रिप

कंट्रोल स्ट्रिप एक छोटी, हमेशा दिखने वाली पट्टी है, जिससे माउस छुए बिना KeyPilot चालू-बंद किया जा सकता है, कीबोर्ड संदर्भ खोला जा सकता है, और सेटिंग्स तक पहुँचा जा सकता है।

## उपयोग

1. पेज पर पट्टी ढूँढें (खींची जा सकती है)। अगर वह गायब हो, तो वापस लाने के लिए <kbd>Alt</kbd>+<kbd>J</kbd> दबाएँ।
2. इससे ये काम करें:
   - KeyPilot **चालू/बंद** करें
   - **कीबोर्ड संदर्भ** खोलें
   - **सेटिंग्स** खोलें
   - पट्टी संकुचित / फैलाएँ या बंद करें
3. रास्ते से हटाकर रखने के लिए मूव हैंडल से खींचें।
4. **सेटिंग्स → कंट्रोल स्ट्रिप** में चुनें कि वह शुरू में दिखे या संकुचित हो।

KeyPilot बंद होने पर भी <kbd>Alt</kbd>+<kbd>J</kbd> पट्टी वापस लाता है।

## संदर्भ

### नियंत्रण

| नियंत्रण | भूमिका |
| --- | --- |
| चालू/बंद | <kbd>Alt</kbd>+<kbd>K</kbd> के बराबर |
| कीबोर्ड संदर्भ | <kbd>K</kbd> / <kbd>D</kbd> के बराबर |
| सेटिंग्स | <kbd>'</kbd> के बराबर |
| संकुचित / बंद | पट्टी छिपाएँ; <kbd>Alt</kbd>+<kbd>J</kbd> से वापस लाएँ |

### रूप

- टेक्स्ट मोड पट्टी को नारंगी रंग देता है, ताकि दिखे कि ब्राउज़िंग कुंजियाँ क्यों रुकी हैं।
- दृश्यता प्राथमिकताएँ आपकी प्रोफ़ाइल के साथ सिंक होती हैं।
