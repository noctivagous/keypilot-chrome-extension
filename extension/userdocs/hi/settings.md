# सेटिंग्स

सेटिंग्स दिखावट, स्क्रॉलिंग, खोज इंजन, कंट्रोल स्ट्रिप, और आप कौन सा कीबोर्ड परिवार उपयोग करते हैं, यह नियंत्रित करती हैं। बदलाव उसी Chrome प्रोफ़ाइल के टैबों में सिंक होते हैं।

## उपयोग करें

1. <kbd>'</kbd> (कोट) दबाएँ, या कंट्रोल स्ट्रिप, पॉपअप, नया टैब पेज, या कीबोर्ड संदर्भ ड्रॉपडाउन से सेटिंग्स खोलें।
2. बाएँ नेविगेशन में एक श्रेणी चुनें।
3. नियंत्रण समायोजित करें — ज़्यादातर तुरंत लागू होते हैं।
4. पूरा होने पर <kbd>Esc</kbd> या टाइटलबार का बंद नियंत्रण दबाएँ।

[**कीबोर्ड**](kp://settings/keyboard) (लेआउट + हाथ) और [**स्क्रॉलिंग**](kp://settings/scrolling) (पेज ऊपर / पेज नीचे की दूरी) से शुरू करें। बुनियादी बातें सही लगने पर [**क्लिक मोड**](kp://settings/click-mode) और [**टेक्स्ट मोड**](kp://settings/text-mode) को बारीक समायोजित करें।

## संदर्भ

### श्रेणियाँ

| अनुभाग | आप क्या कॉन्फ़िगर करते हैं |
| --- | --- |
| [**अवलोकन**](kp://settings/overview) | हर श्रेणी तक ले जाने वाला केंद्र |
| [**दिखावट**](kp://settings/appearance) | थीम और दृश्य क्रोम |
| [**कीबोर्ड**](kp://settings/keyboard) | लेआउट परिवार, बाएँ हाथ, संख्या पंक्ति, दबी कुंजी का फ़ीडबैक |
| [**क्लिक मोड**](kp://settings/click-mode) | कर्सर शैली, क्रॉसहेयर ज्यामिति, फ़ोकस आयत का रूप, लिंक-होवर संकेत, सक्रियण प्रभाव |
| [**टेक्स्ट मोड**](kp://settings/text-mode) | कर्सर, फ़ोकस शैली (धड़कता किनारा / टिंट), किनारे की चौड़ाई, लेबल, आउटलाइन |
| [**स्क्रॉलिंग**](kp://settings/scrolling) | पेज ऊपर / पेज नीचे की दूरी, सहज बनाम तत्काल छलांग, कैरोसेल छोड़ना, मिडल-क्लिक स्क्रॉल लाइन |
| [**कर्सर**](kp://settings/cursor) | कोई कस्टम कर्सर नहीं बनाम KeyPilot कर्सर; चालू होने पर क्लिक मोड क्रॉसहेयर ज्यामिति |
| [**कंट्रोल स्ट्रिप**](kp://settings/control-strip) | दृश्यता और शुरू में संकुचित; <kbd>Alt</kbd>+<kbd>J</kbd> से पुनर्स्थापित करें |
| [**खोज**](kp://settings/search) | ऑम्निबॉक्स / नया टैब खोज के लिए Brave, Google, या DuckDuckGo |
| [**परिचय**](kp://settings/about) | इस Chrome प्रोफ़ाइल के लिए स्टोरेज और सिंक नोट |

### संबंधित सतहें

- गहरा की-रीमैप **कीबोर्ड लेआउट एडिटर** (<kbd>Alt</kbd>+<kbd>C</kbd>) में है, सेटिंग्स में नहीं। [कीबोर्ड लेआउट एडिटर](kp://docs/layout-config) देखें।
- दस्तावेज़ <kbd>Alt</kbd>+<kbd>H</kbd> है; छोटा गाइड पेज कई क्रोम प्रवेश बिंदुओं से उपलब्ध रहता है।
