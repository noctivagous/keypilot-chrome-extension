# בונה המאקרו

בונה המאקרו הוא עורך השלבים למאקרו של המשתמש, וניגשים אליו מעורך פריסת המקלדת.

## שימוש

1. לחצו <kbd>Alt</kbd>+<kbd>C</kbd> כדי לפתוח את עורך פריסת המקלדת.
2. פתחו את **מאקרו של המשתמש**.
3. **צרו** מאקרו ותנו לו שם ברור — או שכפלו מאקרו קיים.
4. הוסיפו שלבים:
   - בחרו פונקציה בספריית הפעולות והוסיפו אותה למאקרו
   - הוסיפו שבבי **לוגיקה**: המתנה, שער, עצירה, הרצת מאקרו
   - הוסיפו **קבלת טווח טקסט** כדי ללכוד את הבחירה הנוכחית לשלב הבא
   - הוסיפו **הצגת חלון צף** כדי להציג את תוצאת השלב הקודם (או טקסט גיבוי)
   - הוסיפו **הרצת JS** כדי להריץ סקריפט שהודבק
5. סדרו מחדש או הסירו שלבים; פתחו שלב כדי לקבוע פרמטרים והשהיה אופציונלית.
6. **שמרו**, ואז הניחו את המאקרו על מקש מתוך הספרייה / רשימת המאקרו.
7. בדקו בדף רגיל; כווננו את השערים אם הזרימה צריכה להיעצר מוקדם.

## לעיון

### שבבי לוגיקה

| שבב | תפקיד |
| --- | --- |
| **המתנה** | השהיה לפני השלב הבא |
| **שער** | בדיקת התוצאה הקודמת; בכישלון דילוג על השלבים הבאים שהוגדרו |
| **עצירה** | סיום המאקרו |
| **הרצת מאקרו** | קריאה למאקרו אחר (מקונן; מוגן ממחזור) |
| **הרצת JS** | הרצת סקריפט שהודבק; ערך ההחזרה מזין את השער הבא |
| **קבלת טווח טקסט** | לכידת ההדגשה או הבחירה הנוכחית לשלב הבא. זו לא פעולת מקש (השתמשו בהעתקה). |
| **הצגת חלון צף** | הצגת תוצאת הפונקציה הקודמת (או טקסט הגיבוי שהוגדר) בחלון צף. זו לא פעולת מקש. |

### בדיקות שער

השוואות אופייניות מול תוצאת הפונקציה הקודמת:

- יש ערך / ריק
- שווה / לא שווה
- גדול מ- / קטן מ-

שערים שנכשלים מדלגים קדימה לפי ההגדרה, כך שאפשר להסתעף בלי סקריפט מלא.

### מקשי מאקרו כשלבים

פרימיטיבי הקשה מוגדרים (קיצור, מטח, סבב, רציף, עכבר סינתטי, מיפוי רגיל מחדש) יכולים לרוץ כשלבי פונקציה במאקרו, וגם כפעולות מקש עצמאיות.

### טיפים

- שמרו על מאקרו קצרים, ותנו לשלבים שמות לפי הכוונה.
- העדיפו שערים על פני שרשראות ארוכות בלי תנאי, כששלב עלול לא להניב כלום.
- ערכי החזרה של הרצת JS מזינים את השער הבא דרך `kpPriorResult` (ראו *הרצת JS*).
