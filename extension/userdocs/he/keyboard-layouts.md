# פריסות וכיוון היד

**פריסה** היא המפה ממקשים לפעולות. KeyPilot מגיע עם משפחות מובנות; אפשר להחליף כיוון יד או לבנות פריסות מותאמות.

## שימוש

1. פתחו את **ההגדרות** (<kbd>'</kbd>) → **מקלדת**, או השתמשו בתפריט הפריסה בשורת הכותרת של **מקלדת הייחוס**.
2. בחרו **משפחה**:
   - **גלישה** — לחיצה, גלילה, כרטיסיות וכלים במלואם (ברירת מחדל).
   - **ניווט** — ערכה מצומצמת שמתמקדת בלחיצה / אחורה / קדימה.
3. הפעילו **לשמאליים** אם העכבר ביד שמאל — קיצורי הדרך העיקריים עוברים לצד הימני של המקלדת.
4. אפשר לעבור בין משפחות בכל עת עם <kbd>Alt</kbd>+<kbd>[</kbd> (הקודמת) ו-<kbd>Alt</kbd>+<kbd>]</kbd> (הבאה) בלי לשנות את כיוון היד.
5. כדי להתאים מקשים לעומק, לחצו על <kbd>Alt</kbd>+<kbd>C</kbd> לעורך פריסת המקלדת (ראו את הנושא הזה).

פתחו את <kbd>\</kbd> (מקלדת הייחוס) אחרי המעבר — המקלדת המצוירת תמיד תואמת את הפריסה הפעילה.

## לעיון

### משפחות מובנות

| משפחה | מטרה |
| --- | --- |
| גלישה | גלישה יומיומית שמבוססת על המקלדת |
| ניווט | תת-קבוצה מצומצמת לניווט |

כיוון היד אינו תלוי במשפחה. מזהי „Basic Navigation” ישנים עשויים עדיין להיטען מהגדרות ישנות, אבל הם מוסתרים מהבוררים הרגילים.

### פריסות מותאמות

- עריכה של פריסה מובנית בעורך הפריסה יוצרת עותק משתמש (למשל „גלישה עותק 1”).
- פריסות מותאמות הן **בלעדיות**: רק משבצות משויכות, יחד עם שכבת המערכת שפועלת תמיד, מופעלות.
- ייבאו וייצאו JSON מעורך הפריסה כדי לגבות או לשתף פריסות.

### הגדרות קשורות

- הצגת שורת המספרים במקלדת הייחוס / בעורך
- משוב על מקש שנלחץ בזמן הקלדת קיצורים
- מזהה הפריסה הנוכחית והמשפחה נשמרים בפרופיל Chrome
