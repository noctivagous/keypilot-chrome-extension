# הגדרות

ההגדרות שולטות במראה, בגלילה, במנוע החיפוש, בפס הבקרה ובמשפחת המקלדת שבשימוש. השינויים מסתנכרנים בין כרטיסיות באותו פרופיל Chrome.

## שימוש

1. לחצו על <kbd>'</kbd> (גרש), או פתחו את ההגדרות מפס הבקרה, מהחלון הקופץ, מדף הכרטיסייה החדשה, או מתפריט מקלדת הייחוס.
2. בחרו קטגוריה בניווט השמאלי.
3. כווננו את הפקדים — רובם חלים מיד.
4. לחצו על <kbd>Esc</kbd> או על פקד הסגירה בשורת הכותרת כשסיימתם.

התחילו ב[**מקלדת**](kp://settings/keyboard) (פריסה + כיוון יד) וב[**גלילה**](kp://settings/scrolling) (מרחק Page Up / Page Down). כווננו דק את [**מצב קליק**](kp://settings/click-mode) ואת [**מצב טקסט**](kp://settings/text-mode) כשהבסיס מרגיש נכון.

## לעיון

### קטגוריות

| מקטע | מה מגדירים |
| --- | --- |
| [**סקירה**](kp://settings/overview) | מרכז עם קישורים לכל קטגוריה |
| [**מראה**](kp://settings/appearance) | ערכת נושא וממשק חזותי |
| [**מקלדת**](kp://settings/keyboard) | משפחת פריסות, לשמאליים, שורת המספרים, משוב על מקש שנלחץ |
| [**מצב קליק**](kp://settings/click-mode) | סגנון סמן, גיאומטריית הצלב, מראה מלבן המיקוד, רמזי ריחוף על קישורים, אפקטי הפעלה |
| [**מצב טקסט**](kp://settings/text-mode) | סמן, סגנון מיקוד (קצה פועם / גוון), רוחב הקצה, תוויות, מתאר |
| [**גלילה**](kp://settings/scrolling) | מרחק Page Up / Page Down, קפיצות חלקות או מיידיות, דילוג על קרוסלות, לחיצה אמצעית ל-Scroll Line |
| [**סמן**](kp://settings/cursor) | בלי סמנים מותאמים לעומת סמני KeyPilot; גיאומטריית הצלב של מצב הקליק כשהאפשרות פעילה |
| [**פס הבקרה**](kp://settings/control-strip) | נראות והתחלה מכווצת; שחזור עם <kbd>Alt</kbd>+<kbd>J</kbd> |
| [**חיפוש**](kp://settings/search) | Brave, Google או DuckDuckGo לחיפוש בתיבת החיפוש / בכרטיסייה החדשה |
| [**אודות**](kp://settings/about) | הערות אחסון וסנכרון לפרופיל Chrome הזה |

### משטחים קשורים

- מיפוי מקשים מעמיק נמצא ב**עורך פריסת המקלדת** (<kbd>Alt</kbd>+<kbd>C</kbd>), לא בהגדרות. ראו [עורך פריסת המקלדת](kp://docs/layout-config).
- התיעוד הוא <kbd>Alt</kbd>+<kbd>H</kbd>; עמוד המדריך הקצר נשאר זמין מכמה נקודות כניסה בממשק.
