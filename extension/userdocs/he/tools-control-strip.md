# פס הבקרה

פס הבקרה הוא פס קטן שגלוי תמיד להפעלה ולכיבוי של KeyPilot, לפתיחת מקלדת הייחוס ולהגעה להגדרות — בלי לגעת בעכבר.

## שימוש

1. מצאו את הפס בדף (אפשר לגרור). אם הוא נעלם, לחצו <kbd>Alt</kbd>+<kbd>J</kbd> כדי להחזיר אותו.
2. השתמשו בו כדי:
   - להפעיל או לכבות את KeyPilot (**פועל/כבוי**)
   - לפתוח את **מקלדת הייחוס**
   - לפתוח את **ההגדרות**
   - לכווץ / להרחיב או לסגור את הפס
3. גררו דרך ידית ההזזה כדי להניח אותו בצד.
4. ב-**הגדרות → פס הבקרה**, בחרו אם הוא נפתח גלוי או מכווץ.

<kbd>Alt</kbd>+<kbd>J</kbd> מחזיר את הפס גם כש-KeyPilot כבוי.

## לעיון

### פקדים

| פקד | תפקיד |
| --- | --- |
| פועל/כבוי | שווה ערך ל-<kbd>Alt</kbd>+<kbd>K</kbd> |
| מקלדת הייחוס | שווה ערך ל-<kbd>\</kbd> |
| הגדרות | שווה ערך ל-<kbd>'</kbd> |
| כיווץ / סגירה | הסתרת הפס; שחזור עם <kbd>Alt</kbd>+<kbd>J</kbd> |

### מראה

- מצב טקסט צובע את הפס בכתום כדי שאפשר יהיה לראות למה מקשי הגלישה מושהים.
- העדפות הנראות מסתנכרנות עם הפרופיל.
