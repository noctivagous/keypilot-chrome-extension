# מקשי מערכת וממשק Alt

חלק מהמקשים שייכים תמיד לממשק של KeyPilot. הם נשארים זמינים בפריסות המובנות ובפריסות המותאמות.

## שימוש

### שכבת מערכת שפועלת תמיד

מקשי התווים האלה פועלים גם כשהפריסה המותאמת משאירה אותם ריקים:

1. לחצו על <kbd>Esc</kbd> כדי לבטל את המצב הנוכחי (מצב טקסט, בחירה, Scroll Line, והרבה חלונות צפים).
2. לחצו על <kbd>\</kbd> כדי להציג או להסתיר את **מקלדת הייחוס**.
3. לחצו על <kbd>'</kbd> (גרש) כדי לפתוח את **ההגדרות**.

### מקשי קיצור של ממשק Alt

החזיקו את <kbd>Alt</kbd> ולחצו:

| צירוף | פעולה |
| --- | --- |
| <kbd>Alt</kbd>+<kbd>K</kbd> | הפעלה או כיבוי של KeyPilot (פועל גם כשהתוסף כבוי) |
| <kbd>Alt</kbd>+<kbd>J</kbd> | הצגה או הסתרה של פס הבקרה (פועל גם כשהתוסף כבוי) |
| <kbd>Alt</kbd>+<kbd>L</kbd> | פתיחת תיבת החיפוש |
| <kbd>Alt</kbd>+<kbd>;</kbd> או <kbd>Alt</kbd>+<kbd>A</kbd> | פתיחת המשגר עם מיקוד בחיפוש |
| <kbd>Alt</kbd>+<kbd>[</kbd> / <kbd>Alt</kbd>+<kbd>]</kbd> | משפחת הפריסות הקודמת / הבאה |
| <kbd>Alt</kbd>+<kbd>C</kbd> | הפעלה או כיבוי של עורך פריסת המקלדת |
| <kbd>Alt</kbd>+<kbd>H</kbd> | פתיחת התיעוד הזה |
| <kbd>Alt</kbd>+<kbd>I</kbd> | הצגה או הסתרה של סיור ההתחלה |

כדאי לזכור קודם את <kbd>Alt</kbd>+<kbd>K</kbd>, <kbd>Esc</kbd>, <kbd>\</kbd>, <kbd>'</kbd> ו-<kbd>Alt</kbd>+<kbd>H</kbd> — הם פותחים את כל השאר.

## לעיון

### שכבת המערכת מול מקשי הפריסה

- **שכבת המערכת** — <kbd>Esc</kbd>, מקלדת הייחוס, הגדרות. מוגדרת בנפרד ממשפחות הפריסה.
- **מקשי הפריסה** — <kbd>F</kbd>, <kbd>D</kbd>, גלילה, כלים וכן הלאה. מגיעים מהפריסה המובנית או המותאמת הפעילה.
- **ממשק Alt** — מטופל לפני ניתוב המקשים הרגיל; לא מוצג כשיוך אות רגיל.

### הערה על כיוון היד

מקלדת הייחוס היא <kbd>\</kbd> לשתי הידיים, כדי שסגירת חלון תוכל להשתמש ב-<kbd>K</kbd> (לימניים) וב-<kbd>D</kbd> (לשמאליים). ההגדרות נשארות על <kbd>'</kbd>.

### לא לשימוש יומיומי

<kbd>Alt</kbd>+<kbd>D</kbd> מפעיל או מכבה HUD ניפוי של shadow-root למפתחים. דלגו עליו אלא אם אתם מאבחנים רינדור.
