# תחילת העבודה

לחצו על המקשים הראשונים בכל דף; השאירו את מקלדת הייחוס פתוחה עד שהפריסה הופכת לטבע שני.

## שימוש

1. הפעילו או כבו את KeyPilot עם <kbd>Alt</kbd>+<kbd>K</kbd>.
2. הציגו או הסתירו את פס הבקרה עם <kbd>Alt</kbd>+<kbd>J</kbd>.
3. הציגו או הסתירו את **מקלדת הייחוס** עם <kbd>K</kbd>.
4. פתחו את **מדריך ההתחלה** מתפריט הפריסה במקלדת הייחוס (KeyPilot → מדריך התחלה), או לחצו על <kbd>Alt</kbd>+<kbd>I</kbd> כדי להציג את הסיור.

### פקודות המקש הראשונות לתרגול

| מטרה | מקש ברירת מחדל |
| --- | --- |
| לחיצה / מיקוד מתחת לסמן | <kbd>F</kbd> |
| אחורה | <kbd>D</kbd> |
| שורש האתר | <kbd>S</kbd> |
| קדימה | <kbd>R</kbd> |
| גלילה למעלה / למטה | <kbd>C</kbd> / <kbd>V</kbd> |
| יציאה ממצב / ביטול | <kbd>Esc</kbd> |
| מקלדת הייחוס | <kbd>K</kbd> |
| הגדרות | <kbd>'</kbd> — פתיחת [הגדרות](kp://settings/overview) או מעבר ל[מקלדת](kp://settings/keyboard) |
| הפעלה או כיבוי של KeyPilot | <kbd>Alt</kbd>+<kbd>K</kbd> |
| התיעוד הזה | <kbd>Alt</kbd>+<kbd>H</kbd> |

### הסיור מול התרגול

- **הסיור** הוא רשימת משימות של פעולות גלישה אמיתיות. ההתקדמות נשמרת בפרופיל Chrome, ואפשר לאפס אותה מנקודות הכניסה למדריך.
- **לוח התרגול** מופיע עם שקופית תיבת הטקסט, כדי שאפשר יהיה להיכנס למיקוד עם <kbd>F</kbd>, להקליד כרגיל, ולצאת עם <kbd>Esc</kbd>.

</section>
<section class="article-column">

### נקודות כניסה נוספות

- **החלון הקופץ** של התוסף → מדריך
- חלון **המדריך** הצף → הפעלת הסיור
- תפריט מקלדת הייחוס → מדריך התחלה
- <kbd>Alt</kbd>+<kbd>I</kbd> מציג או מסתיר את הסיור בלי לאפס את ההתקדמות

</section>
</div>

### אם לא קורה כלום

- ודאו ש-KeyPilot פעיל (<kbd>Alt</kbd>+<kbd>K</kbd>).
- ודאו שאתם לא בדף `chrome://` ולא ב-Chrome Web Store.
- פתחו את מקלדת הייחוס ובדקו שהפריסה עדיין משייכת את המקש שלחצתם עליו.
