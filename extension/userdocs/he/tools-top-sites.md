# אתרים מובילים

אתרים מובילים הם לוח קומפקטי לסימניות סרגל הכלים, לאתרים הנצפים ביותר, לסימניות אחרונות ולכלי KeyPilot.

## שימוש

1. לחצו <kbd>;</kbd> (גלישה לימניים כברירת מחדל; לשמאליים לרוב <kbd>A</kbd> / <kbd>&#96;</kbd>).
2. עברו בין לשוניות בתוך הלוח: **סרגל כלים**, **נצפים ביותר**, **סימניות אחרונות** ו-**KeyPilot** (בקצה). <kbd>Tab</kbd> עובר ביניהן. מקשי המספרים פועלים לפי פריסת המקלדת.
3. לחצו או הפעילו כרטיס אתר כדי לנווט. הלוח גבוה מספיק לשלוש שורות כרטיסים בלי חיתוך.
4. פתחו את לשונית **KeyPilot** לאותם כרטיסי כלים כמו בחלון התוסף: מקלדת הייחוס, עזרה / תיעוד, מדריך התחלה, הגדרות ופס הבקרה.
5. גררו את שורת הכותרת של **אתרים מובילים** כדי להזיז את הלוח; גררו קצה או פינה כדי לשנות גודל. הגודל והמיקום נזכרים.
6. לחצו <kbd>Esc</kbd> או על כפתור הסגירה בשורת הכותרת כדי לסגור.

## השארה פתוחה בין דפים

כברירת מחדל אתרים מובילים הוא חלון חולף (הוא נסגר בלחיצה על <kbd>Esc</kbd>, בלחיצה בחוץ, או ביציאה מהדף).

כדי להשאיר אותו בזמן הגלישה, כמו מקלדת הייחוס:

1. פתחו את תפריט גלגל השיניים בשורת הכותרת (לצד הסגירה).
2. הפעילו **השארה פתוחה בין דפים**.

הלוח עולה מחדש בכל דף כל עוד משאירים אותו פתוח, והמיקום שלו נשאר מסונכרן בין כרטיסיות. סגרו אותו (או לחצו <kbd>;</kbd> שוב) כדי להסתיר עד לפתיחה מחדש. כבו את אפשרות גלגל השיניים כדי לחזור לחלון חולף.

## לעיון

### מקשי פתיחה כברירת מחדל

| פריסה | מקש טיפוסי |
| --- | --- |
| גלישה לימניים | <kbd>;</kbd> (גם <kbd>&#96;</kbd>) |
| גלישה לשמאליים | <kbd>A</kbd> / <kbd>&#96;</kbd> |

### לעומת המשגר

- **אתרים מובילים** — גישה מהירה לסרגל הכלים / לנצפים ביותר / לסימניות האחרונות של Chrome, ועוד לשונית כלי KeyPilot.
- **משגר** — קטגוריות רחבות יותר, משטח השקה ניתן לעריכה וחיפוש ממוקד (<kbd>Alt</kbd>+<kbd>;</kbd>).
