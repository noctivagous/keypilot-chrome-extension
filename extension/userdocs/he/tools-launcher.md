# משגר

המשגר הוא דפדפן אתרים לפי קטגוריות, עם חיפוש, סימניות, היסטוריה ומשטח השקה שאפשר לערוך.

## שימוש

1. לחצו <kbd>Alt</kbd>+<kbd>;</kbd> או <kbd>Alt</kbd>+<kbd>A</kbd> כדי לפתוח את המשגר כשהחיפוש במיקוד.
2. הקלידו כדי לסנן, או עיינו בקטגוריות (משטח השקה, סימניות, אחרונים, רשתות חברתיות, חדשות, פרודוקטיביות, סרטונים, בידור, קניות, בינה מלאכותית, Internet Archive, חיפושים ועוד).
3. פתחו אתר מהרשת או מהרשימה.
4. לחצו <kbd>/</kbd> כדי להחזיר את המיקוד לחיפוש; השתמשו ב-<kbd>←</kbd>/<kbd>→</kbd>/<kbd>↑</kbd>/<kbd>↓</kbd> לתנועה; <kbd>Esc</kbd> סוגר (או יוצא קודם ממצב עריכה).

כדי לקבע קיצורים משלכם, פתחו את **משטח ההשקה** והשתמשו במצב עריכה כדי לסדר מחדש, להסיר או להוסיף פריטים.

## לעיון

### פתיחה

| שיטה | הערות |
| --- | --- |
| <kbd>Alt</kbd>+<kbd>;</kbd> / <kbd>Alt</kbd>+<kbd>A</kbd> | קיצור של Chrome — החיפוש במיקוד |
| פונקציית פריסה | אפשר לשייך את המשגר לכל מקש בעורך פריסת המקלדת (אין ברירת מחדל חשופה בגלישה לימניים) |

### תת-תצוגות

- משטח השקה / קטגוריות אתרים
- מועדפים / סימניות
- היסטוריה
- חיפוש

### טיפים

- העדיפו את המשגר ליעדים שאתם חוזרים אליהם; העדיפו את תיבת החיפוש לכתובות ולשאילתות חד-פעמיות.
- עריכות במשטח ההשקה נשמרות בפרופיל שלכם.
