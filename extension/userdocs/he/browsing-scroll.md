# גלילה

גללו את הדף או גוללים מקוננים שמתחת לסמן, בצעדים קבועים, בקפיצות, או בשליטה רציפה של Scroll Line.

## שימוש

1. כוונו אל הדף (או אל תוך אזור שניתן לגלול).
2. השתמשו ב-**Page Up** וב-**Page Down** כדי לגלול לפי המרחק שהוגדר.
3. השתמשו ב**גלילה לראש** כדי לקפוץ לראש יעד הגלילה; ב**גלילה לתחתית** כדי להגיע לתחתית.
4. לשליטה רציפה, השתמשו ב-**Scroll Line**:
   - סימן מוצא מופיע מתחת לסמן.
   - הזיזו את העכבר מהמוצא — ככל שמתרחקים, הגלילה מהירה יותר.
   - השתמשו שוב ב-**Scroll Line**, לחצו, או לחצו על <kbd>Esc</kbd> כדי לצאת.
5. אפשר להפעיל **לחיצה אמצעית על אזור ריק בדף** בהגדרות → גלילה, כדי להתחיל Scroll Line בלי מקש Scroll Line.
6. השתמשו ב**הקטנת תצוגה** (<kbd>[</kbd>) וב**הגדלת תצוגה** (<kbd>]</kbd>) כדי לשנות את מרחק התצוגה של הכרטיסייה בצעד דפדפן אחד. הנקודה שמתחת לסמן נשארת קבועה, כמו במחוות צביטה.

כווננו את גודל הצעד ואת ההנפשה תחת **הגדרות → גלילה**.

## לעיון

### פונקציות

| פונקציה | מה היא עושה |
| --- | --- |
| **Page Up** | גלילה למעלה לפי מרחק הגלילה המיידית שהוגדר |
| **Page Down** | גלילה למטה לפי מרחק הגלילה המיידית שהוגדר |
| **גלילה לראש** | קפיצה לראש יעד הגלילה |
| **גלילה לתחתית** | קפיצה לתחתית יעד הגלילה |
| **Scroll Line** | הפעלה או כיבוי של גלילה רציפה לפי מוצא |
| **הקטנת תצוגה** | הקטנת תצוגת הכרטיסייה בצעד אחד, בנקודת הסמן |
| **הגדלת תצוגה** | הגדלת תצוגת הכרטיסייה בצעד אחד, בנקודת הסמן |

מקשי ברירת המחדל של הפונקציות האלה תלויים בפריסת המקלדת הפעילה.

### הגדרות שחשובות

- **מרחק גלילה** עבור Page Up / Page Down
- הנפשה **חלקה או מיידית** לקפיצות
- **דילוג על גוללים רחבים דמויי קרוסלה** ב-Scroll Line
- **לחיצה אמצעית** כדי להתחיל Scroll Line על אזור ריק בדף

### יעד הגלילה

KeyPilot גולל את הדף או את הגולל המקונן שמתחת לסמן. אם Scroll Line ננעל על האזור הלא נכון, צאו, מקמו מחדש את הסמן, ואז השתמשו שוב ב-**Scroll Line**.
