# Page Media

Page Media scans the current page for images, videos, text, documents, fonts, and URLs so you can browse or save them without inspecting the page manually.

## Use it

1. Press <kbd>O</kbd> on the default right-handed Browsing layout.
2. Switch tabs: **Image**, **Video**, **Text**, **Docs**, **Fonts**, **URLs**.
3. Preview items; adjust image scale/aspect when relevant.
4. Copy, download, open full view, or send items to the **Media Library**.
5. Close with <kbd>Esc</kbd> or the overlay close control.

Use Page Media when you want everything on the page; use <kbd>I</kbd> / <kbd>U</kbd> when you already know which hovered asset to grab.

## Reference

### Default key

| Layout | Key |
| --- | --- |
| Browsing right-handed | <kbd>O</kbd> |

Rebind via Layout Config if needed.

### Capabilities

- Image scale and aspect controls
- Fonts tab (custom `.woff2` / `.otf` / `.ttf` first, then system fonts)
- URL table/list views
- Copy, Media Library send, download
- Full view for images/videos

### Related

- **Media Library** (<kbd>M</kbd>) — your saved collection
- **Copy under cursor** — single hovered image/URL
