# Settings

Settings control appearance, scrolling, search engine, Control Strip, and which keyboard family you use. Changes sync across tabs in the same Chrome profile.

## Use it

1. Press <kbd>'</kbd> (quote), or open Settings from the Control Strip, popup, New Tab page, or Keyboard Reference dropdown.
2. Pick a category in the left nav.
3. Adjust controls — most apply immediately.
4. Press <kbd>Esc</kbd> or the titlebar close control when finished.

Start with **Keyboard** (layout + handedness) and **Scrolling** (<kbd>C</kbd>/<kbd>V</kbd> distance). Fine-tune **Click Mode** and **Text Mode** once the basics feel right.

## Reference

### Categories

| Section | What you configure |
| --- | --- |
| **Overview** | Hub linking into each category |
| **Keyboard** | Layout family, left-handed, number row, pressed-key feedback |
| **Click Mode** | Cursor style, crosshair geometry, focus rectangle look, link-hover hints, activation effects |
| **Text Mode** | Cursor, focus style (pulsing edge / tint), edge width, labels, outline |
| **Scrolling** | <kbd>C</kbd>/<kbd>V</kbd> distance, smooth vs instant jumps, carousel skip, middle-click Scroll Line |
| **Cursor** | Disable custom cursors or use KeyPilot crosshairs |
| **Control Strip** | Visibility and start-collapsed; restore with <kbd>Alt</kbd>+<kbd>J</kbd> |
| **Search** | Brave, Google, or DuckDuckGo for Omnibox / New Tab search |
| **About** | Storage and sync notes for this Chrome profile |

### Related surfaces

- Deep key remapping lives in **Keyboard Layout Config** (<kbd>Alt</kbd>+<kbd>C</kbd>), not in Settings.
- Documentation is <kbd>Alt</kbd>+<kbd>H</kbd>; the short Guide page remains available from several chrome entry points.
