# Media Library

Media Library is your personal gallery of saved images, videos, and URLs collected while browsing.

## Use it

1. Press <kbd>M</kbd> (default right-handed Browsing).
2. Browse by **Images**, **Videos**, **URLs**, and domains.
3. Open or full-view an item; select ranges for bulk actions.
4. Download a category or selection as a ZIP; delete what you no longer need.
5. Close with <kbd>Esc</kbd> or the overlay close control.

Add items from Page Media, Copy-under-cursor Functions, or other Actions that list Media Library as a destination.

## Reference

### Default key

| Layout | Key |
| --- | --- |
| Browsing right-handed | <kbd>M</kbd> |

### Categories

- Images, Videos, URLs (and domain groupings)
- Documents may appear in navigation but can be disabled / incomplete depending on build

### Tips

- Prefer Media Library for lasting saves; use clipboard destinations for one-off pastes.
