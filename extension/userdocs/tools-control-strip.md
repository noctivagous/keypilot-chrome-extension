# Control Strip

The Control Strip is a small always-visible bar for toggling KeyPilot, opening the Keyboard Reference, and reaching Settings — without touching the mouse.

## Use it

![Control Strip](images/control-strip.png)

1. Find the strip on the page (draggable). If it's gone, press <kbd>Alt</kbd>+<kbd>J</kbd> to restore it.
2. Use it to:
   - Turn KeyPilot **On/Off**
   - Open **Keyboard Reference**
   - Open **Settings**
   - Collapse / expand or close the strip
3. Drag via the move handle to park it out of the way.
4. In **Settings → Control Strip**, choose whether it starts visible or collapsed.

<kbd>Alt</kbd>+<kbd>J</kbd> restores the strip even when KeyPilot is disabled.

## Reference

### Controls

| Control | Role |
| --- | --- |
| On/Off | Equivalent to <kbd>Alt</kbd>+<kbd>K</kbd> |
| Keyboard Reference | Equivalent to <kbd>K</kbd> / <kbd>D</kbd> |
| Settings | Equivalent to <kbd>'</kbd> |
| Collapse / Close | Hide the strip; restore with <kbd>Alt</kbd>+<kbd>J</kbd> |

### Appearance

- Text Mode tints the strip orange so you can see why browsing keys are suspended.
- Visibility preferences sync with your profile.
