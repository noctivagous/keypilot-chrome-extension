# Seitenmedien

Page Media durchsucht die aktuelle Seite nach Bildern, Videos, Text, Dokumenten, Schriftarten und URLs, sodass Sie diese durchsuchen oder speichern können, ohne die Seite manuell überprüfen zu müssen.

## Benutze es

1. Drücken Sie <kbd>O</kbd> im Standard-Browsing-Layout für Rechtshänder.
2. Tabs wechseln: **Bild**, **Video**, **Text**, **Dokumente**, **Schriftarten**, **URLs**.
3. Vorschau der Elemente; Passen Sie ggf. den Bildmaßstab/das Bildformat an.
4. Kopieren, herunterladen, Vollansicht öffnen oder Elemente an die **Medienbibliothek** senden.
5. Schließen Sie mit <kbd>Esc</kbd> oder der Overlay-Schließsteuerung.

Verwenden Sie Seitenmedien, wenn Sie alles auf der Seite haben möchten. Verwenden Sie <kbd>I</kbd> / <kbd>U</kbd>, wenn Sie bereits wissen, welches schwebende Asset Sie ergreifen müssen.

## Referenz

### Standardschlüssel

| Layout | Schlüssel |
| --- | --- |
| Durchsuchen für Rechtshänder | <kbd>O</kbd> |

Bei Bedarf über den Layout-Editor erneut binden.

### Fähigkeiten

- Bildskalierungs- und Seitenverhältniskontrollen; **Artikel zuerst** (standardmäßig aktiviert) ordnet Bilder in „articles/main“ vor Site-Chrome
- Registerkarte „Schriftarten“ (zuerst benutzerdefinierte `.woff2` / `.otf` / `.ttf`, dann Systemschriftarten)
- URL-Tabellenansicht oder Listenansicht als umschließendes Kartenraster (Artikel/Hauptzeile zuerst; Site-Kopfzeile/-Fußzeile zuletzt)
- Kopieren, Mediathek versenden, herunterladen
- Vollansicht für Bilder/Videos

### Verwandte

- **Medienbibliothek** (<kbd>M</kbd>) – Ihre gespeicherte Sammlung
- **Unter Cursor kopieren** – einzelnes bewegtes Bild/URL
