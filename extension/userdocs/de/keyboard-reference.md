# Tastaturreferenz

Die schwebende Tastaturreferenz ist eine Live-Karte Ihres aktuellen Layouts – der schnellste Weg, Layouts zu erlernen und zu wechseln.

## Benutze es

1. Drücken Sie <kbd>K</kbd> (Rechtshänder) oder <kbd>D</kbd> (Linkshänder) oder verwenden Sie den Schalter „Kontrollleiste/Popup/Neuer Tab“.
2. Bewegen Sie den Mauszeiger über eine Tastenkappe, um die gebundene Aktion anzuzeigen.
3. Verwenden Sie das **Dropdown-Menü für das Titelleistenlayout**, um:
   - Wechseln Sie zwischen integrierten Familien oder benutzerdefinierten Layouts
   - Layout-Editor öffnen (Bearbeiten / Neu / Duplizieren)
   - **Onboarding-Tutorial** starten
   - Öffnen Sie **KeyPilot-Dokumentation/Hilfe** (dieses Popover)
   - Öffnen Sie **KeyPilot-Einstellungen**
4. Ziehen Sie das Fenster; Reduzieren Sie es, wenn Sie Platz auf dem Bildschirm benötigen. Schließen Sie mit dem × oder der gleichen Umschalttaste.
5. Während sich KeyPilot im Textmodus befindet, verwenden Sie <kbd>Exit</kbd> auf dem Referenz-Chrome, wenn Sie <kbd>Esc</kbd> nicht drücken möchten.

## Referenz

### Was es zeigt

- Aktive Familie, Händigkeit und individuelle Aufgaben
- Ständig aktive Systemtasten
- Optionale Zahlenreihe (Einstellungen → Tastatur)
- Hervorhebung gedrückter Tasten, wenn Feedback aktiviert ist
- Optionales Leuchten der Aktionstasten, wenn Sie mit der Maus über einen Link fahren (Einstellungen → Klickmodus)

### Bearbeitungsmodus

Wenn der Layouteditor <kbd>Alt</kbd>+<kbd>C</kbd> geöffnet ist, wird die Tastaturreferenz zur Platzierungsoberfläche: Wählen Sie eine Aktion in der Bibliothek aus und klicken Sie dann auf eine Tastenkappe, um sie zuzuweisen.

### Tipps

- Lassen Sie es während des Lernens auf einem zweiten Monitor oder in einer Ecke geöffnet.
- Wenn eine Taste nichts bewirkt, überprüfen Sie dieses Fenster, bevor Sie davon ausgehen, dass KeyPilot defekt ist – möglicherweise verwenden Sie die Navigationsfamilie oder ein spärliches benutzerdefiniertes Layout.
