# Tab-Verlauf

Der Tab-Verlauf zeigt, wo sich dieser Tab befand – einschließlich alternativer Verzweigungen, wenn Sie von einer Verzweigung weg navigiert haben.

## Benutze es

1. Drücken Sie <kbd>J</kbd> (Standard für Rechtshänder-Browsing; <kbd>F</kbd> für Linkshänder).
2. Durchsuchen Sie die horizontalen Schienen: Verzweigungserhaltender Verlauf und normaler Browserverlauf.
3. Zweigabzeichen kennzeichnen alternative Nachkommen einer Zweigstelle.
4. Klicken Sie auf eine Karte, um dorthin zu navigieren.
5. Drücken Sie zum Schließen <kbd>Esc</kbd>.

Verwenden Sie es, nachdem Sie mehrere Pfade desselben Artikels oder derselben Dokumentenseite durchsucht haben, wenn „Zurück“ allein nicht ausreicht.

## Referenz

### Schienen

- **Verzweigungserhaltender** Verlauf für die aktuelle Registerkarte
- Schiene **Browserverlauf** für herkömmlichen Backstack-Kontext

### Tipps

- Karten navigieren durch die aktuelle Registerkarte.
- Das Schließen mit <kbd>Esc</kbd> ändert die Seite nicht.
- Binden Sie den Tab-Verlauf im Layout-Editor neu oder entfernen Sie ihn, wenn Sie den Schlüssel für etwas anderes benötigen.
