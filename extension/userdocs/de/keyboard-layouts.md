# Layouts & Händigkeit

Ein **Layout** ist die Zuordnung von Tasten → Aktionen. KeyPilot liefert integrierte Familien; Sie können die Händigkeit ändern oder benutzerdefinierte Layouts erstellen.

## Benutze es

1. Öffnen Sie **Einstellungen** (<kbd>'</kbd>) → **Tastatur** oder verwenden Sie das Layout-Dropdown in der Titelleiste **Tastaturreferenz**.
2. Wählen Sie eine **Familie**:
   - **Browsen** – Vollklick, Scrollen, Tabs, Tools (Standard).
   - **Navigation** – Lean-Set mit Fokus auf Klicken/Vorwärts/Vorwärts.
3. Aktivieren Sie **Linkshänder**, wenn Sie die Maus in der linken Hand halten – primäre Tastenkombinationen werden auf die rechte Seite der Tastatur verschoben.
4. Durchlaufen Sie Familien jederzeit mit <kbd>Alt</kbd>+<kbd>[</kbd> (vorher) und <kbd>Alt</kbd>+<kbd>]</kbd> (nächste) ohne Änderung der Händigkeit.
5. Um die Tasten umfassend anzupassen, drücken Sie <kbd>Alt</kbd>+<kbd>C</kbd> für den Tastaturlayout-Editor (siehe dieses Thema).

Öffnen Sie nach dem Umschalten <kbd>K</kbd> (Tastaturreferenz) – die gezeichnete Tastatur entspricht immer dem aktiven Layout.

## Referenz

### Eingebaute Familien

| Familie | Absicht |
| --- | --- |
| Durchsuchen | Tägliches Surfen mit der Tastatur zuerst |
| Navigation | Minimale Navigationsteilmenge |

Händigkeit ist unabhängig von der Familie. Ältere „Basic Navigation“-IDs werden möglicherweise weiterhin aus älteren Einstellungen aufgelöst, sind jedoch für normale Auswahlfunktionen verborgen.

### Benutzerdefinierte Layouts

- Durch Bearbeiten einer im Layout-Editor integrierten Funktion wird eine Benutzerkopie erstellt (z. B. „Browsing-Kopie 1“).
- Benutzerdefinierte Layouts sind **exklusiv**: nur zugewiesene Slots plus das Always-on-System-Layer-Fire.
- Importieren/exportieren Sie JSON aus dem Layout-Editor, um Layouts zu sichern oder zu teilen.

### Verwandte Einstellungen

- Zahlenreihe in der Tastaturreferenz/im Tastatureditor anzeigen
- Feedback zu gedrückten Tasten beim Eingeben von Tastenkombinationen
- Die aktuelle Layout-ID und Familie bleiben in Ihrem Chrome-Profil erhalten
