# Medienbibliothek

Die Medienbibliothek ist Ihre persönliche Galerie mit gespeicherten Bildern, Videos, Dokumenten und URLs, die beim Surfen gesammelt wurden.

## Benutze es

1. Drücken Sie <kbd>M</kbd> (Standard-Rechtshänder-Browsing).
2. Durchsuchen Sie nach **Bildern**, **Videos**, **Dokumenten**, **URLs** und Domänen.
3. Ein Element öffnen oder vollständig anzeigen; Wählen Sie Bereiche für Massenaktionen aus.
4. Laden Sie eine Kategorie oder Auswahl als ZIP herunter; Löschen Sie, was Sie nicht mehr benötigen.
5. Schließen Sie mit <kbd>Esc</kbd> oder der Overlay-Schließsteuerung.

Fügen Sie Elemente aus Seitenmedien, Funktionen zum Kopieren unter dem Cursor oder anderen Aktionen hinzu, die die Medienbibliothek als Ziel auflisten.

## Referenz

### Standardschlüssel

| Layout | Schlüssel |
| --- | --- |
| Durchsuchen für Rechtshänder | <kbd>M</kbd> |

### Kategorien

- Bilder, Videos, Dokumente, URLs (und Domain-Gruppierungen)
- Verwenden Sie **URL für Medienbibliothek abrufen** für einen Dateilink mit der Maus oder „Von Seitenmedien senden“.

### Tipps

- Bevorzugen Sie die Medienbibliothek für dauerhafte Speicherung; Verwenden Sie Zwischenablageziele für einmalige Einfügungen.
