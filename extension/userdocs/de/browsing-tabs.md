# Registerkarten und Verlauf

Wechseln Sie zwischen Tabs und dem Browserverlauf, ohne nach Chrome-Schaltflächen greifen zu müssen.

## Benutze es

1. Drücken Sie <kbd>Q</kbd> / <kbd>W</kbd>, um zur vorherigen/nächsten Registerkarte zu wechseln.
2. Drücken Sie <kbd>T</kbd> für eine neue Registerkarte. <kbd>A</kbd>, um die aktuelle Registerkarte zu schließen.
3. Drücken Sie <kbd>D</kbd>, um zurückzugehen; <kbd>R</kbd>, um fortzufahren.
4. Drücken Sie <kbd>S</kbd> (oder <kbd>1</kbd>), um zum Stammverzeichnis der aktuellen Site (Schema + Host) zu springen.
5. Drücken Sie <kbd>J</kbd> für **Tab-Verlauf** – einen verzweigungsbewussten Verlaufsstreifen für diesen Tab (siehe *Tab-Verlauf*).

## Referenz

### Standardtasten (Browsen, Rechtshänder)

| Schlüssel | Aktion |
| --- | --- |
| <kbd>Q</kbd> | Vorheriger Tab |
| <kbd>W</kbd> | Nächste Registerkarte |
| <kbd>T</kbd> | Neuer Tab |
| <kbd>A</kbd> | Registerkarte schließen |
| <kbd>D</kbd> | Zurück |
| <kbd>R</kbd> | Vorwärts |
| <kbd>S</kbd> / <kbd>1</kbd> | Site-Root |
| <kbd>J</kbd> | Popover „Tab-Verlauf“ |

### Tipps

- Zurück/vorwärts folgen Sie dem normalen Browserverlauf für die Registerkarte.
- Der Tab-Verlauf behält alternative Zweige bei, wenn Sie von einer Verzweigung weg navigieren – nützlich, wenn Sie mehrere Pfade auf derselben Seite erkunden.
- Beim linkshändigen Surfen werden diese Cluster auf der rechten Seite der Tastatur gespiegelt.
