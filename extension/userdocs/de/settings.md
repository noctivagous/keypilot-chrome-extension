# Einstellungen

Die Einstellungen steuern das Erscheinungsbild, das Scrollen, die Suchmaschine, den Kontrollstreifen und die von Ihnen verwendete Tastaturfamilie. Änderungen werden tabübergreifend im selben Chrome-Profil synchronisiert.

## Benutze es

1. Drücken Sie <kbd>'</kbd> (Zitat) oder öffnen Sie die Einstellungen über die Kontrollleiste, das Popup, die Seite „Neuer Tab“ oder das Dropdown-Menü „Tastaturreferenz“.
2. Wählen Sie im linken Navigationsbereich eine Kategorie aus.
3. Passen Sie die Kontrollen an – die meisten gelten sofort.
4. Drücken Sie <kbd>Esc</kbd> oder das Steuerelement zum Schließen der Titelleiste, wenn Sie fertig sind.

Beginnen Sie mit [**Tastatur**](kp://settings/keyboard) (Layout + Händigkeit) und [**Scrolling**](kp://settings/scrolling) (Seite nach oben / Seite nach unten Abstand). Passen Sie den [**Klickmodus**](kp://settings/click-mode) und den [**Textmodus**](kp://settings/text-mode)] an, sobald sich die Grundlagen richtig anfühlen.

## Referenz

### Kategorien

| Abschnitt | Was Sie konfigurieren |
| --- | --- |
| [**Übersicht**](kp://settings/overview) | Hub-Verlinkung in jede Kategorie |
| [**Aussehen**](kp://settings/appearance) | Thema und visuelles Chrom |
| [**Tastatur**](kp://settings/keyboard) | Layoutfamilie, Linkshänder, Zahlenreihe, Rückmeldung bei gedrückter Taste |
| [**Klickmodus**](kp://settings/click-mode) | Cursor-Stil, Fadenkreuz-Geometrie, Fokus-Rechteck-Aussehen, Link-Hover-Hinweise, Aktivierungseffekte |
| [**Textmodus**](kp://settings/text-mode) | Cursor, Fokusstil (pulsierende Kante/Tönung), Kantenbreite, Beschriftungen, Umriss |
| [**Scrollen**](kp://settings/scrolling) | Seite nach oben / Seite nach unten Abstand, sanfte vs. sofortige Sprünge, Karussell-Sprung, Mittelklick auf Bildlauflinie |
| [**Cursor**](kp://settings/cursor) | Keine benutzerdefinierten Cursor im Vergleich zu KeyPilot-Cursor; Klicken Sie auf Modus Fadenkreuzgeometrie, wenn aktiviert |
| [**Kontrollstreifen**](kp://settings/control-strip) | Sichtbarkeit und Start-Einbruch; Wiederherstellen mit <kbd>Alt</kbd>+<kbd>J</kbd> |
| [**Suche**](kp://settings/search) | Brave, Google oder DuckDuckGo für Omnibox/Neue Tab-Suche |
| [**Über**](kp://settings/about) | Speicher- und Synchronisierungshinweise für dieses Chrome-Profil |

### Verwandte Oberflächen

- Die Neubelegung tiefer Tasten erfolgt im **Tastaturlayout-Editor** (<kbd>Alt</kbd>+<kbd>C</kbd>), nicht in den Einstellungen. Siehe [Tastaturlayout-Editor](kp://docs/layout-config).
- Dokumentation ist <kbd>Alt</kbd>+<kbd>H</kbd>; Die kurze Guide-Seite bleibt an mehreren Chrome-Einstiegspunkten verfügbar.
