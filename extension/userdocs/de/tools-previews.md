# Linkvorschau und Popover

Werfen Sie einen Blick auf einen Link in einem großen Betriebssystem-Popup-Fenster, ohne Ihren aktuellen Tab zu ersetzen.

## Benutze es

### Linkvorschau (<kbd>E</kbd>)

1. Bewegen Sie den Mauszeiger über einen Link, bis er hervorgehoben wird.
2. Drücken Sie <kbd>E</kbd>, um ein großes Popup-Fenster in der Nähe des Cursors zu öffnen.
3. Verwenden Sie **In diesem Tab öffnen** oder **In neuem Tab öffnen** in der KeyPilot-Titelleiste.
4. Schließen Sie mit <kbd>Esc</kbd>, dem Steuerelement zum Schließen der Titelleiste oder erneut der Aktionstaste.

### Open Popover

Öffnet den Link unter dem Cursor in einem größeren Popup. Keine Standardtaste im Browsing-Layout — binden Sie **Open Popover** im Layout-Editor.

Die Vorschau der Launcher-Karte und die Ergebnisse der Kategoriesuche verwenden dasselbe Popup-Fenster.

## Referenz

### Standardtasten (Browsen, Rechtshänder)

| Schlüssel | Aktion |
| --- | --- |
| <kbd>E</kbd> | Link-Vorschau-Popup |

### Verhaltenshinweise

- Vorschauen werden immer als Chrome/Brave-Popup-Fenster geöffnet (keine In-Page-Iframes).
- Einstellungen/Anleitung/Dokumente verwenden weiterhin In-Page-Popover-Chrome (Titelleiste, <kbd>Esc</kbd> zum Schließen).
- Passen Sie diese Funktionen im Layout-Editor an oder binden Sie sie neu.
