# Klicken und Verlinken

Mit der Maus auf Elemente zeigen; Drücken Sie eine Taste, um alles zu aktivieren, was sich darunter befindet. KeyPilot zeichnet ein Fokusrechteck auf das anklickbare Ziel oder Textfeld unter dem Cursor.

## Benutze es

1. Bewegen Sie den Mauszeiger über einen Link, eine Schaltfläche oder ein Textfeld, bis das Fokusrechteck angezeigt wird.
2. Drücken Sie <kbd>F</kbd>, um zu klicken – oder um ein Textfeld zu fokussieren und in den Textmodus zu wechseln.
3. Um den Link in einem **neuen Vordergrund-Tab** zu öffnen, drücken Sie <kbd>B</kbd>.
4. Um es in einem **Hintergrundtab** zu öffnen (wie ein Mittelklick), drücken Sie <kbd>G</kbd>.
5. Für einen kurzen Blick in ein Popup-Fenster drücken Sie <kbd>E</kbd> (Linkvorschau) oder <kbd>P</kbd> (größeres Popover). Siehe *Linkvorschau und Popover*.

Wenn das falsche Element hervorgehoben wird, bewegen Sie die Maus leicht – KeyPilot bevorzugt das Blatt unter dem Cursor.

## Referenz

### Standardtasten (Browsen, Rechtshänder)

| Schlüssel | Aktion |
| --- | --- |
| <kbd>F</kbd> | Unter dem Cursor klicken/aktivieren; Textfelder fokussieren |
| <kbd>B</kbd> | Link in neuem Tab öffnen (Vordergrund) |
| <kbd>G</kbd> | Link in neuem Tab öffnen (Hintergrund) |
| <kbd>E</kbd> | Link-Vorschau-Popup |
| <kbd>P</kbd> | Link im Popover-Popup öffnen |

### Visuelles Feedback

- Fokusrechtecke markieren anklickbare Ziele und Textfelder.
- Farben und Glanz können unter **Einstellungen → Klickmodus** angepasst werden.
- Optionale Aktivierungseffekte (Flash, Dash, Marquee, Scale) werden beim Klicken abgespielt.

### Textfelder

Durch Drücken von <kbd>F</kbd> in einem Textfeld wird es fokussiert und die meisten Browsertasten werden angehalten, sodass Sie tippen können. Drücken Sie <kbd>Esc</kbd>, um den Textmodus zu verlassen. Siehe *Modi*.
