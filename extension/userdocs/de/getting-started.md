# Erste Schritte

Drücken Sie die ersten Tasten auf einer beliebigen Seite. Lassen Sie die Tastaturreferenz geöffnet, bis das Layout in Fleisch und Blut übergegangen ist.

## Benutze es

1. Schalten Sie KeyPilot mit <kbd>Alt</kbd>+<kbd>K</kbd> **ein** oder **aus**.
2. Schalten Sie den Kontrollstreifen mit <kbd>Alt</kbd>+<kbd>J</kbd> um.
3. Schalten Sie **Tastaturreferenz** mit <kbd>K</kbd> um.
4. Öffnen Sie das **Onboarding-Tutorial** über das Dropdown-Menü „Tastaturreferenz“ (KeyPilot → Onboarding-Tutorial) oder drücken Sie <kbd>Alt</kbd>+<kbd>I</kbd>, um die exemplarische Vorgehensweise anzuzeigen.

### Erste wichtige Befehle zum Üben

| Ziel | Standardschlüssel |
| --- | --- |
| Klicken/fokussieren Sie unter dem Cursor | <kbd>F</kbd> |
| Zurück | <kbd>D</kbd> |
| Site-Root | <kbd>S</kbd> |
| Vorwärts | <kbd>R</kbd> |
| Nach oben/unten scrollen | <kbd>C</kbd> / <kbd>V</kbd> |
| Modus verlassen / abbrechen | <kbd>Esc</kbd> |
| Tastaturreferenz | <kbd>K</kbd> |
| Einstellungen | <kbd>'</kbd> – öffnen Sie [Einstellungen](kp://settings/overview) oder springen Sie zu [Tastatur](kp://settings/keyboard) |
| KeyPilot umschalten | <kbd>Alt</kbd>+<kbd>K</kbd> |
| Diese Dokumentation | <kbd>Alt</kbd>+<kbd>H</kbd> |

## Referenz

<div class="article-columns">
<section class="article-column">

### Exemplarische Vorgehensweise vs. Übung

- Die **Komplettlösung** ist eine Checkliste mit echten Browsing-Aktionen. Der Fortschritt wird in Ihrem Chrome-Profil gespeichert und kann über die Tutorial-Einstiegspunkte zurückgesetzt werden.
- Das **Übungsfeld** wird mit der Textfeldfolie angezeigt, sodass Sie den Fokus mit <kbd>F</kbd> eingeben, normal eingeben und mit <kbd>Esc</kbd> verlassen können.

</section>
<section class="article-column">

### Andere Einstiegspunkte

- Erweiterung **Popup** → Tutorial
- Popover **Anleitung** → Exemplarische Vorgehensweise starten
- Dropdown-Liste „Tastaturreferenz“ → Onboarding-Tutorial
- <kbd>Alt</kbd>+<kbd>I</kbd> zeigt oder verbirgt die Komplettlösung, ohne den Fortschritt zurückzusetzen

</section>
</div>

### Wenn nichts passiert

- Bestätigen Sie, dass KeyPilot aktiviert ist (<kbd>Alt</kbd>+<kbd>K</kbd>).
- Bestätigen Sie, dass Sie sich nicht bei `chrome://` oder im Web Store befinden.
- Öffnen Sie die Tastaturreferenz und überprüfen Sie, ob Ihr Layout die von Ihnen gedrückte Taste noch zuordnet.
