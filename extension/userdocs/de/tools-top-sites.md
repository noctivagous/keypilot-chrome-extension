# Top-Seiten

Top Sites ist ein kompaktes Panel für Symbolleisten-Lesezeichen, meistbesuchte Websites, aktuelle Lesezeichen und KeyPilot-Tools.

## Benutze es

1. Drücken Sie <kbd>;</kbd> (Standard-Rechtshänder-Browsing; Linkshänder verwenden oft <kbd>A</kbd> / <kbd>`</kbd>).
2. Wechseln Sie zwischen den Registerkarten im Bedienfeld: **Symbolleiste**, **Meistbesuchte**, **Letzte Lesezeichen** und **KeyPilot** (rechter Rand). Zifferntasten <kbd>1</kbd>–<kbd>4</kbd> springen zu einer Registerkarte; <kbd>Tab</kbd> wechselt sie.
3. Klicken oder aktivieren Sie eine Site-Karte, um zu navigieren. Das Panel ist hoch genug für drei Kartenreihen ohne Beschneiden.
4. Öffnen Sie die Registerkarte **KeyPilot** für dieselben Werkzeugkarten wie das Erweiterungs-Popup: Tastaturreferenz, Hilfe/Dokumente, Onboarding-Tutorial, Einstellungen und Kontrollleiste.
5. Ziehen Sie die Titelleiste **Top Sites**, um das Bedienfeld zu verschieben. Ziehen Sie eine Kante oder Ecke, um die Größe zu ändern. Größe und Position werden gespeichert.
6. Drücken Sie zum Schließen <kbd>Esc</kbd> oder die Schaltfläche zum Schließen der Titelleiste.

## Lassen Sie es seitenübergreifend geöffnet

Standardmäßig ist Top Sites ein vorübergehendes Modal (es wird geschlossen, wenn Sie <kbd>Esc</kbd> drücken, außerhalb klicken oder die Seite verlassen).

So behalten Sie es beim Surfen bei, z. B. in der Tastaturreferenz:

1. Öffnen Sie das Zahnradmenü in der Titelleiste (links vom Schließen).
2. Aktivieren Sie **Seitenübergreifend geöffnet bleiben**.

Das Bedienfeld wird dann auf jeder Seite erneut bereitgestellt, während Sie es geöffnet lassen, und seine Position bleibt über alle Registerkarten hinweg synchron. Schließen Sie es (oder drücken Sie erneut <kbd>;</kbd>), um es auszublenden, bis Sie es erneut öffnen. Schalten Sie die Gangoption aus, um zu einem Übergangsmodus zurückzukehren.

## Referenz

### Standardmäßige offene Schlüssel

| Layout | Typischer Schlüssel |
| --- | --- |
| Durchsuchen für Rechtshänder | <kbd>;</kbd> (auch <kbd>`</kbd>) |
| Linkshändiges Surfen | <kbd>A</kbd> / <kbd>`</kbd> |

### Im Vergleich zum Launcher

- **Top-Sites** – schneller Zugriff auf die Chrome-Symbolleiste / die am häufigsten besuchten / neuesten Lesezeichen sowie eine Registerkarte mit den KeyPilot-Tools.
- **Launcher** – breitere Kategorien plus bearbeitbares Launch Deck und gezielte Suche (<kbd>Alt</kbd>+<kbd>;</kbd>).
