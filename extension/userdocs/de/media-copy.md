# Unter dem Cursor kopieren

Schnappen Sie sich das schwebende Bild oder die URL mit einer Taste – in die Zwischenablage, in die Medienbibliothek oder in beides.

## Benutze es

1. Bewegen Sie den Mauszeiger über ein Bild oder ein Link-/URL-Ziel, bis KeyPilot es hervorhebt.
2. Drücken Sie <kbd>I</kbd>, um das schwebende **Bild** zu kopieren.
3. Drücken Sie <kbd>U</kbd>, um die schwebende **URL** zu kopieren.
4. Überprüfen Sie die Einstellungen der Aktionsinstanz im Layout-Editor, wenn Sie eine Medienbibliothek anstelle (oder zusätzlich zur) Zwischenablage wünschen.

**Video kopieren** ist in der Aktionsbibliothek vorhanden, verfügt jedoch über keinen integrierten Standardschlüssel – binden Sie ihn bei Bedarf in den Layout-Editor.

## Referenz

### Standardtasten (Browsen, Rechtshänder)

| Schlüssel | Aktion |
| --- | --- |
| <kbd>I</kbd> | Bewegtes Bild kopieren |
| <kbd>U</kbd> | Bewegte URL kopieren |

Beim linkshändigen Surfen wird das Kopierbild standardmäßig auf <kbd>E</kbd> platziert.

### Reiseziele

Viele Kopierfunktionen unterstützen:

- Zwischenablage
- Medienbibliothek
- Beides

Konfigurieren Sie die Aktionsinstanz und platzieren Sie diese Instanz dann auf einem Schlüssel.

### Verwandte

- **Seitenmedien** (<kbd>O</kbd>) – durchsuchen Sie alles, was auf der Seite gefunden wird
- **Medienbibliothek** (<kbd>M</kbd>) – überprüfen Sie, was Sie gespeichert haben
