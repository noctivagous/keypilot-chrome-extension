# Launcher

Launcher is a categorized site browser with search, bookmarks, history, and an editable Launch Deck.

## Use it

![Launcher](images/launcher.png)

1. Press <kbd>Alt</kbd>+<kbd>;</kbd> or <kbd>Alt</kbd>+<kbd>A</kbd> to open Launcher with search focused.
2. Type to filter, or browse categories (Launch Deck, Bookmarks, Recent, Social, News, Productivity, Videos, Entertainment, Shopping, AI, Internet Archive, Searches, and more).
3. Open a site from the grid or list.
4. Press <kbd>/</kbd> to focus search again; use <kbd>←</kbd>/<kbd>→</kbd>/<kbd>↑</kbd>/<kbd>↓</kbd> to move; <kbd>Esc</kbd> closes (or exits edit mode first).

To pin your own shortcuts, open **Launch Deck** and use edit mode to reorder, remove, or add entries.

## Reference

### Opening

| Method | Notes |
| --- | --- |
| <kbd>Alt</kbd>+<kbd>;</kbd> / <kbd>Alt</kbd>+<kbd>A</kbd> | Chrome hotkey — search focused |
| Layout Function | Launcher can be bound to any key in Layout Editor (no bare default on right-handed Browsing) |

### Subviews

- Launch Deck / site categories
- Favorites / bookmarks
- History
- Search

### Tips

- Prefer Launcher for destinations you revisit; prefer Omnibox for ad-hoc URLs and queries.
- Launch Deck edits persist in your profile.
