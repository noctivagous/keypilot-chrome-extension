KeyPilot — El key-click | Navegación con teclado

KeyPilot es una extensión de Chrome gratuita de Noctivagous Software. El mouse dirige. El teclado activa.

Este intro muestra el key-click: apuntar con el mouse, presionar F para abrir, D para volver. Dos entradas + dos trabajos hacen una mejor interfaz.
